CNN第一课：CV任务为什么需要CNN

⏱ 21分45秒 · BV1TtjJ6CEbe

💡 全连接网络处理图像的致命问题

如果用普通全连接网络处理图像，参数会爆炸！一张224×224×3的RGB图片，输入层就有224×224×3 = 150,528个神经元。如果第一个隐藏层有1024个神经元，仅这一层就有150K×1024 ≈ 1.5亿个参数！这不仅计算慢、容易过拟合，更重要的是——全连接网络完全忽略了图像的空间结构。

核心问题

❌ 全连接网络的缺陷

  • 参数爆炸：图像像素展开为一维向量，参数数量巨大
  • 丢失空间信息：像素的位置关系完全被忽略
  • 没有平移不变性：同一个物体在图片不同位置就认不出来了
  • 泛化能力差：需要大量数据才能训练
图像的本质

🖼️ 空间局部相关性

图像像素之间有很强的局部相关性：

  • 局部像素通常组成边缘、纹理等基础特征
  • 相邻区域构成物体的部件（眼睛、轮子等）
  • 高层组合形成完整物体（人脸、汽车等）
  • 这是一种层次化的特征结构
生物启发

🧠 Hubel-Wiesel实验：视觉皮层的启发

1962年，Hubel和Wiesel通过对猫视觉皮层的研究发现：

  • 简单细胞（Simple Cells）：只对特定位置、特定方向的边缘有反应
  • 复杂细胞（Complex Cells）：对边缘有反应，但具有一定的平移不变性（边缘在小范围内移动仍能激活）
  • 视觉皮层是层次化处理信息的：V1（边缘）→ V2（形状）→ V4（颜色/形状）→ IT（物体识别）
  • CNN正是模拟了这一机制：局部感受野+层次化特征提取

✨ CNN的三大核心优势

1. 参数大幅减少：局部连接+权重共享，同样的任务参数量只有全连接的几十分之一甚至几百分之一；2. 平移不变性：同一个特征在图像任何位置都能被检测到；3. 层次化特征提取：从边缘→纹理→部件→物体，自动学习多层级特征。

卷积层：如何提取图像特征

⏱ 18分32秒 · BV1NR7L6YEiF

💡 卷积运算的核心思想

卷积层是CNN的核心。一个卷积核（滤波器/Kernel）是一个小的权重矩阵（比如3×3），它在输入图像上从左到右、从上到下滑动，每到一个位置就和对应区域做逐元素相乘再求和，得到输出特征图上的一个值。这个过程就像用一个"模板"在图像上找匹配的模式。

卷积核作用

🔍 卷积核能检测什么？

不同的卷积核权重可以检测不同的特征：

  • 边缘检测：水平边缘、垂直边缘、对角线边缘
  • 模糊/平滑：取邻域平均，消除噪声
  • 锐化：强调边缘和细节
  • CNN通过训练自动学习卷积核的权重，不需要人工设计
输出尺寸公式

📐 卷积输出尺寸计算

Out = (In - K + 2P) / S + 1
  • In：输入尺寸（如224）
  • K：卷积核大小（如3）
  • P：Padding填充大小
  • S：Stride步幅
关键参数

⚙️ Padding 填充

在输入图像周围填充0（通常），有两个作用：

  • 保持尺寸：3×3卷积用P=1，可以让输出和输入尺寸相同
  • 保留边缘信息：不填充的话，图像边缘像素只被计算一次，信息利用不充分
  • P=K/2（向下取整）时称为Same Padding
关键参数

⚙️ Stride 步幅

卷积核每次滑动的距离：

  • S=1：每次滑动1个像素，最常用
  • S=2：每次滑动2个像素，输出尺寸减半，起到下采样作用
  • 步幅越大，输出尺寸越小，计算越快
多通道与1×1卷积

🌈 多通道卷积与1×1卷积的妙用

RGB多通道卷积

  • 输入是3通道RGB图像，卷积核也必须是3通道的（K×K×3）
  • 每个通道独立卷积后相加，得到1个输出通道
  • 有N个卷积核，就输出N个通道（每个卷积核产生1个通道）
  • 卷积核数量 = 输出通道数 = 特征图数量

1×1卷积的作用

  • 降维/升维：用较少的1×1卷积核减少通道数，大幅降低计算量（GoogLeNet/ResNet核心技巧）
  • 跨通道信息融合：在不改变空间尺寸的情况下整合各通道信息
  • 增加非线性（后面接ReLU）

CNN：池化层、分类与代码示例

⏱ 15分07秒 · BV1fW7L6XEiv

💡 池化层是做什么的？

池化层（Pooling）通常紧跟在卷积层之后，作用是降低特征图尺寸，减少计算量和参数，同时让网络对小的位移有更强的鲁棒性。池化层没有可学习的参数，只是固定的运算。

池化类型

🏊 Max Pooling vs Average Pooling

  • Max Pooling（最大池化）：取窗口内的最大值，保留最显著的特征，最常用
  • Average Pooling（平均池化）：取窗口内的平均值，更平滑，但可能丢失重要特征
  • 典型参数：2×2窗口，步幅S=2，这样高宽都减半
池化作用

🎯 池化层的三大作用

  • 降维：特征图尺寸减半，后续计算量减为1/4
  • 增大感受野：后面层的每个神经元能看到更大的原图区域
  • 平移不变性：特征在小范围内移动，池化后仍能激活
经典架构

🏆 CNN架构演进之路

1998
LeNet-5

Yann LeCun提出，手写数字识别，卷积+池化+全连接的经典模式，现代CNN的雏形

2012
AlexNet

Alex Krizhevsky，ImageNet竞赛冠军，8层网络，ReLU激活函数、Dropout、GPU训练，深度学习革命的开始

2014
VGGNet

牛津大学，统一使用3×3小卷积核堆叠，16-19层，结构简洁规整，证明了深度的重要性

2014
GoogLeNet (Inception)

Google，Inception模块（多尺度卷积并行），1×1卷积降维，22层但参数比AlexNet还少

2015
ResNet

何恺明等人，残差连接，152层（甚至1000+层），解决深度网络退化问题，影响最深远

📋 典型CNN结构模式

[Conv → ReLU → Pool] × N → Flatten → [FC → ReLU] × M → 输出层。图像经过多轮卷积+池化提取特征后，Flatten展平为向量，通过全连接层完成分类。现代网络（ResNet等）通常只用卷积层，最后用全局平均池化替代Flatten。

# PyTorch实现简单CNN
import torch
import torch.nn as nn

class SimpleCNN(nn.Module):
  def __init__(self):
    super().__init__()
    self.features = nn.Sequential(
      nn.Conv2d(3, 32, 3, padding=1), # 3通道输入→32通道
      nn.ReLU(),
      nn.MaxPool2d(2, 2), # 尺寸减半
      nn.Conv2d(32, 64, 3, padding=1),
      nn.ReLU(),
      nn.MaxPool2d(2, 2),
    )
    self.classifier = nn.Sequential(
      nn.Flatten(),
      nn.Linear(64 * 56 * 56, 256),
      nn.ReLU(),
      nn.Linear(256, 10) # 10分类
    )

  def forward(self, x):
    x = self.features(x)
    x = self.classifier(x)
    return x

残差连接：CNN和Transformer的共同捷径

⏱ 33分26秒 · BV1LGMw6HEEB

💡 深度网络的退化问题

理论上网络越深，表达能力越强。但实际训练发现：网络加深到一定程度后，训练误差反而上升！这不是过拟合（过拟合是训练误差低但测试误差高），而是深层网络更难训练——梯度在反向传播时不断相乘，越来越小（梯度消失）或越来越大（梯度爆炸），导致前面层几乎学不到东西。

梯度问题

⚠️ 梯度消失与爆炸

  • 梯度消失：反向传播时梯度经过多层连乘，趋近于0，前面层参数不更新
  • 梯度爆炸：梯度连乘后变得很大，参数更新不稳定
  • BN（BatchNorm）部分缓解了这个问题，但没有根本解决
  • 根本问题：深层网络很难学习恒等映射（即输出=输入）
核心思想

🪜 残差连接：y = F(x) + x

y = F(x) + x

ResNet的核心思想极其简单：

  • 不让网络直接学习y=H(x)，而是学习残差F(x)=H(x)-x
  • 即：输出 = 输入 + 残差（F(x)是需要学习的"增量"）
  • 有一条捷径（shortcut/skip connection）直接把x传到输出
为什么有效

🔑 残差连接为什么能训练152层？

  • 恒等映射很容易：如果F(x)=0，那y=x就是恒等映射，网络至少不会变差
  • 梯度直接回传：反向传播时，梯度可以通过shortcut直接流回前面层，不会消失
  • 梯度公式：∂L/∂x = ∂L/∂y · (1 + ∂F/∂x)，那个"+1"保证了即使∂F/∂x很小，梯度也不会消失
  • ResNet用152层在ImageNet上取得3.57%错误率，远超人类水平

🌉 残差连接在Transformer中的应用

残差连接不只属于CNN！Transformer中每个子层（多头注意力、FFN）都用了残差连接+LayerNorm：x = x + Sublayer(LN(x))。可以说，没有残差连接就没有Transformer，也就没有今天的大语言模型。后续的DenseNet（密集连接）等都是残差思想的扩展。

NLP概述：从规则到Transformer与大模型

⏱ 25分58秒 · BV1RMMu6TEpu
发展历史

📜 NLP七十年：从规则到大模型

1950s-80s
规则方法

人工编写语法规则和词典，如机器翻译的规则系统。优点：可解释；缺点：规则写不完，无法处理歧义，维护成本极高

1990s-2010
统计NLP

基于统计的方法：BoW（词袋模型）、TF-IDF、N-gram语言模型、隐马尔可夫模型（HMM）、条件随机场（CRF）。从数据中自动学习概率

2013
词向量时代

Word2Vec、GloVe将词映射为稠密向量，捕捉词语间的语义关系（king-man+woman≈queen），是NLP的里程碑

2014-2016
RNN/LSTM + Seq2Seq

RNN/LSTM处理序列数据，Seq2Seq+Attention用于机器翻译。但RNN无法并行计算，长距离依赖问题严重

2017
Transformer诞生

Google发表《Attention Is All You Need》，完全抛弃RNN，只用Self-Attention，可并行计算，能捕捉长距离依赖，AI革命的起点

2018-至今
预训练大模型时代

BERT（2018）、GPT系列（GPT-1/2/3/4）——预训练+微调范式，大语言模型(LLM)展现出涌现能力，ChatGPT改变世界

💡 注意力机制的核心思想

当你读一句话时，你不会对每个词都花同样的注意力——你会聚焦在最重要的部分。注意力机制就是让模型学会"对重要的信息分配更多权重"。比如翻译"The animal didn't cross the street because it was tired"，"it"指的是"animal"而不是"street"，注意力机制能让模型在处理"it"时重点关注"animal"。

核心机制

🎯 Self-Attention 自注意力

Self-Attention是Transformer的核心：

  • 一句话中的每个词都和句子中所有词计算注意力权重
  • 每个词的输出是所有词的加权和，权重代表它们之间的关联度
  • 可以并行计算（不像RNN必须一个词一个词处理）
  • 能捕捉任意距离的依赖关系
架构简述

🏗️ Transformer架构

Transformer采用编码器-解码器结构：

  • 编码器（Encoder）：多层堆叠，每层=多头注意力+FFN+残差+LayerNorm
  • 解码器（Decoder）：类似编码器，但加了掩码注意力防止看到未来的词
  • BERT只用编码器，GPT只用解码器
大模型范式

🚀 预训练+微调：大模型成功的关键

现代LLM的核心范式：

📚

预训练 Pre-training

在海量文本（互联网、书籍等）上做无监督学习，学习通用语言能力。通常是"下一个词预测"任务

🎯

微调 Fine-tuning

在特定任务数据上继续训练，适配具体任务（分类、问答、翻译等）。现在也常用Prompting替代微调

✨

涌现能力

参数规模大到一定程度（百亿级以上），模型突然展现出小模型没有的能力：推理、思维链、Few-shot学习

🌟 AI的未来展望

从机器学习到深度学习，从CNN到Transformer到大语言模型，AI正在以前所未有的速度发展。多模态（理解图像、音频、视频）、具身智能（机器人）、AI for Science（用AI做科学研究）、AGI（通用人工智能）……这是一个最好的时代，也是AI学习者的黄金时代。恭喜你完成了全部34集的学习，这只是你AI旅程的开始！
