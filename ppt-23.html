数据在网络中如何流动？

前向传播全过程——从输入到预测

📥 输入 X 原始数据：图片像素、文本向量、特征向量……
↓
🔢 第1隐藏层：z¹ = W¹X + b¹, a¹ = σ(z¹) 线性变换 + 非线性激活
↓
🔢 第2隐藏层：z² = W²a¹ + b², a² = σ(z²) 上一层输出作为这一层输入
↓
...（重复L-1次，L是层数）...
↓
📤 输出层：ẙ = softmax(zᴸ) 或 σ(zᴸ) 或 zᴸ 多分类用softmax，二分类用sigmoid，回归直接输出
↓
📏 计算损失：L(ẙ, y) 对比预测和真实标签，衡量误差

反向传播四步法回顾

神经网络训练的核心引擎——链式法则的工程实现

$$\displaystyle 反向传播 = 链式法则 + 计算图 + 动态规划$$

Step 1️⃣ 前向传播

计算所有层的激活值a¹, a², ..., aᴸ，缓存下来后面要用。

Step 2️⃣ 输出层误差

δᴸ = ∂L/∂zᴸ = (aᴸ - y) ⊙ g'(zᴸ)
（输出层的"误差信号"）

Step 3️⃣ 反向传播误差

从后往前逐层计算：
δˡ = ((Wˡ⁺¹)ᵀδˡ⁺¹) ⊙ g'(zˡ)
把误差从后层传到前层

Step 4️⃣ 计算梯度

∂L/∂Wˡ = δˡ(aˡ⁻¹)ᵀ
∂L/∂bˡ = δˡ
得到每个参数的梯度，用于更新

🎯 直觉理解

反向传播就像"责任分摊"：最终输出错了，每个参数根据自己"贡献"了多少误差，承担相应的"责任"（梯度），然后往减少误差的方向调整。类似团队项目失败了，追溯每个人的责任。

为什么反向传播是高效的？

暴力求导 vs 反向传播——复杂度对比

❌ 暴力数值求导

对每个参数wᵢ，计算：

$$\displaystyle \partial L/ \partial w_i \approx (L(w+ \epsilon )-L(w- \epsilon ))/(2 \epsilon )$$
  • 每个参数要做两次前向传播
  • 百万参数 → 百万次前向传播
  • 复杂度：O(n)次前向传播
  • 完全不实用，训练一个网络要几百年
VS

✅ 反向传播

一次前向 + 一次反向：

前向缓存aˡ → 反向算δˡ → 得梯度
  • 1次前向传播 + 1次反向传播
  • 不管多少参数，代价都差不多
  • 复杂度：O(1)次前向+反向
  • 这才让深度网络训练成为可能！

🔑 核心洞见

反向传播利用动态规划思想：后层的误差δˡ⁺¹已经算好了，直接拿来算前层δˡ，重复利用中间结果，避免冗余计算。这和"从终点倒着走最短路径"是一个思路。

梯度消失与梯度爆炸

深度网络训练的经典难题

$$\delta^{[l]} = \left( W^{[l+1]} \right)^T \delta^{[l+1]} \odot g'(z^{[l]})$$
梯度反向传播时，要经过每层的\(W\)和\(g'\)连乘
📉

梯度消失 (Vanishing)

当|W|<1或g'<0.25（如sigmoid）时：

  • 梯度反向传播时指数级衰减
  • 靠近输入层的参数几乎不更新
  • 浅层学不到东西，等于网络变"浅"了
  • sigmoid/tanh是重灾区
💥

梯度爆炸 (Exploding)

当|W|>1时：

  • 梯度反向传播时指数级增大
  • 参数更新步长太大，loss变NaN
  • 训练不稳定，直接崩溃
  • RNN中特别常见

✅ 解决方案

① ReLU激活函数——正区间导数为1，不衰减
② 合理的权重初始化（Xavier/He初始化）
③ Batch Normalization——让每层输入分布稳定
④ 残差连接(ResNet)——梯度直接"抄近路"回传
⑤ 梯度裁剪(Gradient Clipping)——爆炸时直接截断

激活函数为什么必须有？

没有激活函数，再深的网络也只是"一层"

$$\displaystyle 如果没有激活函数（即g(x)=x，线性激活）： \ a³ = W³(W²(W¹x + b¹) + b²) + b³ \     = W³W²W¹x + W³W²b¹ + W³b² + b³ \     = W'x + b' \$$ 不管叠多少层，等价于一个单层线性变换！多层的意义完全丧失。这就是为什么必须用非线性激活函数。

🎯 激活函数的核心使命

引入非线性，让神经网络能够拟合任意复杂的函数（万能近似定理）。线性变换的复合还是线性，只有非线性才能让网络"层层抽象"，学到复杂的模式。

📐 好激活函数的性质

• 非线性——这是根本要求
• 连续可导（几乎处处）——才能反向传播
• 单调——保证损失函数是凸的（单峰）
• 计算简单——前向/反向都快
• 输出范围有限（可选，防止爆炸）或不饱和（好）

ReLU的"死亡神经元"问题

为什么负区间输出为0既是优点也是缺点？

✅ ReLU的优点（为什么是默认选择）

• 正区间梯度恒为1——不会梯度消失！
• 计算极快——就是一个max比较，没有exp
• 稀疏激活——约50%神经元输出0，类似生物大脑的稀疏编码，计算效率高
• 收敛速度快——比sigmoid/tanh快约6倍

❌ Dead ReLU问题

• 如果一个神经元的z<0，ReLU输出0
• 梯度也为0，这个神经元永远不会更新
• 它"死"了，不管什么输入都输出0
• 学习率太大时容易大面积"死亡"
• Leaky ReLU/PReLU/ELU就是为了解决这个问题

💡 实际经验

虽然有死亡神经元问题，ReLU仍然是绝大多数场景的首选。实际中死亡神经元比例不高，而且网络有冗余，死几个不影响大局。如果发现ReLU效果不好，可以尝试Leaky ReLU或GELU。Transformer架构统一用GELU（或Swish）。

输出层激活函数选择指南

不同任务用不同输出激活，千万别用错！

任务类型 输出层激活 输出范围 搭配损失函数 示例
二分类 Sigmoid (0,1) 概率 Binary Cross-Entropy (BCE) 垃圾邮件检测、是否患病
多分类 Softmax 各类别概率，和为1 Cross-Entropy (CE) MNIST手写数字(10类)、ImageNet(1000类)
多标签分类 Sigmoid（每个输出独立） 每个(0,1) BCE（每个输出独立算） 图片多标签（有猫+有狗+有树）
回归 不用/线性（恒等映射） (-∞,+∞) 或指定范围 MSE / MAE / Huber 房价预测、温度预测
回归(0-1范围) Sigmoid（缩放输出） (0,1) MSE / BCE 预测概率/比例

⚠️ PyTorch注意事项

nn.CrossEntropyLoss自带LogSoftmax，所以用CrossEntropyLoss时，输出层不要加Softmax！直接输出原始logits即可。加了反而会影响训练稳定性。

三种梯度下降变体对比

Batch GD、SGD、Mini-batch GD——用多少数据算梯度？

变体 每次用多少样本 梯度准确性 收敛速度 能否在线学习 GPU并行 实际使用
Batch GD 全部N个 最准确，无噪声 慢（每步要算全量） ❌ 内存不够 几乎不用
SGD 1个 噪声大，震荡 快（每步很快） ✅ ❌ 无法并行 很少用
Mini-batch GD 一小批(32/64/128/256) 较准确，小噪声 快（矩阵并行） ✅ ✅ GPU矩阵加速 标准选择！

🎯 为什么Mini-batch是王道？

① GPU并行：矩阵运算在GPU上并行效率极高，32~256个样本一起算不比1个慢多少
② 噪声有好处：小噪声帮助跳出局部最优/鞍点，有类似正则化的效果
③ 内存效率：不需要把全部数据加载进显存
④ 收敛稳定：比纯SGD震荡小，比Batch GD快

Epoch vs Iteration：别搞混了

初学者最容易混淆的两个概念

1

Epoch（轮）

完整遍历一遍整个训练集。比如有10000个样本，batch_size=100，那1个epoch = 100次iteration。

1

Iteration（步/迭代）

处理一个mini-batch，更新一次参数。每个iteration处理batch_size个样本。

N

Batch Size

每个mini-batch的样本数。常见32/64/128/256。
iterations/epoch = 总样本数 / batch_size

$$\displaystyle 例：10000样本，batch_size=100，训练50 epochs \ → 每个epoch有 10000/100 = 100 次 iterations \ → 总共 50 \times 100 = 5000 次参数更新$$

💡 Batch Size选择建议

• 32是好的默认起点（论文实验表明小batch泛化往往更好）
• 显存够可以用64/128/256，大batch训练更稳定但可能泛化略差
• 别用太大的batch（如1024+），可能需要配合更大的学习率和更精细的调参
• batch_size通常选2的幂次（32/64/128/256），GPU计算更高效

Momentum：积累"惯性"加速收敛

就像滚下山的球——有了惯性不会在峡谷两边震荡

$$\begin{aligned} v_t &= \beta \cdot v_{t-1} + (1-\beta) \cdot \nabla L_t \\ \theta_t &= \theta_{t-1} - \eta \cdot v_t \end{aligned}$$ \(v\)是速度（梯度的指数滑动平均），\(\beta\)通常取0.9。不是用当前梯度更新，而是用"累积的平均梯度"更新。

🎯 Momentum解决什么问题？

SGD在"峡谷"（一个方向陡、一个方向缓的区域）会左右震荡，前进缓慢。

Momentum的作用：
• 一致的方向梯度会积累加速
• 相反方向的梯度会相互抵消
• 结果：减少震荡，加速收敛！

🎾 物理直觉

想象一个球从山上滚下来：
• 纯SGD：每一步只看当前坡度，容易在沟里来回撞
• Momentum：球有惯性，会记住之前的方向，在一致方向上越滚越快，小的震荡会被惯性"抹平"

β=0.9大致意味着"平均最近10步左右的梯度"。

Adam为什么是"默认首选"？

Adaptive Moment Estimation——集大成的优化器

🔑 Adam的核心思想

Adam = Momentum（一阶矩） + RMSProp（二阶矩） + 偏差修正

• m（一阶矩）：梯度的滑动平均 → 处理梯度方向，类似Momentum加速
• v（二阶矩）：梯度平方的滑动平均 → 处理每个参数的学习率自适应
• m̂, v̂：偏差修正，解决初始m,v为0导致的偏向0问题
• θ更新：m̂/(√v̂+ε) → 方向由m̂决定，步长由v̂自适应调整

✅ 收敛快

通常比SGD快3-5倍，快速出结果，省时间。快速验证想法最重要。

✅ 自适应lr

每个参数有自己的学习率，稀疏特征大lr，频繁特征小lr，自动调整。

✅ 少调参

默认lr=0.001, β₁=0.9, β₂=0.999基本不用改，省心。

核心公式汇总（一）：前向传播

这些公式是神经网络的基础，要做到能默写

$$\displaystyle 单层前向传播 \ \ zˡ = Wˡ \cdot aˡ⁻¹ + bˡ   // 线性变换：权重乘输入加偏置 \ aˡ = g(zˡ)   // 非线性激活：g是激活函数$$
$$\displaystyle 常用损失函数 \ \ MSE（回归）：L = (1/2)||\hat{y} - y||² = (1/2) \sum (\hat{y}_i - y_i)² \ 交叉熵（多分类）：L = - \sum y_i log(\hat{y}_i) \ 二分类BCE：L = -[y \cdot log(\hat{y}) + (1-y) \cdot log(1-\hat{y})]$$

💡 维度小贴士

Wˡ的维度是 (nˡ, nˡ⁻¹)，bˡ是 (nˡ, 1)，zˡ和aˡ是 (nˡ, batch_size)
其中nˡ是第l层的神经元数。注意矩阵乘法的维度匹配！

核心公式汇总（二）：反向传播梯度

反向传播的四个核心公式——理解而非死记

$$\displaystyle 输出层误差 \delta ᴸ： \    \delta ᴸ = (aᴸ - y) ⊙ g'(zᴸ)   // 对MSE+输出激活；CrossEntropy+Softmax时直接是aᴸ-y \ \ 反向传播误差 \delta ˡ： \    \delta ˡ = (Wˡ⁺¹)ᵀ \cdot \delta ˡ⁺¹ ⊙ g'(zˡ)   // 后层误差乘以W转置，再乘当前层激活导数 \ \ 权重梯度 \partial L/ \partial Wˡ： \    \partial L/ \partial Wˡ = \delta ˡ \cdot (aˡ⁻¹)ᵀ   // 误差乘以前层激活的转置 \ \ 偏置梯度 \partial L/ \partial bˡ： \    \partial L/ \partial bˡ = \delta ˡ   // 偏置的梯度就是误差本身（对b的导数是1）$$

🔑 参数更新

Wˡ = Wˡ - η · ∂L/∂Wˡ
bˡ = bˡ - η · ∂L/∂bˡ

这就是（纯）梯度下降。Momentum/Adam只是把这里的梯度换成了更智能的v或m̂/v̂。

常见面试题（一）：基础概念

这些都是面试/考试中高频出现的问题

❓ Q1: 为什么神经网络需要激活函数？

A: 如果没有非线性激活函数，不管多少层的线性变换叠在一起，结果仍然是线性变换（W3(W2(W1x+b1)+b2)+b3 = Wx+b），等价于单层网络，无法拟合非线性函数，多层就失去了意义。激活函数引入非线性，让网络有了拟合任意复杂函数的能力（万能近似定理）。

❓ Q2: 什么是梯度消失？为什么会发生？

A: 梯度消失是指反向传播时，梯度经过多层连乘后指数级衰减，导致靠近输入层的参数几乎不更新，网络"变浅"。原因：①sigmoid/tanh的导数最大值只有0.25/1，多层连乘后指数级变小；②权重初始化太小。解决方案：用ReLU/GELU、BatchNorm、残差连接、合理初始化。

❓ Q3: ReLU相比Sigmoid有什么优势？Dead ReLU是什么？

A: ReLU优势：①正区间导数为1，缓解梯度消失；②计算极快（只需max比较）；③收敛速度快约6倍；④产生稀疏激活。Dead ReLU：当神经元的z值长期小于0，ReLU输出0、梯度也为0，该神经元永远不会更新，"死亡"了。Leaky ReLU/PReLU通过负区间给一个小斜率(α=0.01)缓解这个问题。

常见面试题（二）：优化与训练

优化器和训练技巧相关问题

❓ Q4: Adam优化器的原理是什么？和SGD比有什么优势？

A: Adam结合了Momentum（一阶矩：梯度的指数滑动平均，加速收敛、减少震荡）和RMSProp（二阶矩：梯度平方的指数滑动平均，自适应学习率），加上偏差修正处理初始值问题。优势：①收敛速度快；②自适应学习率，对稀疏梯度友好；③超参数少，默认参数(lr=0.001)通常就很好用，不用怎么调参。缺点是有时最终泛化精度可能略逊于精调的SGD+Momentum。

❓ Q5: 什么是Mini-batch Gradient Descent？为什么不用Batch GD或纯SGD？

A: Mini-batch每次用一小批样本（32~256个）计算梯度并更新参数，是实践中的标准选择。相比Batch GD（全量数据），它速度更快、内存效率高、有噪声帮助跳出局部最优；相比纯SGD（单样本），它能利用GPU并行计算矩阵运算，速度快得多且梯度更稳定。Batch GD太慢，SGD无法利用GPU并行且震荡太严重。

❓ Q6: 训练神经网络时，学习率太大会怎样？太小呢？

A: 学习率太大：参数更新步长过大，loss震荡不收敛甚至上升，严重时参数"飞出去"导致loss变NaN，训练崩溃；学习率太小：收敛极慢，训练时间很长，可能卡在局部最优/鞍点无法逃出，看似在学习但效率极低。学习率是最重要的超参数，通常需要通过实验（如学习率查找）找到合适的值，并配合学习率调度（Warmup+Cosine）。

常见面试题（三）：反向传播与原理

深入理解反向传播机制

❓ Q7: 请简述反向传播算法的过程

A: 反向传播是高效计算神经网络梯度的算法，基于链式法则：①前向传播：输入数据从输入层到输出层，计算并缓存每层的激活值aˡ；②计算输出层误差：δᴸ = (aᴸ-y)⊙g'(zᴸ)（MSE损失时）；③反向传播误差：从后往前逐层计算δˡ = (Wˡ⁺¹)ᵀδˡ⁺¹⊙g'(zˡ)；④计算梯度：∂L/∂Wˡ = δˡ(aˡ⁻¹)ᵀ，∂L/∂bˡ = δˡ。一次前向+一次反向即可算出所有参数的梯度，效率极高，是训练深度网络的核心。

❓ Q8: 为什么训练神经网络要对输入数据做归一化/标准化？

A: ①如果不同特征量级差异大（比如一个0-1，一个0-1000），损失函数的等高线会是很扁的椭圆，梯度下降震荡严重、收敛慢；归一化后等高线更接近圆形，梯度方向更直接指向最小值，收敛更快。②Sigmoid/Tanh在输入大时饱和（梯度接近0），归一化让输入落在激活函数的非饱和区域。③权重初始化也是假设输入是标准化的。实践中通常用StandardScaler（减均值除标准差）或MinMaxScaler（缩放到0-1）。

PyTorch自动微分：autograd

你不需要手动实现反向传播——PyTorch帮你做了

import torch # 创建需要求梯度的张量 x = torch.randn(3, requires_grad=True) w = torch.randn(3, requires_grad=True) b = torch.randn(1, requires_grad=True) # 前向传播：构建计算图 y_pred = torch.sum(w * x) + b # 线性变换 y_pred = torch.sigmoid(y_pred) # 激活函数 loss = (y_pred - 1.0)**2 # MSE损失（假设真实标签是1） # 反向传播：自动计算所有梯度！ loss.backward() # 查看梯度 print(w.grad) # ∂loss/∂w print(b.grad) # ∂loss/∂b print(x.grad) # ∂loss/∂x # 梯度更新（手动或用优化器） with torch.no_grad(): w -= 0.01 * w.grad b -= 0.01 * b.grad w.grad.zero_() # 清零梯度！重要！ b.grad.zero_()

⚠️ 注意事项

①每次backward()后梯度会累加，所以更新参数后要zero_grad()清零；②推理/评估时用with torch.no_grad()关闭梯度计算，省显存和计算；③PyTorch是动态图（Define-by-Run），每次前向传播都重新构建计算图，灵活方便。
