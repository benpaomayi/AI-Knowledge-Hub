RNN/LSTM为什么不够用？

在Transformer诞生之前，序列建模的困境

❌ 问题一：串行处理，无法并行

RNN必须一个词一个词依次处理：处理第t个词时，必须等第t-1个词处理完。这导致GPU强大的并行计算能力完全无法利用，训练速度极慢。

序列长度为n时，需要n步串行计算，时间复杂度O(n)

⚠️ 问题二：长距离依赖丢失

序列太长时，信息在逐步传递中逐渐丢失（梯度消失问题）。虽然LSTM/GRU用门控机制缓解了这个问题，但并没有从根本上解决。

第1个词和第100个词之间的信息传递路径长达100步！

Seq2Seq的瓶颈与GPU算力浪费

机器翻译等任务中，RNN架构的固有缺陷

🔒 Seq2Seq的信息瓶颈

传统Encoder-Decoder架构中，Encoder要把整个源序列压缩成一个固定长度的上下文向量（context vector），Decoder只能靠这个向量生成所有输出。

序列越长，信息压缩损失越严重——就像让你读完一本书后只用一句话复述全部内容。

⚡ GPU算力的浪费

GPU天生适合大规模并行计算（矩阵运算），但RNN的串行结构让GPU英雄无用武之地。

2017年时，GPU算力已经突飞猛进，但RNN架构无法利用这一红利——这是Transformer诞生的重要时代背景。

💡 核心矛盾

序列建模需要：捕捉长距离依赖 + 并行计算加速训练
RNN只能做到：部分捕捉长距离依赖，但完全无法并行

🎯 历史必然

2017年，Google团队在论文《Attention Is All You Need》中给出了答案：完全抛弃循环结构，只用Attention机制，既可以并行计算，又能直接建模任意距离的依赖关系！

Attention机制的诞生

Bahdanau Attention (2014) —— 注意力的起点

✨ Bahdanau Attention的核心思想

在解码每一个目标词时，不再只依赖固定的上下文向量，而是动态地"注意"源序列中最相关的部分。

比如翻译"我爱中国"为"I love China"时：
• 生成"I"时，注意力集中在"我"
• 生成"love"时，注意力集中在"爱"
• 生成"China"时，注意力集中在"中国"

$$\text{Attention}(Q, K, V) = \text{对} \ V \ \text{进行加权求和，权重来自} \ Q \ \text{和} \ K \ \text{的相似度}$$ Attention的本质就是加权求和：对于每个查询\(Q\)，计算它与所有键\(K\)的相似度作为权重，然后对所有值\(V\)进行加权求和。

Self-Attention自注意力机制

Transformer最核心的创新——序列内部互相"看"

💡 Self-Attention是什么？

在传统Attention中，Q来自Decoder，K/V来自Encoder。

而在Self-Attention中，Q、K、V都来自同一个序列！也就是说，序列中的每个位置，都可以直接"看到"序列中的其他所有位置，直接计算任意两个词之间的依赖关系。

✅ 核心优势1：O(1)长距离路径

RNN中两个距离为n的词需要n步才能传递信息；
Self-Attention中任意两个词的距离都是1——一步直达！

再也不用担心长距离依赖问题！

✅ 核心优势2：完全并行计算

所有位置的注意力计算可以同时进行，没有依赖关系；
完美适配GPU并行架构，训练速度提升数十倍！

这才是大模型能训练起来的关键！

Self-Attention计算步骤

一步步拆解Scaled Dot-Product Attention

步骤1：线性变换得到Q、K、V 对输入X分别乘以三个权重矩阵W_q, W_k, W_v，得到Q = X·W_q, K = X·W_k, V = X·W_v
↓
步骤2：计算注意力分数 Q和K做矩阵乘法（点积）：S = Q·K^T，得到每个Query对所有Key的相似度得分
↓
步骤3：缩放(Scaling) 除以√d_k（d_k是Key的维度），防止点积过大导致Softmax饱和
↓
步骤4：Softmax归一化 对缩放后的分数做Softmax，得到0-1之间的注意力权重，每行和为1
↓
步骤5：加权求和V 用注意力权重对V做加权求和，得到最终的输出Z

Scaled Dot-Product Attention公式

Transformer使用的注意力公式

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

📐 符号说明

• Q ∈ ℝn×dk：Query矩阵，n个查询
• K ∈ ℝm×dk：Key矩阵，m个键
• V ∈ ℝm×dv：Value矩阵，m个值
• dk：Key/Query的维度
• dv：Value的维度
• Self-Attention时n=m（同一序列长度）

🎯 直觉理解

Q·KT计算的是"相似度"：两个向量越相似（方向越一致），点积越大。

Softmax把分数变成概率分布（权重），权重越大代表越关注这个位置。

最后对V加权求和，就是把关注的信息聚合起来。

💡 为什么用点积？

点积是计算两个向量相似度最高效的方式——一次矩阵乘法就能算出所有位置对的相似度，GPU可以极快地完成。

为什么要缩放(Scaling)？

除以√dk不是随便选的，有深刻的数学原因

⚠️ 问题：dk大时点积方差过大

假设q和k的每个分量都是独立随机变量，均值为0，方差为1，那么它们的点积 q·k = Σ qiki 的均值为0，方差为dk！

当dk=64（原始论文取值）时，方差是64，标准差是8——点积值的幅度会很大。

❌ 后果：Softmax进入饱和区

点积值过大时，Softmax函数会进入"饱和区"：最大的值接近1，其他值接近0，梯度变得极小——梯度消失，模型训不动！

✅ 解决方案：除以√dk

缩放后，Q·KT/√dk的方差变回1，Softmax在一个舒适的区间工作，梯度保持稳定，训练顺利进行。

这是一个看似微小但至关重要的细节！

示例结果解读

注意力权重矩阵告诉我们什么？

$$\text{注意力权重矩阵} \ A = \text{softmax}(QK^\top/\sqrt{d_k}) = \begin{bmatrix} 0.42 & 0.06 & 0.52 \\ 0.02 & 0.84 & 0.14 \\ 0.16 & 0.47 & 0.37 \end{bmatrix}$$ \(A[i][j]\) 表示：生成第\(i\)个位置的输出时，对第\(j\)个位置的关注度（权重）。每行和为\(1\)。

词1的注意力

[0.42, 0.06, 0.52]

词1最关注词3(0.52)，其次是自己(0.42)，不太关注词2。

词2的注意力

[0.02, 0.84, 0.14]

词2主要关注自己(0.84)——因为它的向量模长较长，和自己最相似。

词3的注意力

[0.16, 0.47, 0.37]

词3最关注词2(0.47)，分配相对均匀——综合上下文信息。

🎯 关键点

注意力权重是学出来的，不是人工设计的！模型通过训练学会"该看哪里"。在真实语言中，"它"会指代前面出现的名词，动词会关注主语和宾语——这些关系都是模型自动学习的。

单组注意力不够？那就用多组，并行关注不同模式

Multi-Head Attention详解

多头注意力的完整公式和设计

$$\begin{aligned} \text{MultiHead}(Q,K,V) &= \text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O \\ \text{where} \quad \text{head}_i &= \text{Attention}(QW_i^Q, KW_i^K, VW_i^V) \end{aligned}$$ 每个头有自己独立的\(W_i^Q, W_i^K, W_i^V\)参数矩阵，学习不同的注意力模式。最后把所有头的输出拼接起来，再乘一个\(W^O\)做线性变换融合。

⚙️ 维度设计

原始Transformer配置：

• dmodel = 512（模型总维度）
• h = 8（注意力头数）
• dk = dv = dmodel/h = 64
• 每个头维度64，8头拼接后回到512维

BERT-base用12头，LLaMA用32/40头等

🎯 不同头学到什么？

通过可视化注意力权重，研究人员发现：

• 有的头专注于语法关系（动词→主语/宾语）
• 有的头专注于指代关系（代词→名词）
• 有的头专注于相邻词（类似局部窗口）
• 有的头捕捉语义相似性

多头让模型同时从多个"视角"理解序列！

位置编码 Positional Encoding

Attention本身对位置不敏感——必须注入位置信息

⚠️ 问题：Self-Attention是排列等变的

如果打乱输入词的顺序，Self-Attention的输出也只是同样打乱顺序——它完全不知道词的位置信息！

但语言是有序的："我打你"和"你打我"用词完全一样，但意思完全相反。

必须显式地给模型注入位置信息！

✅ 解决方案：Positional Encoding

给每个位置pos生成一个位置向量PEpos，和词嵌入向量直接相加，作为输入：
输入向量 = 词嵌入(Word Embedding) + 位置编码(Positional Encoding)

🤔 为什么是相加而不是拼接？

相加可以保持dmodel维度不变，而且模型可以通过线性变换分离出内容和位置信息。拼接会增加维度，增加参数量。

正弦/余弦位置编码

原始Transformer使用的位置编码公式

$$PE_{(pos,2i)} = \sin\!\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right),\quad PE_{(pos,2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)$$ \(pos\)是词的位置（\(0,1,2,\dots\)），\(i\)是维度索引。偶数维度用\(\sin\)，奇数维度用\(\cos\)。不同维度\(i\)使用不同频率的正弦/余弦函数。

📐 为什么用正弦余弦？

可以外推到更长序列！

因为sin(pos+k)和cos(pos+k)可以表示为sin(pos)和cos(pos)的线性组合——这意味着模型可以很容易地学习到相对位置关系。

即使测试时遇到比训练时更长的序列，位置编码也能工作。

🔄 现代位置编码改进

正弦位置编码不是唯一选择：

• 可学习位置编码（BERT）：直接学一个位置嵌入表，简单但不能外推
• RoPE旋转位置编码（LLaMA/GPT-NeoX）：通过旋转矩阵注入位置，目前大模型主流
• ALiBi（BLOOM）：不用位置编码，直接在Attention分数上加位置偏置

Encoder的Self-Attention特点

双向注意力——每个位置都能看到所有位置

✅ Encoder是双向的

Encoder中的Self-Attention没有任何掩码限制——每个位置都可以attend到所有位置（包括自己），包括"未来"的位置。

比如处理句子"The animal didn't cross the street because it was too tired"中的"it"时，Encoder可以同时看到前面的"animal"和后面的"tired"，从而正确判断"it"指代"animal"。

这就是为什么BERT（Encoder-only）擅长理解类任务！

🔍

双向注意力的优势

能看到整个句子的上下文，理解更充分。适合需要"理解"的任务：

• 文本分类（情感分析）
• 命名实体识别(NER)
• 阅读理解/问答
• 指代消解

📤

Encoder输出是什么？

Encoder输出一个序列的向量：每个输入位置对应一个上下文化的向量表示(contextualized representation)。

这些向量融合了整个序列的上下文信息，包含丰富的语义——会被传给Decoder的Cross-Attention层使用。

Feed-Forward Network (FFN)

每个位置独立的全连接网络——非线性变换

$$\text{FFN}(x) = W_2 \cdot \text{ReLU}(W_1 \cdot x + b_1) + b_2$$ 就是两个线性层，中间夹一个\(\text{ReLU}\)激活函数。注意：FFN是位置独立的——每个位置的向量单独过同一个FFN，互相不交互。

📐 维度设计

原始Transformer配置：

• dmodel = 512（输入/输出维度）
• dff = 2048（隐层维度）= 4 × dmodel

先升维到4倍，再降维回来——中间有足够的容量进行非线性变换。

现代大模型d_ff更大，如LLaMA-7B用4*4096=16384，还会用SwiGLU替代ReLU。

💡 FFN的作用是什么？

Attention层负责信息交互/聚合（不同位置之间通信）；

FFN负责非线性变换/特征提取（每个位置单独做复杂的非线性映射，增加模型表达能力）。

可以理解为：Attention是"看哪里"，FFN是"看到之后怎么加工处理"。两者交替堆叠，非常强大。

Masked Self-Attention（掩码自注意力）

Decoder最关键的设计：不能看未来！

🚫 为什么需要掩码？

Decoder是自回归生成：生成第t个词时，只能用1到t-1已经生成的词，不能偷看未来还没生成的词！

比如翻译"我爱中国"，生成"I"时只能看<bos>；生成"love"时能看<bos> "I"；但绝对不能提前看到后面的"China"——否则就是作弊，训练和推理不一致。

$$\text{掩码矩阵} \ M \ \text{（上三角为} -\infty\text{）：} \quad M = \begin{bmatrix} 0 & -\infty & -\infty & -\infty \\ 0 & 0 & -\infty & -\infty \\ 0 & 0 & 0 & -\infty \\ 0 & 0 & 0 & 0 \end{bmatrix}$$ $$\text{加到} \ QK^\top/\sqrt{d_k} \ \text{上，Softmax后} -\infty \ \text{位置权重为} \ 0$$

Mask机制可视化

一个简单例子直观理解

📝 例子：生成句子 "I love China"

生成顺序：<bos> → I → love → China → <eos>

生成"I"时： 输入只有[<bos>] → 只能看<bos>
生成"love"时： 输入是[<bos>, I] → 能看<bos>, I，看不到后面的China
生成"China"时： 输入是[<bos>, I, love] → 能看这三个

🎯 本质：因果注意力(Causal Attention)

Masked Self-Attention也叫因果注意力，因为它遵循因果律：未来不能影响过去。

GPT系列模型就是只用Decoder（Decoder-only），所有注意力都是这种因果掩码——所以GPT能一个词一个词地生成连贯文本。

Cross-Attention交叉注意力

连接Encoder和Decoder的桥梁

🔗 Cross-Attention是什么？

在Cross-Attention层中：

• Q (Query) 来自Decoder：来自上一层（Masked Self-Attention）的输出，代表"我现在需要什么信息"
• K (Key) 和 V (Value) 来自Encoder的最终输出：代表输入序列的所有信息

这让Decoder在生成每个词时，都能去"查"Encoder输出，关注输入序列中相关的部分。

🌍

机器翻译例子

源语言(中文)："我爱中国"

Encoder处理后输出每个中文词的向量。

Decoder生成：
• "I"时，Cross-Attention关注"我"
• "love"时，关注"爱"
• "China"时，关注"中国"

💡

三种Attention对比

Masked Self-Attn：Q/K/V都来自Decoder，有掩码

Cross-Attn：Q来自Decoder，K/V来自Encoder

Encoder Self-Attn：Q/K/V都来自Encoder，无掩码

Add & Norm：残差连接 + 层归一化

每个子层都有的两个关键技术

$$\text{LN}(x + \text{Sublayer}(x))$$ 每个子层的输出是：先做残差连接（把输入\(x\)加到子层输出\(\text{Sublayer}(x)\)上），然后做\(\text{LayerNorm}\)。这叫Pre-Norm结构。

🔗 残差连接(Residual Connection)

来自ResNet（2015年何恺明）的核心思想：学习残差映射，而不是直接学习目标映射。

核心作用：
• 解决深度网络退化问题
• 梯度可以直接"直通"，缓解梯度消失
• 让训练极深的网络成为可能

Transformer有几十甚至上百层，全靠残差连接。

📊 LayerNorm层归一化

对每个样本单独做归一化：把每个向量归一化到均值0、方差1，再加上可学习的缩放γ和平移β。

LayerNorm vs BatchNorm：
• BatchNorm：按batch维度归一化，适合CV，依赖batch大小
• LayerNorm：按样本/序列位置归一化，适合NLP/序列，不依赖batch

归一化让训练更稳定，加速收敛。

Transformer训练过程

怎么训练这个模型？Teacher Forcing是关键

📚 训练数据

训练数据是平行语料：源序列 → 目标序列对。比如机器翻译的(中文句子, 英文句子)对。

👨‍🏫 Teacher Forcing（教师强制）

训练时，Decoder的输入不是模型自己上一步生成的词（那样推理慢还容易跑偏），而是直接用真实标签（ground truth）。

比如目标是"I love China"，Decoder输入是：<bos>, "I", "love", "China"（注意右移一位，shifted right），而不是把上一步的预测喂回来。

好处：可以并行计算所有位置！不需要等t-1生成完再算t，训练速度大大加快。

⚠️ 训练-推理差异：Exposure Bias

训练时喂真实词，推理时喂自己生成的词——这会有分布差异（暴露偏差）。但实践中Teacher Forcing效果很好，是标准做法。可以用Scheduled Sampling等方法缓解，但不常用。

优化器、损失函数与正则化

Transformer训练的具体细节

📉 损失函数

Cross-Entropy交叉熵损失

每个位置都预测下一个词，计算每个位置的交叉熵损失，然后平均。

目标是让正确词的概率尽可能大。

⚡ 优化器与学习率

Adam优化器（β₁=0.9, β₂=0.98, ε=10⁻⁹）

特殊的学习率调度：Warmup——先线性增加学习率，再按步数平方根倒数衰减。

warmup_steps=4000

🛡️ 正则化

• Dropout：p=0.1，用在每个子层输出、嵌入+位置编码相加后

• Label Smoothing（标签平滑）：ε=0.1，把真实标签概率从1改成0.9，其他词平分0.1，防止模型过于自信，提升泛化能力。

$$\text{lrate} = d_{\text{model}}^{-0.5} \cdot \min\!\left(\text{step}^{-0.5},\ \text{step} \cdot \text{warmup\_steps}^{-1.5}\right)$$ Warmup学习率：训练初期学习率从小到大热身（warmup），避免一开始参数随机时梯度过大导致不稳定；然后再慢慢衰减。

Scaled Dot-Product Attention

def attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2,-1) / sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask==0, -1e9)
    attn_weights = softmax(scores, dim=-1)
    return attn_weights @ V

class EncoderLayer(nn.Module):
    def __init__(self, d_model, h, d_ff):
        self.attn = MultiHeadAttention(d_model, h)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.ReLU(),
            nn.Linear(d_ff, d_model))
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
    def forward(self, x, mask=None):
        x = self.norm1(x + self.attn(x,x,x,mask))
        x = self.norm2(x + self.ffn(x))
        return x

Transformer专题 · 术语

重要术语表

Transformer领域的核心概念术语

🔍 Query, Key, Value (QKV)

注意力机制的三个核心输入：查询(你要找什么)、键(用什么匹配)、值(实际提取什么内容)。

🔗 Self-Attention 自注意力

Q/K/V来自同一序列的注意力，让序列内部元素直接交互。

🔀 Cross-Attention 交叉注意力

Q来自一个序列，K/V来自另一个序列的注意力，连接Encoder和Decoder。

🎯 Multi-Head Attention 多头注意力

并行运行多组独立注意力，每组学习不同模式，最后拼接融合。

📍 Positional Encoding 位置编码

给输入嵌入添加位置信息的方法，因为Attention本身对位置不敏感。

🚫 Masked Attention 掩码注意力

用mask阻止某些位置参与注意力计算（如Decoder中屏蔽未来位置）。

🔄 Autoregressive generation 自回归生成

生成时逐个词生成，每一步把已生成的词加入输入，生成下一个词。

👨‍🏫 Teacher Forcing 教师强制

训练时用真实标签作为下一步输入，而非模型生成结果，加速并行训练。

总结

Transformer核心要点回顾

💡 核心创新

Transformer用Self-Attention彻底抛弃了循环结构，解决了RNN的两大痛点：无法并行计算和长距离依赖丢失。任意两个位置距离为1，完全并行。

🧩 关键组件

• Scaled Dot-Product Attention：高效相似度计算
• Multi-Head Attention：多模式信息提取
• Positional Encoding：注入位置信息
• Residual + LayerNorm：稳定深度网络训练
• Masked Attention：自回归生成的关键

🏗️ Encoder-Decoder架构

Encoder（双向注意力）负责理解，Decoder（因果+交叉注意力）负责生成。这一架构既可以做理解任务，也可以做生成任务。

🚀 历史意义

2017年的Transformer是现代AI的基石架构——从BERT、GPT、ViT到ChatGPT、LLaMA、Sora，所有革命性的AI成果都建立在Transformer之上。

它不仅是一个模型，更是一种通用的信息建模范式。

🎯 最后一句话

Attention Is All You Need——你不需要RNN，不需要CNN，只要注意力机制就够了。这个在2017年看起来大胆的标题，已经被过去7年的AI发展反复验证。
