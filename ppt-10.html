决策树的结构

一棵树由三类节点组成

🌳

根节点 (Root Node)

树最顶端的节点，包含所有样本。第一个判断条件从这里开始。

例：天气如何？

🔀

内部节点 (Internal Node)

也叫判断节点，代表一个特征的判断条件。每个内部节点有两个或多个分支。

例：湿度 > 70%？风大吗？

🍃

叶子节点 (Leaf Node)

树最末端的节点，不再分裂，代表最终的预测结果（类别或数值）。

例：出去玩 / 不出去玩

🌲 树模型家族

决策树是很多强大算法的基础：随机森林（Random Forest）、GBDT、XGBoost、LightGBM……这些集成模型本质上都是"很多棵决策树"组合在一起。理解决策树，是理解这些高级算法的前提。

衡量纯度指标一：信息熵

Entropy——来自信息论，衡量不确定性/混乱程度

$$H(S) = - \sum_{i=1}^{k} p_i \cdot \log_2(p_i)$$ 符号解释：
• \(S\)：当前节点的样本集合
• \(k\)：类别数量（比如二分类 \(k=2\)）
• \(p_i\)：第 \(i\) 类样本在集合 \(S\) 中所占的比例
• \(\log\) 通常以 2 为底（单位是比特 bit）

🎯 熵越小越纯

• 集合完全纯净（只有一类）：H = 0
• 集合完全混乱（各类均匀分布）：H 最大
• 二分类时：H = -p·log(p) - (1-p)·log(1-p)

⚠️ 注意：p=0时怎么办？

数学上规定：0 · log(0) = 0。因为某一类样本一个都没有时，它不贡献任何不确定性。

信息熵公式详解

用具体数值感受熵的变化

$$\displaystyle H(S) = -p \cdot log_{2}(p) - (1-p) \cdot log_{2}(1-p)$$ 二分类情况下，p 是正类比例，1-p 是负类比例
场景 正类比例 p 负类比例 1-p 信息熵 H(S) 含义
全是正类 1.0 0.0 0 完全纯净，没有不确定性
大部分正类 0.9 0.1 0.47 比较纯，不确定性低
一半一半 0.5 0.5 1.0 完全混乱，不确定性最大
大部分负类 0.1 0.9 0.47 比较纯，不确定性低
全是负类 0.0 1.0 0 完全纯净，没有不确定性

📊 熵的形状

二分类的熵是一个开口向下的抛物线（拱形）：p=0 或 p=1 时熵为0（最纯），p=0.5 时熵最大（最混乱）。记住这个直觉就够了！

信息熵的含义

熵 = 不确定性 = 混乱程度 = "惊喜度"

🎯

H = 0（最纯）

盒子里全是红球，闭着眼摸一定是红球。没有任何不确定性，不需要任何信息就能猜中结果。

🎲

H = 1（最混乱）

盒子里红球蓝球各一半，摸之前完全猜不准。不确定性最大，需要最多的信息才能确定结果。

📊

H 在中间

9红1蓝，大概率摸到红球，但也有小概率蓝球。有一定不确定性，熵值介于0和1之间。

🧠 生活中的"熵"

• 明天太阳从东边升起？这是确定事件，熵=0
• 掷硬币猜正反？完全随机，熵最大
• 说明天会不会下雨？有一定概率但不确定，熵在中间
决策树分裂的目标：让熵从大变到小！

信息增益 (Information Gain)

划分前的熵 - 划分后的加权平均熵 = 熵减少了多少

$$\text{Gain}(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} \cdot H(S_v)$$ 含义：用特征 A 对集合 S 进行划分后，不确定性"减少"了多少
• \(H(S)\)：划分前 \(S\) 的熵（父节点熵）
• \(S_v\)：特征 \(A\) 取值为 \(v\) 时对应的子集
• \(|S_v|/|S|\)：该子集的权重（样本数占比）
• 信息增益越大 → 划分效果越好！

🎯 选择最佳特征

对每个特征都算一下信息增益，选信息增益最大的那个特征作为当前节点的划分条件！这就是ID3算法的核心思想。

ID3算法：选信息增益最大的特征

Iterative Dichotomiser 3——最经典的决策树算法之一

1️⃣ 开始：所有样本在根节点
↓
2️⃣ 遍历所有特征：计算每个特征的信息增益
↓
3️⃣ 选最优：选信息增益最大的特征作为当前节点
↓
4️⃣ 分裂：按该特征的不同取值，将样本分到各个子节点
↓
5️⃣ 递归：对每个子节点重复步骤2-4，直到满足停止条件
↓
6️⃣ 停止条件：节点样本全属于同一类 / 没有更多特征 / 样本数太少

信息增益的问题：偏向取值多的特征

ID3用信息增益选特征，但它有一个明显的缺陷

⚠️ 问题场景

假设数据集中有一个"编号"特征（ID），每个样本的编号都不同（1, 2, 3, 4...）。

用"编号"来划分会发生什么？

每个子节点只有一个样本！熵为0！信息增益达到最大！

但这样的树有意义吗？完全没有！它相当于记住了每个样本，遇到新数据根本无法预测（过拟合了）。

❌ 信息增益的偏好

信息增益天然偏向取值数量多的特征。取值越多 → 划分后子集越小越纯 → 信息增益越大。但这不一定是真的有预测能力的特征。

✅ C4.5的改进：信息增益率

为了解决这个问题，Ross Quinlan（ID3的作者）在C4.5算法中提出了信息增益率（Gain Ratio），对取值多的特征加一个"惩罚项"。

C4.5改进：信息增益率

在信息增益基础上除以一个"分裂信息度"作为惩罚

$$\displaystyle GainRatio(S, A) = Gain(S, A) / IV(A)$$ 其中 IV(A) 是特征 A 的"固有值"（Intrinsic Value）：
IV(A) = -Σv (|Sv|/|S|) · log2(|Sv|/|S|)

• IV 本质上是特征 A 本身的熵
• 特征取值越多 → IV 越大 → 惩罚越重
• 信息增益率克服了偏向多取值特征的问题！

✅ C4.5的优点

• 用信息增益率，减少对多取值特征的偏好
• 能处理连续值特征（离散化）
• 能处理缺失值
• 构造完成后可以剪枝

⚠️ C4.5的局限

• 只能做分类，不能做回归
• 是多叉树（不是二叉树）
• 计算熵涉及log运算，效率较低
• 实际中用得不如CART多

衡量纯度指标二：基尼系数

Gini Impurity——CART算法使用的指标，计算更快

$$\text{Gini}(S) = 1 - \sum_{i=1}^{k} p_i^2$$ 符号解释：
• \(p_i\)：第 \(i\) 类样本所占比例
• 基尼系数范围：\([0,\ 1-1/k]\)
• 基尼系数越小 → 越纯净！

🎯 基尼系数的直观含义

从集合 S 中随机抽取两个样本，这两个样本类别不一致的概率！

📊 数值例子（二分类）

• 全是一类（p=1）：Gini = 1 - 1² = 0（最纯）
• 一半一半（p=0.5）：Gini = 1 - 0.5² - 0.5² = 0.5（最混乱）

⚡ 为什么用基尼系数？

• 不用算log，只有平方和加法，计算速度更快
• 和熵的曲线形状非常相似（都是0到最大再到0）
• 实际效果和用熵差不多，但效率更高
• sklearn默认使用基尼系数！

基尼系数公式详解

用具体数值感受基尼系数的变化

$$\displaystyle Gini(S) = 1 - [p_1² + p_2² + ... + p_{k}²]$$ 二分类时简化为：Gini(S) = 1 - p² - (1-p)² = 2p(1-p)
场景 正类比例 p 负类比例 1-p 基尼系数 Gini(S) 含义
全是正类 1.0 0.0 0 完全纯净，抽两个一定同类
大部分正类 0.9 0.1 0.18 很纯，抽两个不同类概率低
一半一半 0.5 0.5 0.5 最混乱，抽两个不同类概率50%
大部分负类 0.1 0.9 0.18 很纯，抽两个不同类概率低
全是负类 0.0 1.0 0 完全纯净，抽两个一定同类

📈 基尼 vs 熵

基尼系数曲线 Gini = 2p(1-p) 是抛物线，熵是拱形的对数曲线。两者形状非常接近，实际使用中效果差异不大——但基尼不用算log，计算更快，这是sklearn默认用基尼的原因。

基尼系数的概率含义

随机抽两个样本，类别不一致的概率

假设一个盒子里有10个球：7个红球，3个蓝球。

🔴 第一次抽
抽到红球概率 0.7
×
🔵 第二次抽
抽到蓝球概率 3/9
+
🔵 第一次抽
抽到蓝球概率 0.3
×
🔴 第二次抽
抽到红球概率 7/9

🧮 简化计算（有放回抽样）

P(不同类) = P(红)·P(蓝) + P(蓝)·P(红) = 2·p红·p蓝 = 2 × 0.7 × 0.3 = 0.42

用基尼公式：Gini = 1 - 0.7² - 0.3² = 1 - 0.49 - 0.09 = 0.42

完全一致！基尼系数就是在衡量"乱不乱"——越乱，随便抓两个不一样的概率越大。

CART算法

Classification and Regression Tree——目前最常用的决策树

🌲

二叉树

CART永远是二叉树——每次分裂只分成两个子节点（是/否），不像ID3可以多叉。这简化了树结构，也让递归更高效。

🏷️📈

分类+回归

名字就说了——既能做分类（用基尼系数），也能做回归（用均方误差MSE）。一个算法两种用途！

⚡

基尼系数

分类任务默认使用基尼系数选择最佳划分，不用算log，计算速度比信息熵快。

🏆 为什么CART最常用？

• sklearn中的 DecisionTreeClassifier/DecisionTreeRegressor 就是CART实现
• 它是更高级集成模型（随机森林、GBDT、XGBoost）的基础
• 二叉树结构 + 基尼系数 = 高效且效果好
• 既支持分类又支持回归，实用性强

CART特点总结

二叉树、分类回归都能做、用基尼系数

CART构建树的过程和ID3类似，但有几个关键区别：

🌳 永远二叉分裂：无论特征有多少个取值，CART每次都只问"是/否"，分成两个子集
📊 连续值处理：对连续特征，遍历所有可能的划分点，选基尼增益最大的阈值
📐 回归树：回归任务不用基尼系数，用均方误差(MSE)来选最佳划分点
✂️ 自带剪枝：CART训练完后可以用"代价复杂度剪枝"进行后剪枝

⚠️ 注意：特征可以重复使用

CART中同一个特征可以在不同层级被多次使用（比如"年龄>30?"→"年龄>50?"），因为每次分裂都是独立的判断。

决策树的过拟合问题

如果不加限制，树会一直长到每个叶子只有一个样本

🌳 不限制深度的树

🌳 → 🌲 → 🌴 → 🎋

树会不断分裂，直到：

  • 每个叶子节点的样本都属于同一类
  • 或者没有更多特征可以用了
  • 极端情况：每个叶子只有1个样本

结果：训练集100%正确，测试集一塌糊涂！

🤔 为什么会过拟合？

决策树的表达能力太强了！它可以把训练数据的所有细节（包括噪声）都学进去。

想象你在画一条分类边界：

  • 深度为1的树（决策树桩）：一条直线，很简单
  • 深度为5的树：折线，比较复杂
  • 深度为20的树：锯齿状，把噪声都拟合了！

树越深 → 模型越复杂 → 越容易过拟合

  • 提前设置停止条件

  • sklearn主要靠这个

Post-pruning

  • 先建一棵完整的树

  • 效果略好但训练慢

🎯 剪枝的本质

用一点点偏差（Bias）换取方差（Variance）的大幅下降，也就是奥卡姆剃刀原则——如无必要，勿增实体。简单的模型往往泛化能力更好。

预剪枝（最常用）：训练时限制

通过设置参数提前停止树的生长——简单直接

📏

max_depth
最大深度

最重要的参数！

限制树的最大层数。值越小模型越简单，越不容易过拟合。

常用值：3~10 之间

默认 None（不限制）

🔢

min_samples_split
最小划分样本数

一个节点至少要有多少样本才允许继续分裂。

样本少于这个数就不再分裂，直接成为叶子。

常用值：2~20

默认 2

🍃

min_samples_leaf
叶节点最小样本数

叶子节点至少要有多少个样本。

分裂后如果某个子节点样本数少于这个值，这次分裂就不做。

常用值：1~10

默认 1

⚙️ 参数调优

这几个参数是决策树调参的核心！实际中最常调整的是 max_depth，通过交叉验证选一个最优值，一般就能显著降低过拟合。

后剪枝：先建完整树再裁剪

先生成一棵完整的树，再自底向上检查哪些分支可以去掉

1️⃣ 生成完整树：不做任何限制，让树自由生长到最大（每个叶子纯净或无法再分）
↓
2️⃣ 自底向上遍历：从最底层的内部节点开始，逐个考察
↓
3️⃣ 尝试剪枝：把当前节点的子树去掉，让它变成一个叶子节点
↓
4️⃣ 验证比较：用验证集比较剪枝前后的性能，如果性能提升（或不下降），就保留这次剪枝
↓
5️⃣ 重复直到根节点：继续往上检查，直到不能再剪为止

📊 CCP剪枝（代价复杂度剪枝）

CART用的叫CCP（Cost Complexity Pruning），给树的复杂度加一个惩罚项 α。α=0是完整树，α越大剪得越狠。sklearn中通过 ccp_alpha 参数控制。

决策树优缺点总结

没有万能的算法，只有适合场景的算法

✅ 优点

  • 可解释性极强——模型可以可视化，决策过程完全透明，像人在做判断
  • 无需特征缩放——不需要归一化/标准化，对特征尺度不敏感
  • 能处理类别特征——不需要独热编码（sklearn需额外处理，但原理上支持）
  • 能捕捉非线性关系——不像线性模型只能画直线
  • 对异常值鲁棒——单个异常点不容易影响整体结构
  • 预测速度快——预测时只需要走几条判断，O(log n) 时间

❌ 缺点

  • 容易过拟合——不加限制的话很容易把噪声都学进去
  • 不稳定——数据稍微变一点，树结构可能完全变了（高方差）
  • 容易偏向多值特征——ID3的问题，CART用基尼系数缓解
  • 不擅长处理不平衡数据——类别数多的类别会主导划分
  • 单棵树准确率有限——通常不如集成模型（随机森林等）

💡 实际应用建议

需要可解释性的场景（金融风控、医疗诊断）→ 决策树很好；追求准确率 → 用基于决策树的集成模型（随机森林、XGBoost、LightGBM），它们在工业界更常用。

sklearn使用决策树代码示例

用经典的鸢尾花数据集训练一棵决策树

# 导入需要的库 from sklearn.datasets import load_iris from sklearn.tree import DecisionTreeClassifier from sklearn.model_selection import train_test_split from sklearn.metrics import accuracy_score # 1. 加载数据 iris = load_iris() X, y = iris.data, iris.target # 2. 划分训练集和测试集 X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.3, random_state=42 ) # 3. 创建决策树分类器（CART算法） clf = DecisionTreeClassifier( criterion='gini', # 'gini'（基尼系数，默认）或 'entropy'（信息熵） max_depth=3, # 限制最大深度，防止过拟合 min_samples_split=5, # 最小划分样本数 min_samples_leaf=2, # 叶子节点最小样本数 random_state=42 ) # 4. 训练模型 clf.fit(X_train, y_train) # 5. 预测和评估 y_pred = clf.predict(X_test) print(f"准确率: {accuracy_score(y_test, y_pred):.2f}") # 输出：准确率: 1.00（鸢尾花数据集很简单）

本集小结

恭喜你完成了第10集！回顾一下核心要点

🌳 决策树本质

层层嵌套的 if...else 判断，从根节点走到叶子节点就是预测过程，既可以分类也可以回归。

📐 两个纯度指标

信息熵 H(S) = -Σpᵢ·log(pᵢ)：衡量不确定性，越纯熵越小；基尼系数 Gini(S) = 1-Σpᵢ²：随机抽两个样本不同类的概率，计算更快。

⚙️ 三种经典算法

ID3（信息增益、多叉树、仅分类）→ C4.5（信息增益率、改进多值偏向）→ CART（基尼系数、二叉树、分类+回归，sklearn默认，最常用）。

✂️ 防止过拟合：剪枝

预剪枝（最常用）：通过 max_depth、min_samples_split、min_samples_leaf 限制树生长；后剪枝：先建完整树再裁剪。

💡 优缺点

优点：可解释强、无需特征缩放、能处理非线性；缺点：容易过拟合、不稳定、单棵树准确率有限。
