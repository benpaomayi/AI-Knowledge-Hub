Tensor：PyTorch的基础数据结构

Tensor就是多维数组——numpy数组的GPU加速版

import torch

# 创建Tensor（和numpy很像）
x = torch.tensor([1.0, 2.0, 3.0]) # 1D张量，类似向量
x = torch.randn(3, 4) # 2D张量 3×4，随机正态分布
x = torch.zeros(2, 3, 4) # 3D张量 2×3×4，全0

# Tensor的常用属性
x.shape # 形状: torch.Size([2, 3, 4])
x.dtype # 数据类型: torch.float32
x.device # 设备: cpu 或 cuda:0

# Tensor运算（和numpy几乎一致）
y = x + 1 # 逐元素加
y = torch.matmul(a, b) # 矩阵乘法
y = x.view(2, 12) # 改变形状（类似reshape）
y = x.flatten() # 展平成1D

💡 Tensor和Numpy数组的区别

Tensor可以放在GPU上加速计算（用.to(device)），最重要的是：Tensor支持自动微分（requires_grad=True时，PyTorch会自动追踪计算历史，用于反向传播）。

自动微分 Autograd：PyTorch的灵魂

自动求导——你只需要写前向传播，反向传播交给框架

import torch

# 创建需要求梯度的张量
w = torch.tensor([2.0], requires_grad=True)
b = torch.tensor([1.0], requires_grad=True)

# 前向传播：构建计算图
x = torch.tensor([3.0])
y = w * x + b # 预测值 = 2×3+1 = 7
loss = (y - 10)**2 # MSE损失：(7-10)² = 9

# 反向传播：自动计算所有梯度！
loss.backward()

# 查看梯度 ∂loss/∂w 和 ∂loss/∂b
print(w.grad) # tensor([-18.])，即2×(7-10)×3 = -18
print(b.grad) # tensor([-6.])，即2×(7-10)×1 = -6

✅ 这就是深度学习框架的核心价值

你不需要手动推导复杂的梯度公式，不需要手动实现反向传播——只要把前向传播写对了，调用loss.backward()，PyTorch自动帮你算好所有参数的梯度！

DataLoader：高效批量加载数据

DataLoader帮你自动处理batching、shuffling、并行加载

📦

Batching

自动把单个样本打包成batch，不用手动拼接。一个batch是shape为[batch_size, 1, 28, 28]的Tensor。

🔀

Shuffling

每个epoch开始前打乱数据顺序，防止模型记住样本顺序，提高泛化能力。train=True时开shuffle。

⚡

并行加载

num_workers参数开启多进程预加载数据，GPU训练时CPU同时准备下一批数据，减少等待时间。

from torch.utils.data import DataLoader

train_loader = DataLoader(
    train_dataset,
    batch_size=64, # 每个batch 64张图片
    shuffle=True, # 训练时打乱顺序
    num_workers=2 # 2个进程并行加载
)

test_loader = DataLoader(
    test_dataset,
    batch_size=1000, # 测试可以用更大batch
    shuffle=False # 测试不需要打乱
)

数据预处理 transforms

在数据进入模型之前，对其做必要的变换

transform操作 作用 什么时候用
transforms.ToTensor() 把PIL图片/numpy数组转成Tensor，并把像素值从0-255缩放到0-1 几乎必用，PyTorch模型要求Tensor输入
transforms.Normalize(mean, std) 标准化：(x-mean)/std，让数据均值为0、标准差为1 推荐使用，让训练更稳定收敛更快。MNIST的mean=0.1307, std=0.3081
transforms.RandomHorizontalFlip() 随机水平翻转（数据增强） 训练时用，增加数据多样性，防过拟合（MNIST数字别用，6和9翻了就错了）
transforms.RandomCrop() 随机裁剪（数据增强） 训练时用，增加数据多样性
transforms.Compose([...]) 把多个变换串起来按顺序执行 需要做多个预处理时使用

⚠️ MNIST数据增强注意

MNIST是手写数字，不能随便翻转！垂直翻转会让9变成6、6变成9，水平翻转很多数字就不是数字了。对于MNIST做Normalize就够了，彩色图片分类（如CIFAR10）再用更多数据增强。

nn.Module：定义神经网络的标准方式

所有自定义网络都要继承nn.Module，实现两个方法

import torch.nn as nn
import torch.nn.functional as F

class SimpleMLP(nn.Module):
    def __init__(self):
        super().__init__() # 必须调用父类构造函数
        # 在__init__里定义需要学习参数的层（Linear、Conv等）
        self.flatten = nn.Flatten() # 展平：28×28 → 784
        self.fc1 = nn.Linear(784, 256) # 全连接层1: 784→256
        self.fc2 = nn.Linear(256, 128) # 全连接层2: 256→128
        self.fc3 = nn.Linear(128, 10) # 输出层: 128→10（10个类别）

    def forward(self, x):
        # forward定义前向传播：数据如何流过网络
        x = self.flatten(x)
        x = F.relu(self.fc1(x)) # 线性层后接ReLU激活
        x = F.relu(self.fc2(x))
        x = self.fc3(x) # 最后一层不要加Softmax！CrossEntropyLoss内置了
        return x

# 创建模型实例
model = SimpleMLP()

🔑 nn.Module的魔法

只要你把层定义在__init__里（用self.xxx = ），PyTorch会自动追踪所有可训练参数，model.parameters()能拿到所有需要优化的参数，不用手动管理！

我们的MLP网络结构

简单但有效的多层感知机，MLP=全连接层+激活函数

📥 输入：28×28 灰度图 → Flatten → 784维向量
↓
🔵 Linear(784, 256) + ReLU
↓
🔵 Linear(256, 128) + ReLU
↓
📤 输出：Linear(128, 10) → 10个类别的logits
🔢

参数量

784×256 + 256 + 256×128 + 128 + 128×10 + 10 ≈ 23.5万参数，非常小的网络。

⚡

为什么用ReLU？

ReLU(x)=max(0,x)，计算快、梯度不饱和、缓解梯度消失问题，是隐藏层激活函数的首选。

⚠️

不要加Softmax！

最后一层直接输出logits，因为nn.CrossEntropyLoss内置了LogSoftmax，重复加效果会变差。

训练循环五要素

记住这五步，就记住了所有深度学习训练的核心

① 遍历Epoch for epoch in range(epochs): 一轮一轮遍历整个数据集
② 遍历Batch for data, target in train_loader: 一批一批取数据
③ 前向传播 output = model(data) 把数据喂给模型，得到预测结果
④ 计算Loss + 反向传播 loss = criterion(output, target); loss.backward() 算误差+自动求梯度
⑤ 优化器更新参数 optimizer.step(); optimizer.zero_grad() 更新参数+清空梯度

💡 核心中的核心

不管是MLP、CNN、Transformer还是大模型，训练循环永远是这五步！变的只是网络结构和数据，训练逻辑永远是：epoch→batch→前向→loss+反向→step。

model.train() vs model.eval()

训练和测试时模型"模式"不同，这是新手最容易忘的！

🔵 model.train() 训练模式

  • 训练开始前调用
  • Dropout：随机丢弃神经元（激活）
  • BatchNorm：用当前batch的均值/方差，并更新运行统计量
  • 需要计算梯度，更新参数
VS

🟢 model.eval() 评估模式

  • 测试/验证开始前调用
  • Dropout：关闭，所有神经元都用
  • BatchNorm：用训练时累计的运行均值/方差，不更新
  • 配合torch.no_grad()不计算梯度，省显存提速

⚠️ 非常重要！忘记切换模式的后果

测试时忘了调用model.eval()：Dropout会随机失活，BatchNorm用batch统计量，导致预测结果随机，准确率飘，模型看起来很"菜"。这是新手排名第一的坑！

训练代码：完整训练循环

把前面的组件串起来，开始训练！

epochs = 5
model.train() # 切换到训练模式

for epoch in range(epochs):
    running_loss = 0.0
    for batch_idx, (data, target) in enumerate(train_loader):
        data, target = data.to(device), target.to(device)

        optimizer.zero_grad() # ❶ 清零梯度（重要！不然梯度会累加）
        output = model(data) # ❷ 前向传播
        loss = criterion(output, target) # ❸ 计算损失
        loss.backward() # ❹ 反向传播，计算梯度
        optimizer.step() # ❺ 更新参数

        running_loss += loss.item()

    # 每个epoch结束打印一次
    avg_loss = running_loss / len(train_loader)
    print(f"Epoch {epoch+1}/{epochs}, Loss: {avg_loss:.4f}")

⚠️ optimizer.zero_grad()的位置

每个batch开始时调用，或者step()之后调用。如果忘记zero_grad()，梯度会累加（相当于batch size变大了），训练会异常——这是新手排名第二的坑！

测试评估：计算准确率

训练完要在测试集上评估泛化能力

model.eval() # 切换到评估模式！（Dropout/BN行为不同）
correct = 0
total = 0

# with torch.no_grad()：关闭梯度计算，省显存、速度快
with torch.no_grad():
    for data, target in test_loader:
        data, target = data.to(device), target.to(device)
        output = model(data) # 前向传播得到预测结果

        # output形状是[batch_size, 10]，取最大值的索引作为预测类别
        _, predicted = torch.max(output.data, dim=1)

        total += target.size(0)
        correct += (predicted == target).sum().item()

accuracy = 100 * correct / total
print(f"测试集准确率: {accuracy:.2f}%")

✅ torch.no_grad()别忘了

测试时不需要反向传播，不需要计算梯度，用no_grad()包裹可以大幅减少显存占用和计算量，速度更快。

📊 torch.max(output, dim=1)

output是[bs, 10]，dim=1是在10个类别维度上取最大值。返回（最大值，最大值索引），索引就是预测的类别0-9。

完整代码（二）：模型、训练、测试

定义网络→训练→评估，完整流程

# 4. 定义模型
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(784, 256)
        self.fc2 = nn.Linear(256, 128)
        self.fc3 = nn.Linear(128, 10)
    def forward(self, x):
        x = self.flatten(x)
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        return self.fc3(x)

model = MLP().to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=1e-3)

# 5. 训练！
model.train()
for epoch in range(5):
    for data, target in train_loader:
        data, target = data.to(device), target.to(device)
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()
    print(f"Epoch {epoch+1}完成")

常见错误排行榜

这些坑90%的新手都踩过，提前避坑！

排名 错误 现象 正确做法
🥇 #1 测试时忘记model.eval() 测试准确率低、结果不稳定、有随机性 测试前加model.eval()，训练前加model.train()
🥈 #2 忘记optimizer.zero_grad() Loss不收敛或训练异常，梯度会累加 每个batch前或step()后调用zero_grad()
🥉 #3 最后一层重复加Softmax 训练慢、效果差，相当于算了两次 用CrossEntropyLoss时网络最后直接输出logits
#4 数据和模型不在同一个device 报错：Expected all tensors to be on the same device model.to(device) 同时 data.to(device)
#5 维度不匹配 报错：mat1 and mat2 shapes cannot be multiplied 检查每层输入输出shape，注意Flatten
#6 标签传成one-hot 用CrossEntropyLoss时报维度错 CrossEntropyLoss要类别索引（0-9），不是one-hot

从MLP到CNN：图像任务的正确打开方式

全连接网络处理图片有局限，CNN才是CV的核心

📐

MLP的问题

把28×28图片展平成784维向量，丢失了空间结构信息：

  • 像素之间的位置关系（上下左右）被忽略了
  • 参数量大，容易过拟合
  • 图片稍微平移/旋转一点就认不出了
🖼️

CNN的优势

卷积层保留空间结构，局部连接+权值共享：

  • 提取边缘、纹理、形状等局部特征
  • 参数量少，平移等变
  • 是图像识别、目标检测等任务的基础

📚 进阶方向

本集先掌握MLP+完整训练流程，这是一切的基础。CNN（卷积神经网络）后续会讲，当你掌握了基本训练逻辑，换网络结构只是改__init__和forward的事情，训练循环完全不用动！

模型保存与加载

训练好的模型要保存下来，下次直接用不用重新训

# ========== 保存模型 ==========
torch.save(model.state_dict(), 'mnist_mlp.pth')
print("模型已保存")

# ========== 加载模型 ==========
# 先创建一个同样结构的模型实例
model = MLP().to(device)

# 加载保存的权重参数
model.load_state_dict(torch.load('mnist_mlp.pth', map_location=device))
model.eval() # 加载完用于预测要切eval模式

# 然后就可以直接做推理了！
with torch.no_grad():
    output = model(some_test_image)
    pred = output.argmax(dim=1)

💡 推荐只存state_dict()

torch.save(model, path)可以存整个模型，但不推荐（文件大、依赖代码路径、跨版本可能不兼容）。存state_dict()（只存参数权重）是官方推荐方式，更灵活更稳定。

本集知识点总结

PyTorch MNIST核心要点回顾

📦 PyTorch四大模块

torch（张量）、nn（网络层）、optim（优化器）、utils.data（数据加载）

🔢 Tensor与Autograd

Tensor是GPU版numpy，requires_grad=True时自动追踪计算，backward()自动求梯度——这是PyTorch的灵魂

📊 数据加载

Dataset定义样本怎么取，DataLoader负责batching/shuffling/并行加载，transforms做预处理

🧱 定义网络

继承nn.Module，__init__定义层，forward()定义前向传播。最后不要加Softmax（CrossEntropyLoss内置了）

🔄 训练循环五要素

epoch→batch→前向传播→计算loss+backward()→optimizer.step()+zero_grad()。记住这个流程通用所有DL任务！

⚠️ 两个最易忘的点

① 训练train()/测试eval()模式别搞混
② 别忘了optimizer.zero_grad()，别忘记加model.to(device)和data.to(device)
