深度网络的期望

越深的网络应该表达能力越强，效果越好，对吗？

🤔 理论上的直觉

深度网络有更多层、更多参数、更强的非线性表达能力。深层可以学到更抽象、更高级的特征。所以：

网络越深 → 表达能力越强 → 效果应该越好

📊 深度增加的好处

👁️

感受野更大
能看到更全局的信息

🧩

特征更抽象
从边缘到语义概念

💪

表达力更强
能拟合更复杂的函数

❓ 但是……

如果这是真的，为什么VGG只有19层？为什么不做100层、1000层？实际训练中，人们发现网络加深到一定程度后，效果反而变差了！

排除其他可能原因

为什么会出现退化问题？是梯度消失吗？

❓ 是梯度消失/爆炸吗？

部分原因是，但BatchNorm已经很大程度缓解了梯度问题。加入BN后，梯度不会严重消失/爆炸，但退化问题仍然存在。所以这不是主要原因。

❓ 是参数太多过拟合吗？

不是！过拟合的表现是训练集好测试集差，但退化问题中训练集都差——说明优化困难，不是过拟合。

💡 真正的根源：恒等映射难以学习

问题的本质是：如果浅层网络已经学到了不错的特征，深层网络理论上应该至少能做到"什么都不做"——也就是恒等映射(Identity Mapping)：直接把浅层特征传递下去，H(x)=x。

但是，让一堆非线性层（Conv→BN→ReLU→Conv→BN…）去拟合恒等映射H(x)=x 非常困难！深层网络很难学到"这层什么都不做"。

核心突破：ResNet残差连接

2015年何恺明等人提出，一个简单的加法解决了大问题

y = F(x, W) + x 不再直接让网络学习 H(x) = y（从x到y的直接映射）
而是让网络学习残差 F(x) = y - x（需要"补充"什么）
如果需要恒等映射，只需要让 F(x) → 0（这容易得多！）
输入 x
Conv → BN → ReLU
Conv → BN
F(x)
+
ReLU → 输出 y = F(x)+x

✨ 就是这么简单！

不需要增加任何参数，几乎不增加计算量，只是在卷积块的输入和输出之间加了一条"捷径"(skip connection)，把x直接加到F(x)上。

直觉理解：盘山公路的捷径

为什么残差连接让深层网络至少不会比浅层差？

🏔️ 想象你在爬山

如果没有残差连接：你必须一层层地爬上去，每层都要变换数据，一旦某层出问题，信息就丢了。

有了残差连接：就像在盘山公路旁边修了一条直达捷径。你可以走主路（卷积层提取新特征），也可以随时走捷径（直接传递），两条路在出口汇合相加。

🎯 "走捷径不会更差"的保证

最坏情况：卷积层什么有用特征都没学到，F(x)≈0，此时y≈x，相当于什么都没做——至少不会让结果变差。

正常情况：卷积层学到有用的新特征，F(x)提供了增量信息，y = x + 新特征，比原来更好。

📚 另一个类比：差分放大器

学过电路的同学可以类比差分放大器：放大的是输入和输出之间的"残差/差值"，而不是从头构建输出。学习增量比学习完整映射容易得多。

为什么学习残差更容易？

F(x)→0 比 H(x)→x 容易得多

❌ 普通网络：学习H(x)=x

让两层卷积权重恰好实现恒等映射：

  • Conv→BN→ReLU→Conv→BN的组合
  • 需要多个权重矩阵精确相乘得到单位矩阵
  • BN有归一化，ReLU有截断（负数变0）
  • SGD优化器几乎不可能找到这样的解
  • 深层网络训练困难，退化严重

✅ 残差网络：学习F(x)→0

让卷积层输出全0就等价于恒等映射：

  • 权重初始化为接近0（BN后γ初始化小值）
  • 两层卷积很容易输出接近0的值
  • 不需要拟合恒等映射，只需要"少做改动"
  • 优化器很容易找到F(x)≈0的区域
  • 深层网络也能轻松训练

💡 关键洞察

把"学习恒等映射"这个难题，转化为"学习零映射"这个简单问题。而神经网络的权重通常初始化接近0，学习输出接近0是轻而易举的事。

梯度高速公路

反向传播时，梯度可以直接通过shortcut流回任意浅层

🔄 来看看反向传播

假设损失L对输出y的梯度是∂L/∂y。我们来算对输入x的梯度：

y = F(x) + x

∂L/∂x = ∂L/∂y · ∂y/∂x = ∂L/∂y · (1 + ∂F/∂x) 梯度被分成了两部分：
• ∂L/∂y · 1：通过shortcut直接传递的梯度，不经过任何权重层！
• ∂L/∂y · ∂F/∂x：通过卷积层F传播的梯度

关键：那个"+1"项！即使∂F/∂x很小甚至为0，梯度也不会消失——至少还有1倍的梯度直接传回去。

🛤️ 梯度可以"抄近路"

无论网络有多少层，梯度都可以通过每个残差块的shortcut直接从深层传到浅层，不会因为经过很多层而消失。这就是为什么152层甚至1000+层ResNet都能训练。

ResNet基本构建块：BasicBlock

ResNet-18/34使用的基础残差块

输入 x (C通道, H×W)
3×3 Conv, C channels
↓
BatchNorm + ReLU
↓
3×3 Conv, C channels
↓
BatchNorm
+
ReLU → 输出 y (C通道, H×W)

📝 BasicBlock结构

两个3×3卷积堆叠，加上一个shortcut连接。当输入输出通道数相同时，shortcut直接是恒等映射（什么都不做，直接加）。

⚠️ 尺寸不匹配时怎么办？

如果通道数改变或者空间尺寸减半（下采样），shortcut需要用1×1卷积来匹配维度，否则不能直接相加。

BottleneckBlock：更深的网络用的块

ResNet-50/101/152使用瓶颈结构，用1×1卷积减少计算

输入 x (256通道)
1×1 Conv, 64通道 (降维)
↓ BN+ReLU
3×3 Conv, 64 channels
↓ BN+ReLU
1×1 Conv, 256通道 (升维)
↓ BN
+
ReLU → 输出 y (256通道)

💡 为什么叫Bottleneck？

先用1×1卷积把通道数从256降到64（"瓶颈"），然后做3×3卷积，再用1×1卷积升回256。这样3×3卷积的输入输出通道都是64，计算量大幅减少！整个BottleneckBlock的参数量和计算量甚至比BasicBlock还少。

为什么残差连接这么重要？

它的影响力远远超出了ResNet和CV领域

🛤️

梯度畅通

解决了深层网络梯度消失问题，让上百层甚至上千层网络可训练。"+1"项保证梯度不会消失。

🎯

学习增量

每一层只需要在已有特征基础上学习"增量/残差"，而不是重新学习整个映射，学习难度大幅降低。

🛡️

不退化保证

最坏情况F(x)→0等价于恒等映射，深层网络性能不会比浅层更差，下限有保证。

🌍 真正的影响力：跨领域通用

残差连接的思想如此简单、有效、通用，它迅速从CV扩散到NLP、语音、强化学习等几乎所有深度学习领域。可以说，现代深度网络几乎没有不用skip connection的。

残差连接的广泛应用：CNN家族

ResNet之后，CNN架构普遍采用残差连接

🔗 DenseNet (2017)

残差连接的极致版本：每层与前面所有层密集连接（concatenate而非add）。每层接收前面所有层的输出作为输入，特征复用，参数更少更高效。

🔀 ResNeXt (2017)

ResNet + Inception思路：分组卷积+残差连接。在相同计算量下精度更高，多分支等价于Inception+ResNet的组合。

🏗️ 其他基于ResNet的架构

Wide ResNet（更宽更浅）、ResNeSt（注意力+ResNet）、ConvNeXt（现代ConvNet借鉴Transformer设计）……几乎所有2015年后的SOTA CNN都基于残差连接。

📱 工业界标准backbone

ResNet-50是最常用的视觉backbone之一，被用于目标检测（Faster R-CNN/RetinaNet/YOLO）、分割（DeepLab/Mask R-CNN）、人脸识别等几乎所有视觉任务。

残差连接的广泛应用：Transformer

Transformer中每个子层都有残差连接+LayerNorm！

⚡ Transformer的Add & Norm

2017年的《Attention Is All You Need》中，每个子层都有残差连接！这不是巧合——没有残差连接，几十层的Transformer根本训练不动。

🧱 Transformer Encoder层结构

x → Multi-Head Self-Attention → Add&Norm（残差+LayerNorm）
   → Feed-Forward Network (FFN) → Add&Norm（残差+LayerNorm）
   → 输出

这里的"Add"就是残差连接！每个子层外面都包了一层残差，公式：
output = LayerNorm(x + Sublayer(x))

🎯 为什么Transformer也需要残差？

Transformer通常有6-12-24甚至上百层（GPT-3有96层）。没有残差连接，梯度在反向传播时层层相乘会消失，深层Transformer根本无法训练。残差是Transformer能够成功训练的关键组件之一。

残差连接的变种

研究者们还提出了哪些改进？

🔄 Pre-activation ResNet (2016)

把BN和ReLU放到卷积之前：BN→ReLU→Conv→BN→ReLU→Conv，shortcut上直接是干净的恒等映射。训练更稳定，泛化更好，适合极深网络（1000+层）。

🛣️ Highway Networks (2015)

残差连接的"前辈"：引入门控机制控制残差流，y = T(x)·F(x) + (1-T(x))·x。T(x)是transform gate，学习有多少信息走主路多少走捷径。ResNet是Highway的特例（T(x)=1）。

🔀 ResNeXt (2017)

引入分组卷积/基数维度：把Bottleneck中的3×3卷积拆成多组并行，等价于多分支ResNet+Inception。在相同计算量下精度更高。

🔗 DenseNet (2017)

连接更激进：每层与前面所有层拼接(concatenate)而非相加，最大化特征复用。参数量小，计算高效，但内存占用大。

PyTorch实现BasicBlock

代码其实非常简单——就是一个加法！

import torch import torch.nn as nn class BasicBlock(nn.Module): expansion = 1 def __init__(self, in_channels, out_channels, stride=1): super().__init__() # 两个3×3卷积层 self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1, bias=False) self.bn1 = nn.BatchNorm2d(out_channels) self.conv2 = nn.Conv2d(out_channels, out_channels, 3, padding=1, bias=False) self.bn2 = nn.BatchNorm2d(out_channels) # Shortcut，如果维度不匹配需要用1×1卷积调整 self.shortcut = nn.Sequential() if stride != 1 or in_channels != out_channels: self.shortcut = nn.Sequential( nn.Conv2d(in_channels, out_channels, 1, stride=stride, bias=False), nn.BatchNorm2d(out_channels) ) def forward(self, x): out = torch.relu(self.bn1(self.conv1(x))) out = self.bn2(self.conv2(out)) out += self.shortcut(x) # ⭐ 关键：残差连接！就是加一下 out = torch.relu(out) return out

✨ 核心就一行

out += self.shortcut(x)——这就是残差连接的全部！输入x通过shortcut直接加到卷积输出上。短短一行代码，解决了困扰深度学习多年的深层网络训练难题。

PyTorch实现BottleneckBlock

ResNet-50/101/152使用的瓶颈结构

class Bottleneck(nn.Module): expansion = 4 # 输出通道 = out_channels × 4 def __init__(self, in_channels, out_channels, stride=1): super().__init__() # 1×1 降维 self.conv1 = nn.Conv2d(in_channels, out_channels, 1, bias=False) self.bn1 = nn.BatchNorm2d(out_channels) # 3×3 特征提取（低维） self.conv2 = nn.Conv2d(out_channels, out_channels, 3, stride=stride, padding=1, bias=False) self.bn2 = nn.BatchNorm2d(out_channels) # 1×1 升维 self.conv3 = nn.Conv2d(out_channels, out_channels * self.expansion, 1, bias=False) self.bn3 = nn.BatchNorm2d(out_channels * self.expansion) self.shortcut = nn.Sequential() if stride != 1 or in_channels != out_channels * self.expansion: self.shortcut = nn.Sequential( nn.Conv2d(in_channels, out_channels * self.expansion, 1, stride=stride, bias=False), nn.BatchNorm2d(out_channels * self.expansion) ) def forward(self, x): out = torch.relu(self.bn1(self.conv1(x))) out = torch.relu(self.bn2(self.conv2(out))) out = self.bn3(self.conv3(out)) out += self.shortcut(x) # ⭐ 残差连接 out = torch.relu(out) return out

💡 注意expansion=4

Bottleneck最后输出通道是out_channels×4（如64→256），所以shortcut也要对应调整维度。1×1→3×3→1×1的结构让计算量集中在低维的3×3卷积，大幅节省计算。

残差设计哲学

一个加法操作为什么这么伟大？

0

额外参数

恒等shortcut完全不需要额外参数，几乎零计算成本，就能获得巨大的训练稳定性和性能提升。

∞

通用性强

任何网络、任何层都可以加残差连接，不挑架构。CNN/Transformer/RNN/GAN都适用。

🛡️

保底不亏

最坏情况F(x)=0，效果和原来一样。只会更好不会更差，这是一个"免费的午餐"。

🎯 简单即是美

深度学习中最有影响力的创新往往不是什么复杂的模块，而是像残差连接这种简单、优雅、直击本质的设计。好的解决方案不需要复杂，而需要精准解决问题。

残差连接 vs BatchNorm

两个都解决训练问题，但解决的是不同问题

为什么Transformer也需要残差？

Attention和FFN之后都有Add&Norm，这是必须的

🤔 Transformer不是没有CNN的退化问题吗？

Transformer的问题是它太深了——GPT-3有96层，BERT-base有12层，BERT-large有24层。这么深的网络，即使有LayerNorm，没有残差连接梯度仍然会严重消失，无法训练。

📐 Transformer中的残差公式

Self-Attention子层：
x = x + MultiHeadAttention(LayerNorm(x))  # Pre-LN
或：x = LayerNorm(x + MultiHeadAttention(x))  # Post-LN

FFN子层：
x = x + FFN(LayerNorm(x))
或：x = LayerNorm(x + FFN(x))

⚠️ Pre-LN vs Post-LN

原始Transformer用Post-LN（残差后做LN），但后来发现Pre-LN（残差前做LN）训练更稳定，不需要warmup也能收敛。GPT-2/BERT等实际都更偏向Pre-LN或其变种。但核心不变：一定有残差连接。

残差连接的一些直觉细节

深入理解残差网络为什么有效

🎓 残差表示假说

残差连接让网络每层只需要学习"修改"什么，而不是重新学习整个映射。这符合表示学习的思想：好的特征应该是逐步精化的，而不是每次推翻重来。

📊 集成模型视角

有研究者把ResNet看作很多不同深度路径的集成。ResNet展开后相当于从输入到输出有指数多条路径（选不选每个block的残差），训练时这些路径都在贡献梯度。这也解释了为什么ResNet看起来很深，但有效深度可能没那么深。

🔬 梯度流视角

残差连接提供了一条梯度直接传播的信息高速公路。反向传播时，损失信号可以毫无阻碍地到达任何浅层，有效解决了梯度消失问题。这是残差连接最根本的好处。

🧠 与大脑的类比

皮质微回路(cortical minicolumn)中也存在类似的"跳过"连接，大脑的信息处理也是多条路径并行而非严格串行。残差连接可能在某种程度上符合生物神经网络的信息处理方式。

自测答案

你答对了吗？

✅ 问题1答案

退化问题：网络加深后训练误差反而升高。这不是过拟合，因为过拟合是训练集好测试集差，而退化问题中训练集表现都更差，说明深层网络更难优化，学不到好的解。

✅ 问题2答案

权重初始化接近0，卷积层很容易输出接近0的值（两层小权重相乘结果更小）。但要让多层Conv+BN+ReLU恰好拟合恒等映射H(x)=x非常困难，因为ReLU会截断负数，BN有归一化操作，权重难以精确配合出单位映射。

✅ 问题3答案

反向传播梯度：∂L/∂x = ∂L/∂y·(1 + ∂F/∂x)。梯度中有个"+1"项，来自shortcut直接传递的梯度。即使∂F/∂x很小（梯度消失），"+1"保证梯度至少以∂L/∂y大小直接传回，不会消失。

✅ 问题4答案

BasicBlock是两个3×3卷积（ResNet-18/34用）；Bottleneck是1×1→3×3→1×1，先降维再升维（ResNet-50/101/152用）。Bottleneck用1×1卷积减少3×3卷积的通道数，大幅减少计算量，能构建更深网络。

✅ 问题5答案

Transformer（Add&Norm）、DenseNet、U-Net（跳跃连接）、GAN、Stable Diffusion、YOLO、Faster R-CNN、BERT/GPT……几乎所有现代深度网络！

本集核心要点总结

残差连接核心知识一页纸总结

📉 退化问题

网络加深到一定程度训练误差反而升高，不是过拟合，而是深层网络难以学习恒等映射H(x)=x。

🛤️ 残差连接

y = F(x) + x，让网络学习残差F(x)=y-x而不是直接学H(x)=y。F(x)→0比H(x)→x容易得多。零额外参数，计算量可忽略。

🛡️ 梯度高速公路

反向传播：∂L/∂x = ∂L/∂y·(1+∂F/∂x)，"+1"项保证梯度不会消失，可训练上百甚至上千层网络。

🧱 ResNet构建块

BasicBlock（ResNet-18/34，两个3×3）和Bottleneck（ResNet-50+，1×1→3×3→1×1），维度不匹配时用1×1卷积调整shortcut。

🌍 广泛应用

DenseNet/U-Net/Transformer/GAN/Diffusion都在用。Transformer中每个Self-Attention和FFN后都有Add&Norm残差。

💡 设计哲学

简单优雅（就是一个加法），零参数零成本，保底不亏，通用性强——深度学习最重要的设计之一。

学习心法：简单的东西才是最重要的

从残差连接获得的启发

🎯 真正有影响力的创新往往很简单

残差连接只是一个加法——out += x。它没有复杂的公式，没有大量的超参数，甚至不需要额外的计算量。但它解决了深度学习最核心的问题之一。

好的解决方案不是把问题变复杂，而是直击本质，用最简单的方法解决问题。

🔍 要理解"为什么"，而不仅是"怎么做"

很多人知道ResNet有skip connection，但不理解为什么要有。理解退化问题、理解梯度传播、理解为什么F(x)=0容易学——这些"为什么"才是真正的知识，能让你举一反三，看懂新的架构。

🌐 建立知识之间的连接

残差连接从CNN来，但改变了Transformer、改变了GAN、改变了整个深度学习。学习时注意知识之间的联系：Transformer的Add&Norm和ResNet的skip connection是同一个思想！
