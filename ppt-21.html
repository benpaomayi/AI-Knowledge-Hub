没有激活函数会怎样？

这是很多初学者最容易忽略的关键问题

$$\displaystyle 如果没有激活函数g( \cdot )： \ 输出 = W_3(W_2(W_1x + b_1) + b_2) + b_3 \       = (W_3W_2W_1)x + (W_3W_2b_1 + W_3b_2 + b_3) \       = Wx + b$$ 不管叠多少层线性变换，本质上都等价于一个单层线性变换！多层网络退化成单层，失去了深度的意义。

❌ 关键问题

线性变换的复合仍然是线性变换。如果没有非线性激活，神经网络只能表达线性关系，连XOR这样简单的非线性问题都解决不了——和单层感知机没区别！

🧠 万能近似定理(Universal Approximation Theorem)

只要有一个隐藏层和足够多的神经元，使用非线性激活函数的前馈神经网络，就能以任意精度逼近任何连续函数！

这就是为什么深度学习这么强大——非线性是关键。

✅ 类比理解

激活函数的理想性质

什么样的函数适合做激活函数？

🔴 必须满足

  • 非线性——否则多层无意义
  • 连续可导（几乎处处）——反向传播需要

🟠 非常希望

  • 计算简单——训练快
  • 输出零中心——梯度更新更稳定
  • 不饱和——防止梯度消失

🟡 锦上添花

  • 输出范围有限——稳定训练
  • 单调性——单层凸优化
  • 平滑——更好的梯度

💡 没有完美的激活函数

现实中没有激活函数能满足所有性质，都是在不同优缺点之间做权衡。我们需要根据场景选择最合适的。

Sigmoid函数：历史的经典

最早被广泛使用的激活函数，像生物神经元的"放电率"

📈
$$\displaystyle \sigma (x) = 1 / (1 + e⁻ˣ) \ \sigma '(x) = \sigma (x)(1- \sigma (x)) 输出范围(0,1)，两端饱和，导数最大0.25（x=0处）$$

✅ 优点

• 输出在(0,1)，可解释为概率
• 平滑可导，梯度自然
• 早期最常用，有历史地位

❌ 三大缺点（致命！）

• 梯度消失：两端饱和，导数接近0
• 非零中心：后层输入恒正，梯度更新zig-zag
• exp计算慢：指数运算开销大

Sigmoid缺点详解：非零中心问题

为什么输出不是零中心会导致训练慢？

🔍 Zig-zag现象

Sigmoid输出恒正(0,1)，所以后层的输入aˡ全是正数。
看梯度：∂L/∂w = δˡ · (aˡ⁻¹)ᵀ
如果aˡ⁻¹全正，那么∂L/∂w的符号完全由δˡ决定，同层所有权重的梯度符号都相同！

这导致梯度更新只能朝着全正或全负的方向走，不能走对角线，训练轨迹出现"之字形"(zig-zag)，收敛变慢。

⚠️ 类比理解

想象你要去一个在你东北方向的目标，但你只能先往东再往北，或者先往北再往东——不能直接往东北走，要绕路。Tanh因为输出零中心(-1,1)，就没有这个问题。

📌 适用场景

现在Sigmoid基本不用在隐藏层了，但在二分类输出层还是标配（输出概率）。

Tanh函数：Sigmoid的改进版

零中心，但仍然有梯度消失问题

📊
$$\displaystyle tanh(x) = (eˣ - e⁻ˣ)/(eˣ + e⁻ˣ) \         = 2 \sigma (2x) - 1 \ tanh'(x) = 1 - tanh²(x) 输出范围(-1,1)，零中心，导数最大1（x=0处）$$

✅ 优点

• 零中心输出(-1,1)——解决了Sigmoid的zig-zag问题
• 导数最大值1，比Sigmoid大
• 实际表现几乎总是比Sigmoid好

❌ 仍然有缺点

• 梯度消失问题依然存在——两端饱和，导数趋近于0
• 依然有exp计算，速度不快

📌 现状

Tanh也基本被ReLU取代了隐藏层地位，但在RNN等场景仍有使用。

ReLU：现代深度学习的默认选择

Rectified Linear Unit——简单、快速、有效

📈
$$\displaystyle ReLU(x) = max(0, x) x<0时输出0，x \geq 0时输出x。负区间导数0，正区间导数1。$$

✅ 三大优点（革命性！）

• 正区间不饱和——g'(x)=1，梯度无衰减！缓解梯度消失
• 计算极快——只需比较操作，不用exp
• 收敛速度快——约6倍于sigmoid/tanh

🌟 为什么ReLU这么重要？

2012年AlexNet用ReLU拿下ImageNet冠军，证明深层网络真的能训起来！这直接开启了深度学习的大爆发时代。在此之前，网络深了就训不动（梯度消失），ReLU改变了这一切。

ReLU的问题：神经元死亡(Dead ReLU)

ReLU并不完美，负区间有个大问题

💀 什么是神经元死亡？

如果一个神经元在训练中，权重更新后，对所有训练样本都输出0（即z<0），那么它的梯度就永远是0，权重再也不会更新——这个神经元"死"了，再也不会激活。

🔍 怎么发生的？

• 学习率太大，一次更新把w推得太负
• 参数初始化不好，一开始就很多神经元z<0
• 数据经过ReLU后有一半神经元（平均）被置0，产生稀疏性（这有时是好事）
• 但如果死得太多，网络表达能力下降

⚠️ 非零中心问题

ReLU和Sigmoid一样，输出非零中心（负区间输出0，正区间输出正），也存在一定的zig-zag问题，但实践中影响不大，被其他优点掩盖了。

Leaky ReLU：给负区间一个小斜率

解决Dead ReLU问题的简单方案

$$\displaystyle f(x) = max( \alpha x, x) \     = x if x>0 else \alpha x \ \alpha 通常取0.01 负区间不再是0，而是一个很小的斜率 \alpha x，让梯度能流回去。$$

✅ 优点

• 解决神经元死亡——负区间有非零梯度
• 保留ReLU的所有优点：计算快、正区间梯度1
• 零中心吗？不是，但比ReLU好一点

❓ 实践表现

虽然理论上Leaky ReLU解决了Dead ReLU，但实际中不一定总是比ReLU好，α的值也比较敏感。所以ReLU仍然是最常用的默认选择。

PReLU：α是可学习参数

Leaky ReLU的改进——让网络自己学α

$$\displaystyle f(x_i) = max( \alpha _i x_i, x_i)$$ αᵢ不是固定的0.01，而是每个通道有自己的α，和权重一样通过反向传播学习！
🧠

PReLU(Parametric ReLU)

α是可学习参数，每个通道一个α。何恺明等人在2015年提出，用在ResNet上取得了很好的效果。

🎲

RReLU(Randomized ReLU)

训练时α从均匀分布U(l,u)中随机采样，测试时固定为均值。有一定正则化效果，在Kaggle比赛中有时好用。

💡 思路

从固定α→学习α→随机α，都是围绕"负区间斜率"做文章，试图在ReLU基础上进一步改进。但这些改进带来的提升通常不大，除非在特定任务/数据集上。

ELU / SELU：自归一化激活

让网络输出自动归一化的激活函数

ELU (Exponential Linear Unit)

$$\displaystyle f(x) = x if x>0 \        = \alpha (eˣ-1) if x \leq 0$$

负区间是指数曲线，输出均值接近0，比ReLU更鲁棒。但计算稍慢（有exp）。

SELU (Scaled ELU)

$$\displaystyle SELU(x) = \lambda \cdot ELU(x, \alpha ) \ \alpha \approx 1.6733, \lambda \approx 1.0507$$

作者证明：如果正确初始化，SELU能让多层网络的输出自动归一化到0均值1方差，不需要BatchNorm！

⚠️ SELU使用条件

SELU要想达到"自归一化"效果有严格条件：必须用lecun_normal初始化、不能用BN、网络架构要满足特定要求。条件不满足时效果可能反而不好，所以没有成为主流。

GELU：Transformer的最爱

平滑版ReLU，GPT/BERT等大模型都在用

$$\displaystyle GELU(x) = x \cdot Φ(x)$$ Φ(x)是标准正态分布的累积分布函数。可以理解为一种"概率性"的ReLU——根据x的大小，以一定概率保留x，另一概率置0。

🌟 GELU的优点

  • 处处平滑可导——不像ReLU在x=0处有个拐点
  • 非线性能力更强，表达能力更好
  • 在NLP/Transformer任务上表现 consistently 比ReLU好
  • BERT、GPT-2/3/4、ViT等都用GELU

📝 近似计算

GELU精确计算需要erf函数，实际中常用快速近似：
GELU(x) ≈ 0.5x(1 + tanh[√(2/π)(x + 0.044715x³)])
PyTorch中直接调用nn.GELU()即可。

Swish / Mish：更平滑的选择

通过自动搜索发现的新式激活函数

Swish

$$\displaystyle Swish(x) = x \cdot \sigma ( \beta x)$$

Google 2017年提出，β可学习或固定1。平滑、非单调，在很多任务上比ReLU好。

Mish

$$\displaystyle Mish(x) = x \cdot tanh(softplus(x)) \ softplus(x) = ln(1+eˣ)$$

2019年提出，比Swish更平滑，YOLOv8等目标检测模型常用。

💡 共同特点

• 都是平滑函数
• 非单调（负区间不是恒0或恒负）
• 有下界没上界
• 计算稍复杂

📊 趋势

在CNN/计算机视觉领域，ReLU/LeakyReLU仍是主流；在NLP/Transformer领域，GELU是标配。Swish/Mish在某些任务上表现更好，但没有"一统天下"。

Softmax：多分类输出层专用

把任意实数向量变成概率分布

$$\displaystyle Softmax(z)_i = eᶻⁱ / \sum _j eᶻʲ$$ 输入是一个向量z（logits），输出是一个概率向量：每个元素在(0,1)之间，且所有元素和为1。

🌰 举个例子

假设输出层logits z = [3, 1, -2]（三分类）
e³≈20.085, e¹≈2.718, e⁻²≈0.135
总和≈22.938
Softmax输出 = [20.085/22.938, 2.718/22.938, 0.135/22.938] ≈ [0.876, 0.118, 0.006]

解释：模型认为属于第1类的概率是87.6%，第2类11.8%，第3类0.6%。

📌 注意

Softmax只用在多分类输出层，隐藏层不用！而且Softmax总是和交叉熵损失搭配使用，PyTorch中nn.CrossEntropyLoss已经包含了Softmax，不要自己加！

Softmax的数值稳定性问题

eˣ太大或太小都会导致数值问题

⚠️ 问题：数值溢出

如果zᵢ很大（比如1000），e¹⁰⁰⁰会溢出变成inf；如果zᵢ很小（比如-1000），e⁻¹⁰⁰⁰会下溢变成0，梯度也变NaN。

✅ 解决方案：减去最大值

Softmax对常数平移不变！所以可以先减去z中的最大值：

m = max(z)
Softmax(z)ᵢ = e^(zᵢ - m) / Σⱼ e^(zⱼ - m)

这样最大的指数就是e⁰=1，不会溢出；其他项最多是0（下溢到0也没关系，因为分母也有1）。

PyTorch/TensorFlow的Softmax已经自动做了这个处理，你不用管。

💡 提示

自己实现Softmax时一定要记得减最大值！否则很容易出现NaN。这是面试常考的细节题。

隐藏层激活函数选择建议

这么多激活函数，实际中怎么选？

🥇 默认首选：ReLU 简单、快、效果好，绝大多数场景先试ReLU，错不了
🥈 如果Dead ReLU严重：Leaky ReLU/ELU 如果训练中发现很多神经元输出0，可以试试Leaky ReLU
🥉 Transformer/NLP：GELU BERT/GPT/ViT都用GELU，不要用ReLU
🏅 追求SOTA：Swish/Mish 比赛/刷榜时可以试试，可能有小幅提升，但训练稍慢

⚠️ 别用Sigmoid/Tanh在隐藏层

除了某些特殊网络（如RNN），隐藏层就别用Sigmoid/Tanh了，梯度消失太严重，深层网络根本训不动。

从1940年代到今天，激活函数的进化之路

1940s-1960s：阶跃函数 McCulloch-Pitts神经元、感知机——不可导，只能训单层

激活函数与初始化的关系

好的激活函数需要配合好的初始化

Xavier初始化

适用：Sigmoid/Tanh
W ~ N(0, 2/(n_in + n_out))
或均匀分布U(-√(6/(n_in+n_out)), √(...))

让前向/反向传播时信号方差保持不变。

He初始化(Kaiming)

适用：ReLU/Leaky ReLU
W ~ N(0, 2/n_in)
或均匀分布U(-√(6/n_in), √(...))

专门为ReLU设计，考虑了一半神经元被置0的情况。

🔑 PyTorch默认初始化

nn.Linear默认用Kaiming初始化（适合ReLU），所以你不用特意改。但如果用Sigmoid/Tanh，最好手动换成Xavier。实际上：直接用ReLU+默认初始化就好，不用纠结。

常见误区与面试题

这些问题经常被问到，也很容易搞错

❓ Q1：为什么ReLU在x=0处不可导还能用？

因为x=0是一个测度为0的点，几乎不可能在训练中精确遇到；而且次梯度(subgradient)在x=0处取0或1都可以，实际中不影响训练。

❓ Q2：为什么不用sin/cos做激活函数？

周期函数会导致不同输入有相同输出，且导数±1震荡，梯度不稳定，训练容易不收敛。虽然有相关研究，但实践中不用。

❓ Q3：ReLU输出非负不是有zig-zag问题吗？为什么还比Tanh好？

因为梯度消失的危害远大于zig-zag！zig-zag只是让收敛变慢一点，梯度消失直接让深层网络学不到东西。两害相权取其轻。而且batch normalization也缓解了这个问题。

❓ Q4：多标签分类为什么用Sigmoid不用Softmax？

因为多标签中类别不互斥（一张图可以既有猫又有狗），不需要概率和为1，每个类独立判断是否存在。Softmax强制互斥，不适合。

激活函数的使用非常简单

import torch import torch.nn as nn # 方法1：在__init__里定义，forward里调用 class Net(nn.Module): def __init__(self): super().__init__() self.fc1 = nn.Linear(784, 256) self.relu = nn.ReLU() # 隐藏层用ReLU self.fc2 = nn.Linear(256, 10) self.softmax = nn.Softmax(dim=1) # 输出层10分类用Softmax def forward(self, x): x = self.relu(self.fc1(x)) x = self.softmax(self.fc2(x)) return x # 方法2：直接在forward里用torch.nn.functional import torch.nn.functional as F x = F.relu(self.fc1(x)) x = F.gelu(self.fc1(x)) # GELU也有 # ⚠️ 重要：用CrossEntropyLoss时不要自己加Softmax！ criterion = nn.CrossEntropyLoss() # 已包含LogSoftmax+NLLLoss

本集核心知识点总结

激活函数——神经网络的非线性来源

🔑

核心作用

引入非线性，让多层网络有意义

🥇

默认选择

隐藏层ReLU，二分类Sigmoid，多分类Softmax

⚠️

注意事项

Sigmoid梯度消失、Dead ReLU、CrossEntropyLoss别加Softmax

🎯 记住

• 没有激活函数 = 多层退化成单层，这是最重要的一句话
• Sigmoid/Tanh：历史经典，但隐藏层已淘汰，Sigmoid留作二分类输出
• ReLU：简单、快、效果好，隐藏层首选，注意Dead ReLU问题
• GELU：Transformer/NLP标配
• Softmax：多分类输出层专用，和交叉熵搭配
• 不要死记，多实践——不同任务可能适合不同激活函数
