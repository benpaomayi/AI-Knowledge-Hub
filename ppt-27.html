为什么参数初始化这么重要？

训练从初始参数开始——起点错了，后面怎么努力都没用

🏁 初始化W,b
→
前向传播计算loss
→
反向传播算梯度
→
梯度下降更新W,b
→
🔁 循环...直到收敛
💥

梯度爆炸

初始化太大→激活值饱和前z值太大→反向传播梯度越乘越大→更新太大→loss=NaN，训练直接崩溃。

🫥

梯度消失

初始化太小→激活值接近0→Sigmoid/Tanh/ReLU梯度都接近0→参数几乎不更新→loss永远不下降。

🐢

训练极慢

初始化不好即使不消失不爆炸，也会让梯度方向不对、收敛很慢，别人10epoch训好你100epoch还不行。

直观理解：在Loss Landscape上选起点

梯度下降是从初始点开始"滚下山"——起点决定你能到哪个山谷

🏔️ 损失函数地形

高维空间中损失函数像起伏的山地，有很多山谷（局部最优）和一个最低山谷（全局最优）。梯度下降就是从起点往低处滚。

✅ 好的初始化

  • 在一个"斜坡"上，梯度方向合理
  • 既不在"悬崖"上（梯度过大爆炸）
  • 也不在"平原"上（梯度消失走不动）
  • 能够顺利收敛到一个好的山谷
VS

❌ 糟糕初始化

  • 在悬崖边→梯度爆炸直接飞出去
  • 在平原上→梯度消失原地不动
  • 在一个很差的局部最优坑里
  • 所有神经元对称，永远学不到东西

💡 注意

现代优化器（Adam等）和Normalization层降低了对初始化的敏感度，但初始化仍然重要——好初始化让你更快收敛、效果更好。

全零初始化：新手最容易犯的错

"既然不知道权重初始多少，那就都设0吧？"——大错特错！

🚨 为什么全零不行？——对称性问题(Symmetry Breaking)

如果所有W初始化为0：
1. 前向传播：不管输入是什么，所有神经元的计算结果都完全一样→所有神经元输出相同
2. 反向传播：所有神经元的梯度也完全相同→所有神经元参数更新量完全一样
3. 更新后：所有神经元参数仍然完全一样→永远保持对称！

结果：不管网络有多少层、多少神经元，本质上和只有1个神经元没区别，永远学不到不同特征！

# ❌ 绝对不要这么做！
nn.Linear.weight.data.fill_(0)

# 为什么？让我们看一个简单网络：
# h1 = ReLU(W1·x + b1) W1全0→h1全相同
# h2 = ReLU(W2·h1 + b2) h1全相同→h2全相同
# 反向传播：∂L/∂W1所有行都一样→更新后W1还是对称
# 死循环！永远学不到东西！

随机初始化：打破对称性

全零不行，那随机初始化总可以吧？——没那么简单！

✅ 随机初始化的作用

从某个分布随机采样权重（如高斯分布/均匀分布），每个神经元初始参数不同，打破对称性，这样不同神经元才能学到不同特征。

⚠️ 但随机的方差很重要！

不是随便随机就可以——随机的方差（标准差）大小直接影响训练成败：

📈

方差太大（W太大）

• z = Wx + b 值很大
• Sigmoid/Tanh进入饱和区→梯度≈0
• ReLU可能一直激活或永远死
• 多层累积后激活值爆炸→梯度爆炸
• 症状：loss=NaN

📉

方差太小（W太小）

• z = Wx + b 值很小，接近0
• Sigmoid在z≈0附近梯度最大？但...
• 多层后激活值越来越小→梯度也越来越小
• 深层网络梯度消失→参数几乎不更新
• 症状：loss完全不下降

方差问题演示：前向传播信号放大/缩小

每一层都让信号方差保持一致——这就是Xavier/He初始化的核心思想

$$\displaystyle Var(z) = Var(W \cdot x) \approx n_in \cdot Var(W) \cdot Var(x)$$ 假设输入x均值0方差1，W独立同分布均值0，那么z的方差约为 n_in × Var(W)。

• 如果 Var(W) 太大 → 每层Var(z)×n_in×Var(W) > 1 → 信号越来越大（爆炸）
• 如果 Var(W) 太小 → 每层Var(z)×n_in×Var(W) < 1 → 信号越来越小（消失）
• 理想：Var(z) = Var(x)，信号既不放大也不缩小

Var≈?
→ σ → W₂ →
z₂
Var≈?
→ σ → ... →
z_L
Var≈1（理想）

🎯 核心洞察

我们希望每层输入输出方差保持一致，这样信号在深层网络中既不爆炸也不消失。Xavier和He初始化就是按这个思想推导出来的。

Xavier/Glorot初始化（2010）

Xavier Glorot和Yoshua Bengio在2010年提出，让前向反向传播方差都一致

📜 历史背景

2010年大家发现深层网络训练不动，很大原因是初始化不对。Xavier初始化是第一个被广泛使用的科学初始化方法，针对Sigmoid和Tanh激活函数设计。

$$\displaystyle Xavier均匀初始化：W ~ U(-a, a)，其中 a = \sqrt{(6 / (n_in + n_out)) \ Xavier正态初始化：W ~ N(0, \sqrt{(2 / (n_in + n_out)))$$ n_in：该层输入神经元个数
n_out：该层输出神经元个数
推导时同时考虑前向传播和反向传播的方差一致，取了n_in和n_out的调和平均。
# PyTorch中Xavier初始化
import torch.nn as nn
import torch.nn.init as init

linear = nn.Linear(784, 256)

# Xavier均匀初始化
init.xavier_uniform_(linear.weight)

# Xavier正态初始化
init.xavier_normal_(linear.weight)

Xavier初始化：适用场景与局限

Xavier很好，但只在Sigmoid/Tanh上效果好，对ReLU不适用

✅ 适用场景

• 激活函数是 Sigmoid 或 Tanh
• 激活函数关于0对称、在0附近梯度近似为1
• 2010-2015年左右的网络常用（AlexNet早期层还在用）

⚠️ 为什么对ReLU不适用？

ReLU负半轴直接置0！这意味着大约一半的神经元输出为0，方差被砍半。
Xavier推导时假设激活函数近似恒等映射（Tanh在0附近确实如此），但ReLU负半轴是0，方差不满足Xavier假设→用Xavier初始化ReLU网络，每层方差还是会衰减→深层还是梯度消失。

ReLU

❌ Xavier不合适

❌ Xavier也不合适

He/Kaiming初始化（2015）

何恺明等人在2015年提出，专门针对ReLU设计——现在最常用！

🏆 为什么He初始化这么重要？

2015年ResNet论文里用了He初始化，直接让152层超深网络能训起来！He初始化现在是使用ReLU/LeakyReLU网络的标配，PyTorch中nn.Linear等层默认就是He初始化的变体。

$$\displaystyle He正态初始化：W ~ N(0, \sqrt{(2 / n_in)) \ He均匀初始化：W ~ U(-b, b)，其中 b = \sqrt{(6 / n_in)$$ n_in：该层输入神经元个数
关键区别：Xavier是1/(n_in+n_out)，He是2/n_in！
那个×2就是补偿ReLU负半轴置0导致的方差减半！
# PyTorch中He初始化（也叫Kaiming初始化）
linear = nn.Linear(784, 256)

# He正态初始化（最常用）
init.kaiming_normal_(
    linear.weight,
    mode='fan_in', # 默认就是fan_in，用n_in
    nonlinearity='relu' # 针对relu（默认）
)

# He均匀初始化
init.kaiming_uniform_(linear.weight)

He初始化：为什么是2/n_in？

那个×2的因子是怎么来的？——补偿ReLU的方差减半

$$\displaystyle ReLU后：y = max(0, z) → Var(y) \approx ½ Var(z)$$ 假设z对称分布在0周围（W零均值、x零均值时确实如此），ReLU后大约一半值变成0，另一半保留，方差大约减半。

为了让Var(y) = Var(x)（信号方差不变）：
Var(z) = n_in · Var(W) · Var(x)
Var(y) = ½ Var(z) = ½ · n_in · Var(W) · Var(x) = Var(x)
→ Var(W) = 2/n_in
所以W ~ N(0, √(2/n_in)) 就是He初始化！

Var≈1（完美！）
→ 下一层 →

✅ 完美补偿

He初始化把W方差设为2/n_in，让z的方差是2，经过ReLU后方差砍半正好是1，完美保持方差不变！这样深层网络信号既不爆炸也不消失。

偏置b怎么初始化？

偏置简单多了——通常初始化为0就可以！

✅ 偏置b通常初始化为0

偏置不像权重W那样有对称性问题——因为W已经随机初始化打破对称了，b初始化为0不会导致对称问题。

特殊情况：
• 有些LSTM/GRU偏置会设为1（让遗忘门一开始偏向记住）
• ReLU网络有人建议b初始化为一个小正数（如0.01），避免初期太多神经元死亡，但不是必须

# ✅ 偏置初始化为0是标准做法
init.zeros_(linear.bias)

# PyTorch中nn.Linear默认就是：
# weight用Kaiming均匀初始化
# bias初始化为0（如果bias=True）

# 特殊情况：ReLU防止死亡ReLU可选
init.constant_(linear.bias, 0.01) # 非必须

💡 注意

偏置初始化不是重点，对结果影响很小，不用花太多精力纠结b怎么初始化——设0就好。

BatchNorm：降低对初始化的敏感度

有了BN层，初始化就没那么敏感了——但还是要合理初始化

📊 Batch Normalization做了什么？

BN层对每个mini-batch的输入做标准化：均值0方差1，再加上可学习的γ和β参数。这相当于每一层都把分布拉回"舒适区"，不会因为前面层的问题导致后面激活值爆炸/消失。

输入z
→
BN标准化
→ 均值0方差1
→
γ·z_norm + β
（可学习缩放偏移）
→
激活函数

✅ BN带来的好处

• 大幅降低对初始化的要求，初始化稍差也能训
• 允许用更大学习率，训练更快
• 自带一定正则化效果
• ResNet等现代网络标配

⚠️ 但不能完全乱来

• BN不能救完全错误的初始化（比如全零、太大NaN）
• 初始化好还是更快收敛
• 有些网络没有BN（如Transformer底层、小网络）

预训练初始化：迁移学习

最好的初始化：用别人在大数据集上训好的权重！

🏆 迁移学习是现在的主流

与其随机初始化从头训，不如用在ImageNet等大数据集上预训练好的模型权重作为起点，再在你的小数据集上微调。这比随机初始化效果好太多，训练也快很多。

🎲 随机初始化

  • 从零开始学习所有特征
  • 需要大量数据+大量算力
  • 训练时间长，可能不收敛
  • 小数据集容易过拟合
VS

🌟 预训练初始化

  • 已经学到通用特征（边缘、纹理、形状）
  • 小数据集也能有好效果
  • 训练快，收敛好，不容易过拟合
  • ⭐ 现在做项目首选！

💡 注意

微调时用预训练权重初始化，但注意学习率要小！参考上一集讲的差分学习率。

PyTorch中的初始化函数

torch.nn.init 提供了各种初始化方法

import torch.nn.init as init

# ========== 常用初始化 ==========
# 1. 均匀分布 U(a,b)
init.uniform_(tensor, a=0.0, b=1.0)

# 2. 正态分布 N(mean, std)
init.normal_(tensor, mean=0.0, std=1.0)

# 3. 常数初始化
init.constant_(tensor, val=0)
init.zeros_(tensor)
init.ones_(tensor)

# ========== Xavier/Glorot ==========
init.xavier_uniform_(tensor) # U(-√(6/(n_in+n_out)), ...)
init.xavier_normal_(tensor) # N(0, √(2/(n_in+n_out)))

# ========== He/Kaiming（推荐！） ==========
init.kaiming_uniform_(tensor, mode='fan_in', nonlinearity='relu')
init.kaiming_normal_(tensor, mode='fan_in', nonlinearity='relu')

# ========== 其他 ==========
init.orthogonal_(tensor) # 正交初始化，RNN/Transformer有时用
init.sparse_(tensor) # 稀疏初始化

PyTorch层自带的默认初始化

其实你不手动初始化，PyTorch也会做合理的默认初始化

ℹ️ PyTorch nn.Linear 默认初始化

weight：Kaiming均匀初始化（He初始化的均匀版本）
bias：初始化为0（如果bias=True）

哎？那是不是不用手动初始化了？

✅ 大多数情况默认就够了

PyTorch的默认初始化已经挺合理了（针对ReLU设计的He均匀），普通MLP、简单CNN不手动初始化也能训。

⚠️ 但有些情况需要手动初始化

• 你用的是Tanh/Sigmoid，Xavier可能更合适
• 自定义层没有默认初始化
• 想要可复现（设置随机种子+显式初始化更可控）
• 深层网络想确保初始化正确（显式写出来更保险）
• 读论文复现，论文指定了初始化方法

# 给整个模型做初始化的写法
def init_weights(m):
    if isinstance(m, nn.Linear):
        init.kaiming_normal_(m.weight, nonlinearity='relu')
        if m.bias is not None:
            init.zeros_(m.bias)

model.apply(init_weights) # 递归应用到所有层

随机种子：让结果可复现

初始化是随机的，设置随机种子能让每次运行结果一样

🎲 为什么需要设置种子？

权重初始化是随机的，如果不设种子，每次运行初始权重都不一样——有时训得好有时训不好，很难调试和复现。设了种子，随机性固定，别人能复现你的结果。

import torch
import numpy as np
import random

def set_seed(seed=42):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed(seed)
    torch.cuda.manual_seed_all(seed) # 多GPU
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False

set_seed(42) # 在程序最开始调用！

⚠️ 注意

完全可复现性可能会让训练稍慢（cudnn.benchmark=False），但调试和发论文时非常重要。

常见初始化误区

这些坑你踩过吗？

❌ 误区1："越大的W越好，梯度大学得快"

错！W太大→z值太大→Sigmoid/Tanh饱和梯度≈0→反而学不动！ReLU也会爆炸。

❌ 误区2："越小的W越安全，不会爆炸"

错！W太小→多层后信号越来越小→梯度消失→也学不动！

❌ 误区3："ReLU网络用Xavier也差不多吧？"

不推荐！Xavier没考虑ReLU负半轴置0，深层网络用Xavier还是会梯度消失，用He！

❌ 误区4："有BN层就不用管初始化了，随便怎么设都行"

错！BN能降低敏感度但救不了全零、NaN这种极端情况，合理初始化还是更快收敛。

❌ 误区5："预训练模型随便替换最后一层就行"

注意！替换的最后一层也要合理初始化，别用太大值把前面预训练好的层带坏了，微调时学习率也要小。

初始化调试技巧

训练前先做个"体检"——初始化好没好，跑前几步看看

Step 1：初始化后检查参数统计 打印各层W的mean和std，看是否符合预期（He初始化std≈√(2/n_in)）
Step 2：看前向传播激活值 跑一个batch，看各层激活值是不是既不全0也不爆太大，Sigmoid/Tanh不要都在饱和区
Step 3：看反向传播梯度 backward后看各层梯度的mean/std，不要全0也不要NaN/inf，也不要太大太小
Step 4：看前10个epoch loss loss应该开始下降，不是NaN，不是完全不动，不是剧烈震荡（轻微震荡正常）
Step 5：过拟合一个小batch 取20个样本训练，模型应该能很快把loss降到接近0、准确率100%——这是验证初始化+模型+代码有没有bug的最佳方法！

初始化发展简史

初始化方法是随着网络变深一步步发展来的

2006年之前：预训练+逐层初始化（DBN），没有好的直接初始化方法，深层网络训不动
2010年：Xavier初始化 Glorot & Bengio，让前向反向方差一致，让训练几层到十几层网络成为可能，配合Sigmoid/Tanh
2015年：He/Kaiming初始化 何恺明等，针对ReLU设计，×2补偿方差，配合BN让100+层ResNet成为可能，现在最常用
2015年后：迁移学习成为主流 大家发现用预训练权重初始化比任何随机初始化方法都好，现在做项目优先用预训练
现在：大模型时代，预训练初始化是唯一解；随机初始化只在从头训大模型时用，配合更好的优化器和归一化层

本集知识点总结

参数初始化核心要点回顾

🚫 绝对不要全零初始化W

全零导致对称性问题，所有神经元永远学一样的东西，网络等于只有1个神经元。

⚠️ 随机初始化方差要合适

太大→梯度爆炸NaN；太小→梯度消失loss不动。需要让每层信号方差保持一致。

📜 Xavier初始化（2010）

√(2/(n_in+n_out))，针对Sigmoid/Tanh设计，现在用得少了。

⭐ He初始化（2015）

√(2/n_in)，×2补偿ReLU方差减半，ReLU网络标配，现在最常用！

🌟 最好的初始化：预训练

有预训练模型就用预训练，比任何随机初始化都好，配合小lr微调。

🎯 实践建议

偏置b设0；有BN层更稳；设种子可复现；前10步检查loss/激活/梯度。
