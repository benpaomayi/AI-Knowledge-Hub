📊 评估模式

model.eval() with torch.no_grad(): for x, y in val_loader: logits = model(x) pred = logits.argmax(dim=1) acc = (pred == y).float().mean() # 评估完记得切回train模式! model.train()

⚠️ 两个最容易犯的错误

❌ 忘记zero_grad()

梯度会累加，导致参数更新错误

❌ 忘记model.eval()

Dropout/BN在推理时行为不同，结果随机

训练循环Pseudo-code模板

def train(model, train_loader, val_loader, epochs): best_acc = 0 for epoch in range(epochs): # ========== Training ========== model.train() train_loss = 0 for x, y in train_loader: optimizer.zero_grad() logits = model(x) loss = criterion(logits, y) loss.backward() torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0) # 梯度裁剪 optimizer.step() train_loss += loss.item() scheduler.step() # 学习率调度 # ========== Validation ========== model.eval() val_loss = 0; correct = 0; total = 0 with torch.no_grad(): for x, y in val_loader: logits = model(x) val_loss += criterion(logits, y).item() correct += (logits.argmax(1) == y).sum().item() total += y.size(0) val_acc = correct / total print(f"Epoch {epoch}: train_loss={train_loss/len(train_loader):.4f}, val_acc={val_acc:.4f}") # ========== Early Stopping & Save Best ========== if val_acc > best_acc: best_acc = val_acc torch.save(model.state_dict(), "best_model.pt") patience_counter = 0 else: patience_counter += 1 if patience_counter >= patience: print("Early stopping!") break

学习率设置策略总结

🔰 初学者

  • 优化器：Adam
  • 初始LR：1e-3
  • 调度器：StepLR(step=10, gamma=0.5)
  • Weight Decay：1e-4
简单可靠

🚀 进阶使用

  • 优化器：AdamW
  • 初始LR：LR Finder找
  • 调度器：CosineAnnealingLR
  • Warmup：前5% epoch线性升温

🏆 追求SOTA

  • 优化器：SGD+Momentum(0.9)
  • 初始LR：LR Finder
  • 调度器：OneCycleLR
  • Weight Decay：网格搜索
需要调参

💡 关键经验

学习率是最重要的超参数。如果loss不降，先调LR！太大→震荡/NaN，太小→收敛慢/不收敛。

L1 vs L2 正则化对比

📐 L2 Regularization (Weight Decay)

L = Loriginal + λ Σ w²
  • 效果：让权重均匀变小，接近0但不为0
  • 优点：稳定，处处可导
  • 缺点：不产生稀疏性
  • 使用：深度学习默认首选
默认用这个

📏 L1 Regularization

L = Loriginal + λ Σ |w|
  • 效果：让部分权重变0，产生稀疏解
  • 优点：有特征选择效果
  • 缺点：在0点不可导
  • 使用：特征选择/压缩场景
特征选择

训练问题诊断表

症状 可能原因 解决方案
Train/Val loss都不下降 学习率太大（震荡） 降低LR，如1e-3→1e-4
学习率太小（走不动） 增大LR，用LR Finder
数据/标签有问题 检查数据可视化，过拟合小样本测试
Train loss降，Val loss升 过拟合！ 加正则化（WD/Dropout/数据增强）
训练太久 Early Stopping，保存最佳模型
Train loss下降很慢 学习率太小 增大LR
梯度消失/初始化不好 用BN/残差连接/He初始化
Loss = NaN 梯度爆炸/数据有NaN 降低LR + 梯度裁剪 + 检查数据

核心代码模板：数据准备

import torch from torch import nn, optim from torch.utils.data import DataLoader, random_split from torchvision import datasets, transforms # 数据预处理 transform_train = transforms.Compose([ transforms.RandomHorizontalFlip(), transforms.RandomCrop(32, padding=4), transforms.ToTensor(), transforms.Normalize((0.5,), (0.5,)) ]) transform_test = transforms.Compose([ transforms.ToTensor(), transforms.Normalize((0.5,), (0.5,)) ]) # 加载数据并划分 full_dataset = datasets.MNIST(root='./data', train=True, transform=transform_train, download=True) train_size = int(0.8 * len(full_dataset)) val_size = len(full_dataset) - train_size train_dataset, val_dataset = random_split(full_dataset, [train_size, val_size]) val_dataset.dataset.transform = transform_test train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True) val_loader = DataLoader(val_dataset, batch_size=100, shuffle=False) test_dataset = datasets.MNIST(root='./data', train=False, transform=transform_test) test_loader = DataLoader(test_dataset, batch_size=100, shuffle=False)

核心代码模板：模型定义

class MLP(nn.Module): def __init__(self, input_dim=784, hidden_dims=[256, 128], num_classes=10, dropout=0.5): super().__init__() layers = [] prev_dim = input_dim for h_dim in hidden_dims: layers.append(nn.Linear(prev_dim, h_dim)) layers.append(nn.BatchNorm1d(h_dim)) # BatchNorm加速收敛 layers.append(nn.ReLU()) layers.append(nn.Dropout(dropout)) # Dropout防过拟合 prev_dim = h_dim layers.append(nn.Linear(prev_dim, num_classes)) # 最后不加softmax! self.net = nn.Sequential(*layers) # Kaiming初始化 self._init_weights() def _init_weights(self): for m in self.modules(): if isinstance(m, nn.Linear): nn.init.kaiming_normal_(m.weight, nonlinearity='relu') nn.init.zeros_(m.bias) def forward(self, x): x = x.view(x.size(0), -1) # Flatten return self.net(x) model = MLP() model

常见坑点与避坑指南

❌ 忘记zero_grad()

梯度会累加，导致参数更新错误

# ❌ 错误 loss.backward() optimizer.step() # ✅ 正确 optimizer.zero_grad() loss.backward() optimizer.step()

❌ 忘记model.eval()

Dropout/BN推理时随机，结果不对

# ❌ 错误：验证时还在train模式 # outputs = model(x) # Dropout开着! # ✅ 正确 model.eval() with torch.no_grad(): outputs = model(x) model.train()

❌ 最后一层加softmax

CrossEntropyLoss已经包含log_softmax

# ❌ 错误 self.net = nn.Sequential( ..., nn.Linear(256, 10), nn.Softmax(dim=1) # 重复了! ) # ✅ 正确：直接输出logits self.net = nn.Sequential( ..., nn.Linear(256, 10) )

常见坑点与避坑指南（续）

⚠️ 训练/测试预处理不一致

测试时不要用训练时的数据增强（随机翻转等）

注意

⚠️ 张量没搬到GPU

model.to(device)了但x,y没.to(device)会报错

# 每个batch都要搬 x = x.to(device) y = y.to(device)

⚠️ 标签泄露(Label Leakage)

验证/测试数据泄露到训练集，或预处理用了全量数据统计量

数据划分后再fit归一化参数

⚠️ 梯度爆炸→NaN

loss突然变NaN大多是LR太大或梯度爆炸

# 加梯度裁剪 torch.nn.utils.clip_grad_norm_( model.parameters(), max_norm=1.0 )

训练好模型的标准

🎯 Sanity Check通过

在几十~几百个样本上能过拟合，loss降到接近0

📈 训练/验证曲线接近

Train loss和Val loss差距不大，没有严重过拟合

🏆 验证集指标达标

验证集准确率/指标达到你的预期目标

🔧 能正确加载预测

保存的模型加载后在测试集上结果一致

理想的训练曲线

train loss ↓↓↓
val loss ↓↓ 然后趋于平稳
val acc ↑↑↑ 然后趋于平稳

val loss开始上升 → 过拟合了！
两个loss都不降 → LR或数据有问题

  • 🔹 过拟合→加数据/正则化
  • 🔹 CNN用BatchNorm，Transformer用LayerNorm
  • 🔹 默认优化器：AdamW (lr=1e-3, wd=1e-4)
