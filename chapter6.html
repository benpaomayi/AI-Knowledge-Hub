损失函数：告诉模型错了多少

⏱ 15分50秒 · BV1jgGB6PE7S

💡 损失函数的作用

损失函数（Loss Function）是模型的"裁判"——它量化模型预测值与真实值之间的差距，告诉优化器应该往哪个方向调整参数。没有损失函数，模型就不知道自己错在哪里，也就无法学习。选择合适的损失函数是训练神经网络的关键第一步。

回归损失

📈 回归任务损失函数

  • MSE/L2损失：均方误差，对大误差惩罚重，梯度随误差减小而减小，收敛稳定
  • MAE/L1损失：平均绝对误差，对异常值鲁棒，但在零点处梯度不连续
  • Huber Loss：结合MSE和MAE优点，误差小时用MSE，误差大时用MAE
MSE = (1/n)Σ(yi - ŷi)²
MAE = (1/n)Σ|yi - ŷi|
分类损失

🎯 分类任务损失函数

  • 交叉熵Cross-Entropy：多分类首选，衡量两个概率分布的差异，配合Softmax使用
  • BCELogits Loss：二分类专用，内部包含Sigmoid，数值稳定性更好
  • 为什么分类用交叉熵而不用MSE？梯度特性——交叉熵在分类错误时梯度大，正确时梯度小，更适合概率输出
选择指南

📋 损失函数选择与自定义场景

回归问题：首选MSE；数据有异常值用Huber或MAE

多分类问题：CrossEntropyLoss（注意：不需要手动加Softmax，PyTorch内部已包含）

二分类问题：BCEWithLogitsLoss（比先Sigmoid再BCE更稳定）

自定义损失场景：

  • 多任务学习：多个损失加权求和
  • 不平衡数据：Focal Loss（难样本加权）
  • 领域特殊需求：如目标检测的IoU Loss

识别手写数字：PyTorch实战MNIST

⏱ 24分10秒 · BV1uPGj6fEQh

💡 MNIST——深度学习的"Hello World"

MNIST手写数字识别是深度学习入门的经典项目，相当于编程中的Hello World。通过这个实战，你将掌握PyTorch的核心工作流：数据加载→模型定义→训练循环→验证测试。重要的是理解框架本质，而不是死记API——PyTorch的核心就是张量运算+自动求导。

数据加载

📦 Dataset & DataLoader

  • Dataset：封装数据，实现__getitem__和__len__方法
  • DataLoader：批量加载、打乱顺序、多线程预取
  • torchvision.datasets内置MNIST等常用数据集
  • transforms.ToTensor()：将PIL图像转为[0,1]范围的张量
模型定义

🧩 nn.Module 网络定义

  • 继承nn.Module，在__init__中定义层
  • 实现forward方法定义前向传播
  • 简单MLP：Flatten→Linear→ReLU→Linear→ReLU→Linear(10)
  • 不用写反向传播——autograd自动计算梯度
# PyTorch MNIST 核心代码
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# 1. 设备配置（GPU加速）
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# 2. 定义简单MLP网络
class MLP(nn.Module):
  def __init__(self):
    super().__init__()
    self.flatten = nn.Flatten()
    self.layers = nn.Sequential(
      nn.Linear(28*28, 256), nn.ReLU(),
      nn.Linear(256, 128), nn.ReLU(),
      nn.Linear(128, 10)
    )
  def forward(self, x):
    return self.layers(self.flatten(x))

# 3. 训练循环：epoch → iteration
model = MLP().to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()
for epoch in range(10):
  for X, y in train_loader:
    X, y = X.to(device), y.to(device)
    pred = model(X)
    loss = criterion(pred, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

学习率：小小参数大影响

⏱ 24分16秒 · BV1NMVn6vE7o

💡 学习率是最重要的超参数

在所有超参数中，学习率对训练结果的影响最大。它控制参数更新的步长：步子太大容易跨过最优解来回震荡；步子太小收敛极慢甚至陷入局部最优。调参时第一个应该调的就是学习率。

学习率过大vs过小

⚠️ 学习率的影响

  • lr太大：loss震荡不收敛、甚至NaN（梯度爆炸）、在最优点附近来回跳
  • lr太小：收敛极慢、训练停滞、容易陷入局部最优、过拟合风险高
  • 合适的lr：loss稳定下降、快速收敛到较好的解
查找方法

🔍 LR Finder 学习率查找

从极小学习率开始，指数级增大lr，记录每个lr对应的loss，选loss下降最快那段的lr（通常取拐点前的值）。PyTorch Lightning等框架内置此功能。

不同任务推荐值：

  • Adam优化器：1e-3 ~ 3e-4（常用起点）
  • SGD+动量：1e-2 ~ 1e-1（需要更大初始lr）
  • Transformer微调：1e-5 ~ 5e-5（要小）
学习率调度

📉 学习率调度器与Warmup

常见调度器：

  • StepLR：固定步长衰减（如每30轮乘0.1）
  • CosineAnnealingLR：余弦退火，平滑下降到最小值
  • ReduceLROnPlateau：监控指标，停滞时自动降低lr

Warmup预热策略：

  • 训练开始时先用很小的lr，逐渐线性增大到设定值
  • 为什么？训练初期参数随机，大lr容易导致不稳定
  • Transformer等大模型必备技巧
  • 通常warmup步数占总步数的5%~10%

参数初始化：调参高手的秘诀

⏱ 17分14秒 · BV17i7Q6HEFt

💡 好的初始化是成功的一半

很多人忽略参数初始化，但初始值直接影响训练速度和最终效果。为什么不能全零初始化？——对称性问题：所有神经元初始状态相同，梯度更新也相同，永远学不出不同的特征，相当于只有一个神经元在工作。

Xavier初始化

⚖️ Xavier/Glorot初始化

保持前向传播和反向传播时的方差一致，防止信号逐层放大或缩小。

W ~ U(-√(6/(nin+nout)), √(6/(nin+nout)))
适合：Sigmoid、Tanh激活函数
PyTorch: nn.init.xavier_uniform_()
He初始化

🔥 He/Kaiming初始化

针对ReLU的非线性特性设计，考虑了ReLU会将一半神经元置零的情况。

W ~ N(0, √(2/nin))
适合：ReLU及其变体（LeakyReLU等）
PyTorch: nn.init.kaiming_normal_()
现代网络默认首选！
要点总结

📋 初始化方法对比与BatchNorm

  • 随机高斯：简单但方差需要手动调整，可能梯度消失/爆炸
  • Xavier：Sigmoid/Tanh时代的标准
  • He/Kaiming：ReLU网络的最佳选择
  • 合适的初始化能大幅加快收敛速度

BatchNorm降低对初始化的敏感度：

Batch Normalization层将每层输出归一化到均值0方差1，大大缓解了不好的初始化带来的问题，使得网络更容易训练。这也是为什么现代深度网络对初始化不那么敏感的重要原因。

归一化：Transformer都在用的训练技巧

⏱ 16分49秒 · BV1X2Ex6rEu9

💡 内部协变量偏移（ICS）

训练深度网络时，每一层参数更新都会改变下一层输入数据的分布——这就是内部协变量偏移。就像你在学射箭时，靶子一直在动，你永远也射不准。归一化层让每一层输入分布保持稳定，网络训练更快更稳定。

BatchNorm原理

📦 Batch Normalization

  • 对一个batch内的特征做：减均值→除方差→可学习缩放γ和平移β
  • 训练时：用当前batch的均值/方差，同时累计移动平均running mean/var
  • 测试时：用训练时累计的全局均值/方差，不依赖batch
  • 位置：通常放在Conv/Linear之后、激活函数之前（也有放在激活后的做法）
其他归一化

🔄 常用归一化方法

  • BatchNorm (BN)：沿batch维度归一化，batch小效果差，CNN常用
  • LayerNorm (LN)：沿特征维度归一化，不依赖batch大小，Transformer标配
  • InstanceNorm：每个样本每个通道单独归一化，风格迁移常用
  • GroupNorm：将通道分组后归一化，batch小时可替代BN
BN(x) = γ · (x - μbatch) / √(σbatch² + ε) + β
μbatch, σbatch²: 当前batch的均值和方差
γ, β: 可学习的缩放和平移参数（让网络有机会恢复原分布）
ε: 防止除零的小常数，通常1e-5

过拟合克星：深度学习正则化

⏱ 19分13秒 · BV1DHJ76SEmj

💡 深度学习的过拟合问题更严重

经典机器学习模型参数量通常是万级别，而深度神经网络动辄百万、千万甚至千亿参数——参数远大于数据量时，过拟合几乎必然发生。正则化就是一系列防止模型"死记硬背"训练数据、提高泛化能力的技术。

权重衰减

⚖️ L1/L2正则化 (Weight Decay)

  • L2正则化：在损失函数中加λΣw²，惩罚大权重，让权重趋向小值，最常用
  • L1正则化：加λΣ|w|，倾向于产生稀疏权重（很多w=0），可用于特征选择
  • PyTorch优化器中直接设置weight_decay参数（Adam默认0，SGD常用1e-4）
  • 直觉：小权重意味着模型更"简单"，不容易拟合噪声
Dropout

🎲 Dropout随机失活

  • 训练时：以概率p（通常0.5）随机将神经元输出置零
  • 推理时：所有神经元都用，但输出要乘以(1-p)缩放（或训练时除以1-p——Inverted Dropout）
  • 为什么有效：防止神经元之间"共谋"，强迫网络学习鲁棒特征，类似集成学习的效果
  • Dropout率选择：隐藏层0.2~0.5，输入层0.1~0.2
其他正则化

🛡️ 更多正则化方法

数据增强（Data Augmentation）：

  • 图像：随机裁剪、翻转、旋转、颜色抖动、Mixup、Cutout
  • 文本：同义词替换、随机删除、回译
  • 最便宜最有效的正则化！ 本质是增加训练数据

Early Stopping早停：

  • 监控验证集性能，当验证集loss不再下降时停止训练
  • 保存验证集表现最好的checkpoint
  • 简单有效，几乎是训练标配

还有：标签平滑、DropConnect、随机深度（Stochastic Depth）等

如何训练一个深度学习模型

⏱ 26分28秒 · BV1FmJJ6rEqS

💡 训练DL模型是系统工程

很多新手调参靠"玄学"——瞎试、凭感觉。实际上训练深度学习模型有科学的流程和方法论。掌握了这套方法论，你就能系统地诊断问题、有针对性地调参，而不是乱猜。调参也是有优先级的，不要一上来就改网络结构。

全流程

🗺️ 深度学习训练完整流程

1️⃣ 数据准备

数据清洗训练/验证/测试划分数据归一化DataLoader配置数据增强类别不平衡处理

2️⃣ 模型构建

选择网络结构参数初始化(He/Xavier)前向传播测试参数量统计转移到GPU

3️⃣ 训练配置

损失函数选择优化器(Adam/SGD)学习率设置学习率调度器正则化配置

4️⃣ 训练循环

前向传播算loss反向传播算梯度梯度裁剪参数更新验证集评估保存best模型TensorBoard可视化
常见问题

🔧 问题诊断指南

  • Train loss不下降：学习率太大/太小、初始化问题、梯度爆炸（加梯度裁剪）、数据/标签有问题、优化器错了
  • Train loss下降但Val loss上升：过拟合！加正则化/数据增强/Early Stopping/减少模型复杂度
  • 收敛太慢：增大学习率、换更好的优化器（Adam）、检查数据归一化
  • 出现NaN：学习率太大梯度爆炸、除零、loss计算有问题（如log(0)）
调参优先级

🎯 调参顺序建议

按这个顺序调，效率最高：

  1. 1️⃣ 学习率 & 优化器 🔝 最重要！
  2. 2️⃣ Batch size
  3. 3️⃣ 正则化（weight decay/dropout）
  4. 4️⃣ 网络结构（层数/宽度）
  5. 5️⃣ 其他trick（初始化/激活函数/调度器）

记住：从一个能work的baseline开始，每次只改一个变量，做对照实验！
