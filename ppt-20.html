前向传播回顾

数据从输入层流向输出层，得到预测值

输入X → z¹ = W¹a⁰ + b¹ → a¹ = g(z¹) → z² = W²a¹ + b² → a² = g(z²) → ... → ŷ = aᴸ 前向传播是"推理"过程：逐层做线性变换(z=Wa+b)，再通过激活函数g做非线性变换，最终得到预测ŷ。

损失函数：衡量预测有多差

L(ŷ, y)告诉我们当前预测和真实值的差距

📉 回归问题：MSE

L = (1/2)||ŷ - y||²

均方误差，预测值和真实值差的平方和（系数1/2为求导方便）

📊 分类问题：交叉熵

L = -Σ yᵢ log(ŷᵢ)

交叉熵损失，衡量两个概率分布的差异

🎯 训练目标

我们的目标是找到一组参数W,b，让损失L尽可能小。梯度下降告诉我们：沿着梯度反方向更新参数，损失就会减小。问题是——怎么高效计算所有参数的梯度？

为什么需要反向传播？

直接逐层求导太复杂，链式法则从输出往回算更高效

❌ 蛮力求导

  • 对每个参数w，直接用定义求偏导
  • 需要重复计算大量中间结果
  • 时间复杂度：O(N²)甚至更高
  • 百万参数时完全不可行
VS

✅ 反向传播

  • 利用链式法则，从输出层往回算
  • 中间结果只算一次，重复利用
  • 时间复杂度：O(N)，和前向传播同阶
  • 一次前向+一次反向，算出所有梯度

💡 核心洞察

反向传播不是什么神秘的魔法——它就是链式法则 + 动态规划！把大问题拆成小问题，复用中间结果，避免重复计算。

微积分基础：链式法则

反向传播的数学核心——复合函数求导

如果 y = f(g(x))，那么 dy/dx = (dy/dg) · (dg/dx) 这就是链式法则(Chain Rule)：复合函数的导数，可以拆成每个简单函数导数的乘积。

🌰 举个栗子

如果 L = (1/2)(ŷ - y)²，而 ŷ = σ(z)，z = wx + b

∂L/∂w = (∂L/∂ŷ) · (∂ŷ/∂z) · (∂z/∂w) = (ŷ-y) · σ'(z) · x

一层一层"剥开"求导，最后乘起来——这就是链式法则的力量！

🔑 关键理解

链式法则告诉我们：一个参数对最终损失的"贡献"，等于它对每一层影响的乘积。误差从输出端一层层"传"回来，这就是"反向传播"名字的由来。

➡️ 前向传播

从左到右，顺着箭头方向计算，记录每个节点的输出值（激活值）。

⬅️ 反向传播

从右到左，逆着箭头方向计算，利用链式法则求每个节点对L的偏导数（梯度）。

💾 为什么要"记录"？

反向传播计算梯度时，需要用到前向传播时的中间结果（比如aˡ、zˡ）。所以前向传播时必须把这些值存下来，这也是训练神经网络比推理更占显存的原因之一。

反向传播四步法

标准流程，记住这四步就够了

步骤1：前向传播 输入X，逐层计算所有zˡ和aˡ，直到得到预测ŷ和损失L。把所有中间值都存下来！
步骤2：输出层误差δᴸ 计算输出层的"误差项"δᴸ = ∂L/∂zᴸ = (aᴸ - y) ⊙ g'(zᴸ)（MSE损失+σ激活时）
步骤3：反向传播误差 从后往前逐层计算δˡ = ((Wˡ⁺¹)ᵀ δˡ⁺¹) ⊙ g'(zˡ)，l = L-1, L-2, ..., 1
步骤4：计算梯度 ∂L/∂Wˡ = δˡ (aˡ⁻¹)ᵀ，∂L/∂bˡ = δˡ。有了梯度就可以梯度下降更新参数了！

误差项δˡ的含义

理解δˡ是什么，比记住公式更重要

δˡ = ∂L / ∂zˡ δˡ（delta）是损失L对第l层线性输出zˡ的偏导数。它衡量的是：第l层的zˡ变化一点点，损失L会变化多少——也就是这一层"贡献"了多少误差。

🔴 输出层 δᴸ

直接衡量预测值和真实值的差距。误差"发源"的地方。

🟠 隐藏层 δˡ

通过Wˡ⁺¹把后一层的误差"传"回来，再乘以本层激活函数的导数。

🟡 参数梯度

∂L/∂Wˡ = δˡ(aˡ⁻¹)ᵀ——本层误差乘以前一层激活，就是权重的梯度。

🤔 直觉理解

想象团队做项目出了bug：先找到直接责任人（输出层），然后根据每个人的"贡献度"（权重W），把责任一层层追溯回去——每个人为自己造成的那部分错误负责，然后调整自己（更新参数）。

数值示例：手算一个2层网络

用具体数字走一遍反向传播，加深理解

📋 网络设置

• 输入x=0.5，真实标签y=1.0（简单回归）
• 1个隐藏层，1个隐藏神经元，w₁=0.2, b₁=0.1, w₂=0.4, b₂=0.2
• 激活函数用sigmoid: σ(z)=1/(1+e⁻ᶻ)
• 损失函数L=(1/2)(ŷ-y)²

✅ 步骤1：前向传播

z₁ = w₁x + b₁ = 0.2×0.5 + 0.1 = 0.2
a₁ = σ(z₁) = 1/(1+e⁻⁰·²) ≈ 0.5498
z₂ = w₂a₁ + b₂ = 0.4×0.5498 + 0.2 ≈ 0.4199
ŷ = a₂ = σ(z₂) ≈ 0.6034
L = 0.5×(0.6034-1.0)² ≈ 0.0786

数值示例：反向计算梯度

接上页，计算δ₂、δ₁和各参数梯度

✅ 步骤2：输出层误差δ₂

sigmoid导数：σ'(z) = σ(z)(1-σ(z))
δ₂ = ∂L/∂z₂ = (a₂ - y)·σ'(z₂) = (0.6034-1.0)×0.6034×(1-0.6034) ≈ -0.3966×0.2393 ≈ -0.0949

✅ 步骤3：隐藏层误差δ₁

δ₁ = (w₂ᵀ·δ₂)·σ'(z₁) = (0.4×(-0.0949))×0.5498×(1-0.5498) ≈ -0.0380×0.2475 ≈ -0.0094

✅ 步骤4：计算梯度

∂L/∂w₂ = δ₂·a₁ = -0.0949×0.5498 ≈ -0.0522
∂L/∂b₂ = δ₂ ≈ -0.0949
∂L/∂w₁ = δ₁·x = -0.0094×0.5 ≈ -0.0047
∂L/∂b₁ = δ₁ ≈ -0.0094

数值示例：梯度下降更新

用算出的梯度更新参数，看损失是否下降

📊 参数更新（学习率η=0.5）

w₂ = w₂ - η·∂L/∂w₂ = 0.4 - 0.5×(-0.0522) = 0.4 + 0.0261 = 0.4261
b₂ = 0.2 - 0.5×(-0.0949) = 0.2475
w₁ = 0.2 - 0.5×(-0.0047) = 0.2024
b₁ = 0.1 - 0.5×(-0.0094) = 0.1047

🎉 验证损失下降了！

用新参数重新前向传播：
z₁=0.2024×0.5+0.1047≈0.2059, a₁≈0.5513
z₂=0.4261×0.5513+0.2475≈0.4824, ŷ≈0.6183
L=0.5×(0.6183-1.0)²≈0.0729 ← 比之前的0.0786小了！

💡 注意

这只是一次更新！实际训练要重复成千上万次：前向→反向→更新→前向→...直到损失收敛。

为什么激活函数必须可导？

不可导的激活函数，反向传播就失效了

❌ 阶跃函数（不可导）

  • f(x) = 1 if x>0 else 0
  • 除了x=0处，导数都是0！
  • δˡ = ... ⊙ g'(zˡ) = ... ⊙ 0 = 0
  • 梯度全是0，参数无法更新
  • 这就是为什么感知机只能有一层
VS

✅ Sigmoid/ReLU（可导）

  • 几乎处处可导（ReLU在x=0处不可导，但不影响）
  • g'(z)大部分时候不为0
  • 误差信号可以顺利传回去
  • 多层网络才能训练
  • 这是深度学习能"深"的关键！

⚠️ 历史教训

为什么深度学习在2006年才开始爆发？除了算力和数据，一个重要原因是人们早年用sigmoid/tanh，网络一深就梯度消失，根本训不动。直到ReLU出现，深层网络才真正能训练起来。

梯度消失问题(Vanishing Gradient)

深层网络训练的头号敌人

δˡ = (Wˡ⁺¹)ᵀ(Wˡ⁺²)ᵀ...(Wᴸ)ᵀδᴸ ⊙ g'(zˡ)⊙g'(zˡ⁺¹)...⊙g'(zᴸ⁻¹) 反向传播中，梯度是很多项相乘的结果。如果每一层的导数g'(z)都小于1（比如sigmoid最大0.25），乘的层数多了，梯度就会指数级衰减到接近0。
📉

Sigmoid梯度消失

σ'(x)最大值只有0.25（在x=0处），两端饱和时导数趋近于0。

10层后：0.25¹⁰ ≈ 10⁻⁶——梯度几乎为0！
前面的层（靠近输入的层）根本学不到东西。

⚡

ReLU缓解问题

ReLU(x)=max(0,x)，正区间导数g'(x)=1！

只要神经元不"死亡"，正区间梯度能无损传回去，不会衰减。

这就是为什么ReLU是现代深度学习的默认激活函数。

梯度爆炸问题(Exploding Gradient)

和梯度消失相反，但同样危险

💥 怎么发生的？

如果权重W初始化得太大，或者W的取值大于1，反向传播时梯度连乘会导致梯度指数级增长，变得非常大。

📊 梯度爆炸的症状

损失变成NaN 参数更新剧烈震荡 模型完全不收敛 损失一开始就很大

🛠️ 解决方案

1. 合理的权重初始化——Xavier/He初始化，让W不要太大也不要太小
2. 梯度裁剪(Gradient Clipping)——设置阈值，梯度超过就截断
3. Batch Normalization——让每层输入分布稳定，间接缓解梯度问题
4. 残差连接(ResNet)——提供梯度"高速公路"，直接传回去

PyTorch自动微分：autograd

你不需要手写反向传播！PyTorch自动帮你算

🔑 核心概念

  • requires_grad=True：告诉PyTorch这个tensor需要追踪梯度
  • .backward()：在损失tensor上调用，自动计算所有梯度
  • .grad：反向传播后，梯度存在这个属性里
  • with torch.no_grad()：推理时不需要追踪梯度，节省显存和计算
import torch # 定义需要梯度的参数 w = torch.tensor([0.2], requires_grad=True) b = torch.tensor([0.1], requires_grad=True) x = torch.tensor([0.5]) y = torch.tensor([1.0]) # 前向传播：自动构建计算图 y_pred = torch.sigmoid(w * x + b) loss = 0.5 * (y_pred - y)**2 # 反向传播：自动计算所有梯度！ loss.backward() # 查看梯度 print(w.grad) # ∂L/∂w，和我们手算的一致 print(b.grad) # ∂L/∂b

代码示例：手写2层网络前向反向

用NumPy手动实现，理解底层原理

import numpy as np def sigmoid(z): return 1 / (1 + np.exp(-z)) def sigmoid_grad(a): return a * (1 - a) # 初始化参数 W1 = np.random.randn(2, 3) # 输入2→隐藏3 b1 = np.zeros((3, 1)) W2 = np.random.randn(1, 3) # 隐藏3→输出1 b2 = np.zeros((1, 1)) def forward_backward(X, y, W1, b1, W2, b2): # 前向 z1 = W1 @ X + b1 a1 = sigmoid(z1) z2 = W2 @ a1 + b2 a2 = sigmoid(z2) # 反向 dz2 = a2 - y dW2 = dz2 @ a1.T db2 = np.sum(dz2, axis=1, keepdims=True) dz1 = (W2.T @ dz2) * sigmoid_grad(a1) dW1 = dz1 @ X.T db1 = np.sum(dz1, axis=1, keepdims=True) return a2, dW1, db1, dW2, db2

代码示例：PyTorch autograd自动求导

用PyTorch实现同样的网络，不用手写反向传播

import torch import torch.nn as nn # 定义网络（PyTorch风格） class SimpleNet(nn.Module): def __init__(self): super().__init__() self.fc1 = nn.Linear(2, 3) # 2→3 self.fc2 = nn.Linear(3, 1) # 3→1 self.sigmoid = nn.Sigmoid() def forward(self, x): x = self.sigmoid(self.fc1(x)) x = self.sigmoid(self.fc2(x)) return x model = SimpleNet() criterion = nn.MSELoss() optimizer = torch.optim.SGD(model.parameters(), lr=0.1) # 训练一步 X = torch.randn(1, 2) y = torch.tensor([[1.0]]) optimizer.zero_grad() # 梯度清零 y_pred = model(X) # 前向（自动构图） loss = criterion(y_pred, y) # 算损失 loss.backward() # 反向（自动算梯度！） optimizer.step() # 更新参数

训练循环：完整流程

把前向、反向、更新串起来，就是完整的训练

0. 初始化 随机初始化W,b；选择优化器、学习率；准备数据
循环N个epoch：
1. 梯度清零 optimizer.zero_grad()——PyTorch梯度会累加，不清零会出错
2. 前向传播 y_pred = model(X)——得到预测值
3. 计算损失 loss = criterion(y_pred, y)——衡量预测好坏
4. 反向传播 loss.backward()——autograd自动计算所有梯度
5. 参数更新 optimizer.step()——沿梯度反方向更新W,b

反向传播直觉：责任分摊

用一个生活类比来理解反向传播

🏢 公司项目类比

想象一个公司：CEO（输出层）→ 总监（隐藏层2）→ 经理（隐藏层1）→ 员工（输入层附近）。

项目搞砸了，损失了100万（损失L）：
1. 首先问责CEO：CEO负直接责任（输出层误差δᴸ）
2. CEO追溯责任：根据各个总监的"贡献度"（权重W），把责任分配下去
3. 总监再分配：每个总监再根据自己下属经理的贡献度，继续往下分配责任
4. 每个人负责任：每个人根据自己分到的责任大小（梯度），调整自己的工作方式（更新参数）

🎯 关键

没有人是"无辜"的，也没有人承担全部责任——每个人根据自己在整个流程中的"贡献"，承担相应的责任。这就是反向传播的本质：信用分配(Credit Assignment)问题。

常见误区澄清

这些问题很多初学者都会搞错

❌ 误区1：反向传播是一种优化算法？

不是！反向传播只是用来计算梯度的方法。梯度下降（或Adam等优化器）才是用梯度来更新参数的优化算法。反向传播+梯度下降，才是完整的训练流程。

❌ 误区2：反向传播很神秘/很复杂？

一点都不！反向传播本质就是链式法则 + 缓存中间结果，没有任何新的数学。如果你懂微积分的链式求导，你就懂反向传播的原理了。

❌ 误区3：我必须能手推反向传播才能用深度学习？

不需要！就像你不需要会写编译器也能写代码一样，你不需要手推反向传播（PyTorch帮你做了）。但理解原理很重要——这样你遇到梯度消失/爆炸、训练不收敛等问题时，才知道怎么排查。

检查梯度：数值梯度校验

写反向传播时，如何验证自己算对了？

数值梯度：∂L/∂w ≈ [L(w+ε) - L(w-ε)] / (2ε) 用导数的定义（双边差分）来近似计算梯度。ε取很小的值（如1e-5），然后和你解析算出来的梯度比较，如果相对误差小于1e-7，基本就是对的。
def grad_check(f, w, eps=1e-5): # f是计算损失的函数，w是参数 num_grad = np.zeros_like(w) it = np.nditer(w, flags=['multi_index'], op_flags=['readwrite']) while not it.finished: idx = it.multi_index old_val = w[idx] w[idx] = old_val + eps loss_plus = f(w) w[idx] = old_val - eps loss_minus = f(w) w[idx] = old_val num_grad[idx] = (loss_plus - loss_minus) / (2*eps) it.iternext() return num_grad

✅ 实用建议

自己写反向传播时，一定要用梯度校验！这是最可靠的debug方法。当然，用PyTorch autograd就不需要担心这个了。
