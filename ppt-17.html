为什么需要环境管理？

做项目第一件事：隔离环境，避免"依赖地狱"

😱 常见的"依赖地狱"场景

• 项目A需要Python 3.8 + PyTorch 1.0，项目B需要Python 3.10 + PyTorch 2.0
• 装了一个新库，把原来项目依赖的库版本给覆盖了
• 把系统自带Python搞坏了，导致系统工具出问题
• 换一台电脑，环境搭不起来，代码跑不动

❌ 不做环境管理

所有包都装在全局环境，版本互相冲突，今天A项目跑了明天B项目崩。重装系统都解决不了问题。

✅ 使用虚拟环境

每个项目有独立的环境，互不干扰。想装什么版本就装什么版本，不会搞坏系统Python，换电脑也能一键复现。

🎯 核心思想

虚拟环境就是给每个项目一个"独立房间"，每个房间里的东西互不影响。Anaconda就是管理这些"房间"的工具。

Anaconda vs Miniconda：怎么选？

两个都是conda，只是预装包多少的区别

🐍

Anaconda（大而全）

Python数据科学"全家桶"发行版

  • 预装1500+数据科学包（numpy/pandas/sklearn/jupyter等）
  • 安装包约800MB，安装后占空间几个GB
  • 图形化界面Anaconda Navigator，对新手友好
  • 适合：初学者、不想自己装包
⚡

Miniconda（轻量级）

精简版，只有Python+conda+少量基础包

  • 只预装最基本的包，其他需要自己装
  • 安装包约50MB，小巧轻便
  • 纯命令行操作，没有图形界面
  • 适合：有基础、想自己控制包、节省空间

💡 新手建议

第一次装直接选Anaconda就好，省事，不用一个个装常用包。等你熟悉了再考虑Miniconda。两者的conda命令是完全一样的，学会一个另一个自然就会。

安装过程注意事项（重点！）

这几个选项选错了，后面会出问题

❌ Windows特别注意：PATH选项

安装到"Advanced Installation Options"这一步时，一定要勾选"Add Anaconda3 to my PATH environment variable"！虽然它说"not recommended"，但勾上能省很多事。不勾的话终端找不到conda命令。

⚠️ 安装路径

路径中不要有中文和空格！比如不要装在"D:\我的软件\Anaconda"，最好装在"D:\anaconda3"或"C:\anaconda3"这种纯英文路径下，避免出现奇怪的编码问题。

🍎 Mac/Linux用户

Mac选对应芯片版本（Intel还是M1/M2/M3）。下载.pkg文件（Mac）或.sh文件（Linux），按向导一步步点继续就行，默认设置即可。Mac安装完需要重启终端才能用conda命令。

✅ 验证安装成功

安装完成后：
Windows：打开"Anaconda Prompt"，输入conda --version
Mac/Linux：打开终端，输入conda --version
如果显示版本号（比如conda 23.x.x），就说明安装成功了！

Conda虚拟环境核心命令

这几个命令记牢，环境管理不用愁

# 1. 创建虚拟环境（指定Python版本）
conda create -n dl python=3.10

# 2. 激活/进入环境（Windows用Anaconda Prompt）
conda activate dl

# 3. 退出当前环境
conda deactivate

# 4. 查看所有环境
conda env list

🎯 我们现在就来创建第一个环境！

打开终端/Anaconda Prompt，输入上面第一条命令，创建一个叫dl（deep learning的缩写）的环境，Python版本用3.10（兼容性好）。输入y确认，等待安装完成。

配置国内镜像源（必做！）

解决conda/pip下载慢、超时失败的问题

🐢 为什么配置镜像？

conda默认从国外服务器下载包，在国内速度非常慢，几KB/s甚至超时失败。配置国内清华/中科大镜像源后，下载速度能提升几十上百倍！

# 配置清华conda镜像（复制粘贴执行这4行命令）
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge
conda config --set show_channel_urls yes

✅ 验证配置

输入conda config --show channels，如果能看到刚才加的几个清华地址，说明配置成功。以后用conda install安装包就会走国内镜像，飞一般的速度！

pip vs conda：两个包管理器的区别

搞清楚什么时候用pip，什么时候用conda

对比维度 pip conda
出身 Python官方包管理器 Anaconda自带的包管理器
支持语言 只能管Python包 Python/C/C++/R等跨语言包
虚拟环境 需要配合virtualenv/venv 自带虚拟环境管理功能
包数量 PyPI有几十万包，最全 Anaconda仓库相对少一些
二进制包 需要编译（wheel） 预编译二进制，安装快
检查依赖 依赖检查不严格，可能装冲突 严格检查依赖，确保兼容

💡 实际使用建议

优先用conda装（numpy/pandas/scipy等科学计算包，PyTorch官方也推荐conda），conda没有的再用pip装。两者可以混用，不用太纠结。

CPU版 vs GPU版：怎么选？

Compute Platform这里选对，速度差10-100倍！

💻 CPU版

Compute Platform选"CPU"

  • 适合：没有NVIDIA显卡、Mac用户（M系列芯片也支持MPS加速）、只是入门学习
  • 优点：安装简单，不用装CUDA，兼容性好
  • 缺点：训练速度慢，大模型跑不动
  • 入门学习小模型（如MNIST）足够用

⚡ GPU版（推荐！）

Compute Platform选CUDA版本（如CUDA 11.8、12.1）

  • 适合：电脑有NVIDIA独立显卡（GTX/RTX系列）
  • 优点：训练速度快10-100倍，大模型必备
  • 注意：只有NVIDIA显卡支持CUDA！AMD/Intel显卡不行，Mac也不行
  • 选哪个CUDA版本？选11.8或12.1都行，PyTorch自带CUDA，不用你提前装！

🍎 Mac用户注意

Mac没有NVIDIA显卡，但M1/M2/M3芯片支持Metal Performance Shaders (MPS)后端，PyTorch也能加速。选CPU版安装就行，PyTorch会自动识别MPS。

# CPU版安装命令（示例）

CUDA与cuDNN是什么？

GPU加速背后的功臣，了解一下

⚡

CUDA

NVIDIA推出的并行计算平台和编程模型，让开发者能用NVIDIA的GPU做通用计算（不只是打游戏）。可以理解为"GPU的操作系统"，让程序能调用GPU的计算能力。

好消息：用conda装pytorch-cuda会自动安装CUDA运行时，你不需要单独装CUDA Toolkit！

🚀

cuDNN

NVIDIA打造的深度神经网络加速库（CUDA Deep Neural Network library），针对卷积、池化、归一化等深度学习常用操作做了极致优化。

同样，conda安装PyTorch的时候也会自动带上cuDNN，不用你单独装！

✅ 总结一下

以前装PyTorch GPU版需要提前装对应版本的CUDA和cuDNN，很麻烦。现在用conda安装pytorch-cuda，它会把需要的CUDA和cuDNN都打包在环境里，和系统其他部分隔离，非常省心！

验证安装：PyTorch装成功了吗？

三行代码验证，确保一切正常

# 打开终端，激活dl环境，输入python进入交互式环境
# 然后依次输入以下代码：

import torch
print(torch.__version__)   # 应该打印出版本号，比如2.1.0
print(torch.cuda.is_available())   # GPU版返回True，CPU版返回False

🎉 如果看到这些，说明安装成功！

第一行打印出版本号（如2.0.1、2.1.2），说明PyTorch能正常导入；
第二行如果你装的是GPU版，应该返回True——说明PyTorch能识别并使用你的GPU！
如果返回False，说明GPU没识别到，检查你是不是装了CPU版，或者显卡驱动/CUDA版本有问题。

Mac用户：验证MPS加速

M系列芯片的Mac也能用GPU加速！

import torch
print(torch.__version__)
print(torch.backends.mps.is_available())   # M系列芯片应该返回True
print(torch.backends.mps.is_built())   # 确认PyTorch编译了MPS支持

🍎 MPS怎么用？

以后写代码的时候，把device设为"mps"就行，就像N卡用"cuda"一样：
device = torch.device("mps" if torch.backends.mps.is_available() else "cpu")
model = model.to(device)
data = data.to(device)

速度比纯CPU快不少，入门学习足够用了！

常见问题1：网络问题/下载超时

90%的安装问题都是网络导致的

🐢 症状

conda install/pip install的时候卡在"Solving environment"或者下载速度几KB/s，或者报HTTP error、timeout错误。

✅ 解决方案

  • 方案1：配置国内镜像源——前面已经讲过，配置清华conda和pip镜像，这是首选方案
  • 方案2：换pip安装——如果conda还是慢，改用pip安装PyTorch，加国内镜像-i参数
  • 方案3：离线安装——去清华镜像手动下载whl文件，然后pip install 本地文件路径
  • 方案4：用手机热点——有些公司/校园网有限制，换手机4G/5G热点往往就好了

❌ 不要反复重试！

如果下载失败了，不要马上重试，先换源或者检查网络。反复重试会让conda缓存很多损坏的包，反而更麻烦。必要时可以conda clean --all清缓存再试。

常见问题2：CUDA不匹配/识别不到GPU

torch.cuda.is_available()返回False？看这里

🔍 一步步排查

  • 第1步：确认你有NVIDIA显卡——任务管理器→性能，看有没有NVIDIA GPU。AMD/Intel核显不行，Mac也没有CUDA。
  • 第2步：确认驱动装好了——命令行输入nvidia-smi，能看到驱动版本和显卡信息说明正常。如果提示找不到命令，去NVIDIA官网装最新驱动。
  • 第3步：确认装的是GPU版PyTorch——conda list看pytorch后面有没有cuda字样，或者看你装的是不是cpuonly版本。如果装了CPU版，先卸载（conda remove pytorch）再重装GPU版。
  • 第4步：重启试试——刚装完驱动有时候需要重启电脑。

💡 给新手的安心话

就算GPU版暂时装不好也没关系，先用CPU版学，前几集的小例子CPU也能跑。环境问题不是核心知识点，不要在这里卡太久，先往前走，等熟悉了再回来折腾GPU。

3. 手动把Anaconda3和Anaconda3/Scripts加入系统环境变量PATH

⚠️ Permission denied / 权限错误

Mac/Linux用户常见。

解决方案：
1. 不要用sudo pip install！会装到系统Python去
2. 确认你激活了虚拟环境，在自己的dl环境里装
3. Mac如果提示权限问题，检查文件夹权限设置
4. Windows用管理员身份运行Anaconda Prompt试试

🔄 终极解决方案：重建环境

如果环境搞乱了不知道怎么修，最简单的办法：conda deactivate退出环境，conda remove -n dl --all删掉旧环境，然后从头create一个新环境。反正也不麻烦，10分钟就能搞定，比排查问题还快。
