回顾：分类 vs 回归

两类监督学习问题的核心区别

📈 回归问题

  • 预测连续值
  • 输出是一个实数
  • 例如：房价、身高、温度、销售额
  • 损失函数：MSE（均方误差）
  • 代表算法：线性回归
  • 评估：MAE、RMSE、R²
VS

🏷️ 分类问题

  • 预测离散类别
  • 输出是类别标签
  • 例如：垃圾邮件、疾病诊断、图像识别
  • 损失函数：交叉熵（对数损失）
  • 代表算法：逻辑回归（本章）
  • 评估：准确率、精确率、召回率、AUC

💡 关键区别

回归预测"多少"，分类预测"是哪一个"。二分类问题（只有两个类别）是最基础也是最常见的分类问题，我们从二分类开始讲起。

为什么线性回归不适合分类？

两个核心问题：输出范围不对 + 对离群点敏感

⚠️ 问题一：输出范围是 (-∞, +∞)

分类问题我们需要的是概率——样本属于某个类别的可能性，范围必须在0到1之间。但线性回归的输出可以是任意实数，负数、大于1的数都可能出现，这些值没法解释成概率。

⚠️ 问题二：对离群点极其敏感

线性回归用MSE损失，一个离群点就能把整条直线"拉歪"，导致决策边界剧烈变化，分类结果很不稳定。

🔍 直观理解

想象一下：我们用0表示负类，1表示正类，用线性回归拟合：

  • 正常情况下，可能中间值在0.5附近
  • 但如果加一个离群点，比如某个正类样本特征值特别大
  • 直线为了拟合这个点，斜率会变得很平缓
  • 导致原来很多应该判为正类的样本被误判为负类
  • 这在医疗、金融等场景是不可接受的

💡 怎么办？

我们需要一个函数，能把线性回归的输出 (-∞, +∞) "压缩"到 (0, 1) 之间，变成可以解释的概率。这个函数就是——Sigmoid函数！

Sigmoid函数登场

神奇的S形曲线——把任意值映射到0-1之间

$$\displaystyle \sigma (z) = 1 / (1 + e^{-z})$$ 这就是Sigmoid函数，也叫Logistic函数。它的输入z可以是任意实数，输出永远在(0,1)开区间内。

Sigmoid函数的特性非常完美地解决了我们的问题：

  • 单调递增：输入z越大，输出σ(z)越接近1；z越小，越接近0
  • 压缩映射：无论z是-1000还是+1000，输出都在0到1之间
  • 光滑可导：函数曲线平滑，处处可导，这对梯度下降优化很重要

✨ 完美的概率转换器

Sigmoid的输出可以直接解释为"样本属于正类的概率"。比如σ(z)=0.8就表示80%概率是正类，σ(z)=0.2就表示20%概率是正类（也就是80%概率是负类）。

Sigmoid函数的导数

为什么Sigmoid适合梯度下降？因为它的导数有简洁形式

$$\displaystyle \sigma '(z) = \sigma (z) \cdot (1 - \sigma (z))$$ 这是Sigmoid函数一个非常优美的数学性质：它的导数可以用自身来表示！这大大简化了梯度下降的计算。

我们来验证几个点：

  • z=0时，σ(z)=0.5，导数=0.5×0.5=0.25（曲线最陡）
  • z很大或很小时，σ(z)接近0或1，导数接近0（曲线平缓）

⚠️ Sigmoid的缺点（了解即可）

当z非常大或非常小时，导数趋近于0，这会导致"梯度消失"问题，在深度神经网络中这是个麻烦。但在逻辑回归这个简单模型里，它完全够用，而且工作得很好。

$$\displaystyle \hat{y} = \sigma (w^{T}x + b) = 1 / (1 + e^{-(wT}x + b))$$ ŷ 表示样本 x 属于正类（y=1）的概率，即 P(y=1|x) = ŷ，那么属于负类的概率就是 P(y=0|x) = 1 - ŷ。

决策边界

模型如何从概率得到最终分类结果？

🎯 决策规则（默认阈值0.5）

如果 ŷ ≥ 0.5 → 预测为正类 (y=1)
如果 ŷ < 0.5 → 预测为负类 (y=0)

🔍 等价条件

因为 ŷ = σ(z)，且Sigmoid单调递增，
ŷ ≥ 0.5 等价于 z ≥ 0

即：wTx + b ≥ 0 → 正类
　　wTx + b < 0 → 负类

📐 线性决策边界

方程 wTx + b = 0 就是决策边界：

  • 二维特征时，它是一条直线
  • 三维特征时，它是一个平面
  • 更高维时，它是一个超平面

这意味着：逻辑回归只能处理线性可分的问题！

如果两类数据不能用一条直线分开，逻辑回归就分类不好。这是它的局限性。

💡 阈值可以调整！

0.5只是默认阈值，不是必须的。在疾病诊断中，"漏诊"代价很高，我们会降低阈值（比如0.3）——宁可多误诊，也不要漏掉真病人；在垃圾邮件过滤中，"误判正常邮件为垃圾"代价高，我们会提高阈值（比如0.7）。

逻辑回归用什么损失函数？

线性回归用MSE，逻辑回归能直接用MSE吗？

❌ 不能！MSE在逻辑回归中是非凸函数

如果我们用MSE作为损失函数：L = (1/2)(ŷ - y)²，其中ŷ=σ(wx+b)是Sigmoid嵌套线性函数，这个损失函数关于参数w和b不是凸函数——它有很多局部最优点，梯度下降很容易卡在局部最优，找不到全局最优解。

我们需要一个凸函数作为损失，这样梯度下降一定能找到全局最优。这个损失函数就是——交叉熵损失（Cross-Entropy Loss），也叫对数损失（Log Loss）。

MSE损失

非凸 → 局部最优问题
不适合分类

→

交叉熵损失

凸函数 → 全局最优
专门为分类设计

单个样本的交叉熵损失

直观理解：预测越错，惩罚越大

$$\displaystyle L = -[ y \cdot log(\hat{y}) + (1 - y) \cdot log(1 - \hat{y}) ]$$

当真实标签 y = 1（正类）时：

L = -log(ŷ)

• ŷ越接近1（预测对了），L越接近0
• ŷ越接近0（预测错了），L趋向+∞

预测越自信地错，惩罚越大！

当真实标签 y = 0（负类）时：

L = -log(1 - ŷ)

• ŷ越接近0（预测对了），L越接近0
• ŷ越接近1（预测错了），L趋向+∞

同样，预测越错惩罚越大！

🎯 为什么用log？

因为log是单调递增函数，而且把概率的乘法变成加法（数学上方便），最重要的是：它完美地实现了"预测错就重罚"这个目标，而且整个函数是凸的，梯度下降好优化。

整体损失函数

所有样本的损失取平均

$$\displaystyle J(w, b) = -(1/n) \sum _{i=1}^{n} [ y^{(i)} \cdot log(\hat{y}^{(i)}) + (1 - y^{(i)}) \cdot log(1 - \hat{y}^{(i)}) ]$$ 这就是逻辑回归的整体损失函数（代价函数）。我们的目标就是找到 w 和 b，使得 J(w, b) 最小化。

和线性回归求解参数的思路一样：

  • 初始化 w=0, b=0
  • 用梯度下降法不断更新 w 和 b
  • 每次更新沿着梯度反方向走，让损失 J 减小
  • 直到收敛，就得到了最优参数

✨ 好消息

交叉熵损失是凸函数！没有局部最优，无论怎么初始化，梯度下降一定能找到全局最优解（只要学习率合适，迭代次数足够）。

为什么叫"逻辑"回归？

Logit变换——从概率到线性

很多人困惑：这明明是分类算法，为什么叫"逻辑回归"？而且"逻辑"又是什么意思？我们来解释这个名字的由来。

首先，"逻辑"来自Logit变换（对数几率变换）：

$$\displaystyle Logit(p) = log( p / (1 - p) ) = w^{T}x + b$$ 如果 p 是样本属于正类的概率，那么 p/(1-p) 叫"几率"（Odds），log(p/(1-p)) 叫"对数几率"（Log-odds / Logit）。逻辑回归实际上是在用线性回归拟合对数几率！

🔄 逆变换就是Sigmoid！

对 Logit(p) = z 做逆变换，就得到 p = 1/(1+e-z) = σ(z)，也就是我们之前的Sigmoid函数。所以：
逻辑回归 = 对对数几率做线性回归
这就是"逻辑回归"这个名字的由来。

那为什么叫"回归"？

历史原因：它确实是在"回归"一个连续值

📜 命名的历史

逻辑回归最早是统计学家在20世纪中期提出的。虽然我们今天主要用它来做分类，但从统计学角度看，它本质上是在回归（拟合）对数几率这个连续值——对数几率可以从 -∞ 到 +∞，确实是一个连续的回归目标。

⚠️ 重要提醒

逻辑回归是分类算法，不是回归算法！

这是机器学习初学者最容易搞混的一个点。名字里带"回归"只是历史原因，不要被名字误导。它预测的是类别（或者属于某类的概率），解决的是分类问题。

记住：

  • 线性回归 → 回归问题（预测连续值）
  • 逻辑回归 → 分类问题（预测类别/概率）

逻辑回归的优点

为什么它是工业界最常用的分类模型之一？

⚡

简单高效

模型简单，训练和预测速度都极快，尤其是在大数据量下表现很好，适合工业界高并发场景。

🔍

可解释性极强

每个特征的权重 w 都有明确含义：权重越大，这个特征对正类的贡献越大。这在金融、医疗等需要解释性的领域至关重要。

📊

输出概率值

不只是给出0/1分类结果，还给出概率置信度，方便做阈值调整、排序、模型融合等。

🏭

工业界广泛使用

是很多分类任务的baseline（基线模型）。CTR预估、风控、信用评分等场景，逻辑回归至今仍是主力或重要基准。

💡 经验之谈

做分类问题时，先试试逻辑回归！它简单快，结果不容易离谱，而且可以作为对比基准。如果逻辑回归效果就很好，就没必要上复杂模型了。

逻辑回归的缺点

它不是万能的，有明确的适用边界

❌ 只能处理线性可分问题

逻辑回归的决策边界是线性的（直线/超平面）。如果两类数据不是线性可分的（比如环形分布、异或问题），逻辑回归就分类不好。这时候需要特征工程或者换非线性模型（如决策树、SVM+核、神经网络）。

⚠️ 对特征工程要求高

因为模型本身表达能力有限，效果很大程度上依赖于特征工程：需要人工做特征组合、特征交叉、非线性变换等，才能学到非线性关系。这也是为什么说"特征工程决定上限"。

⚠️ 对多重共线性敏感

如果特征之间高度相关，会导致权重估计不稳定，解释性变差。可以用正则化（L1/L2）来缓解这个问题，sklearn的逻辑回归默认就带L2正则。

💡 这些缺点很重要吗？

在工业界很多问题中，经过良好特征工程后，数据往往近似线性可分，这时候逻辑回归效果很好。而且它简单、快、可解释——这些工程上的优点往往比精度上的一点点提升更重要。

多分类问题：One-vs-Rest

逻辑回归天生是二分类器，怎么做多分类？

很多分类问题不止两个类别，比如手写数字识别（0-9共10类）、图像分类（猫/狗/鸟/鱼...）。怎么用逻辑回归做多分类？最常用的策略是One-vs-Rest (OvR)，也叫One-vs-All (OvA)。

第1步：假设有K个类别，训练K个独立的二分类器
第2步：第i个分类器训练时，把"第i类"当作正类，"其他所有类"当作负类
第3步：预测时，把样本输入K个分类器，得到K个概率值，取概率最大的那个类别作为最终预测结果

📌 例子：手写数字识别（10类）

训练10个逻辑回归分类器：
• 分类器1：是"1"吗？（是=1，其他=0）
• 分类器2：是"2"吗？（是=1，其他=0）
• ...
• 分类器10：是"0"吗？（是=1，其他=0）
预测时，哪个分类器输出概率最高，就预测是哪个数字。

分类评估不能只看准确率！

准确率在不平衡数据上会骗人，我们需要更多指标

⚠️ 不平衡数据陷阱

假设某种疾病发病率是0.1%（1000人里1个患病）。如果一个模型把所有人都预测为"健康"，它的准确率是多少？

准确率 = 99.9%！

看起来很完美，但这个模型完全没用——它一个病人都没查出来！这就是为什么光看准确率是不够的，尤其是在数据不平衡的场景（风控、医疗、欺诈检测等）。

为了全面评估分类模型，我们需要学习：

  • 混淆矩阵（Confusion Matrix）——把所有预测结果分四类
  • 精确率（Precision）——你预测为正的里面，真的是正的有多少？
  • 召回率（Recall）——所有真实正例中，你找回来多少？
  • F1 Score——精确率和召回率的调和平均
  • ROC曲线与AUC——衡量模型整体排序能力

混淆矩阵

理解分类评估的基础——四个核心概念

对于二分类问题，每个样本的预测结果有四种可能：

预测：正类 (1)
预测：负类 (0)
真实：正类 (1)
TP
真阳性
预测对了，真的是正类
FN
假阴性
漏诊！本来是正类，预测成负类
真实：负类 (0)
FP
假阳性
误诊！本来是负类，预测成正类
TN
真阴性
预测对了，真的是负类

✅ 预测正确的：TP、TN

TP（真阳性）：实际是正，预测也是正
TN（真阴性）：实际是负，预测也是负

❌ 预测错误的：FP、FN

FP（假阳性/第一类错误）：误报
FN（假阴性/第二类错误）：漏报
这两类错误的代价往往不一样！

准确率（Accuracy）

最直观但也最容易误导人的指标

$$\displaystyle Accuracy = (TP + TN) / (TP + TN + FP + FN) = 预测正确的 / 全部样本$$

准确率就是"预测对的比例"，这个指标很好理解，但正如前面所说，在不平衡数据上它具有欺骗性。

🔍 癌症检测例子

1000个人里1个癌症患者，999个健康人。模型预测所有人都是健康：

  • TP=0（没找到一个真病人）
  • TN=999（健康人都判对了）
  • FP=0（没有误诊）
  • FN=1（漏诊了1个病人！）
  • 准确率 = 999/1000 = 99.9% —— 看起来很美，但漏诊了所有病人！

⚠️ 什么时候可以用准确率？

当正负样本比例差不多均衡时，准确率是个不错的指标。但在风控、医疗、欺诈检测等不平衡场景，一定要看精确率、召回率这些更细致的指标。

精确率（Precision）

你说它是正类，它真的是正类的概率——"找得对不对"

$$\displaystyle Precision = TP / (TP + FP)$$ 分母是"你预测为正类的所有样本"，分子是"其中真的是正类的"。精确率衡量的是：你的正类预测有多"准"。

🎯 适用场景：误诊代价高

垃圾邮件过滤：如果把正常邮件误判为垃圾邮件（FP），用户可能错过重要邮件，这代价很高。这时候我们希望精确率高——你说是垃圾邮件的，最好真的是垃圾邮件，宁可漏一些垃圾邮件，也不要误判正常邮件。

继续用癌症检测的例子（模型全预测健康）：

  • TP=0, FP=0 → Precision = 0/(0+0) 无意义（因为它没预测任何正例）
  • 如果模型很激进，把100个人判为癌症，其中只有1个真病人：Precision = 1/100 = 1%——非常低，大部分是误诊

召回率（Recall）

所有真的正类中，你找回来多少——"找得全不全"

$$\displaystyle Recall = TP / (TP + FN) = TPR（真阳性率）$$ 分母是"所有真实正类样本"，分子是"你正确找出来的正类"。召回率衡量的是：正类样本被你"抓回来"了多少比例。也叫灵敏度（Sensitivity）、真阳性率（TPR）。

🚨 适用场景：漏诊代价高

癌症诊断：如果把癌症患者漏诊为健康（FN），病人可能错失治疗时机，代价是生命！这时候我们希望召回率高——宁可把可疑的都判为阳性（多一些误诊），也不能漏掉一个真病人。

再次用癌症检测的例子：

  • 模型全预测健康：Recall = 0/(0+1) = 0%——一个病人都没找到！非常糟糕
  • 模型把所有人都判为癌症：Recall = 1/(1+0) = 100%——所有病人都找到了，但代价是有999个误诊

精确率 vs 召回率：权衡

这两个指标往往是矛盾的，需要根据场景取舍

🎯 精确率高

"你说它是正的，基本就是正的"

• 误诊少
• 但可能漏得多
• 阈值高时实现
• 适合：垃圾邮件过滤、推荐系统

⇄

🚨 召回率高

"是正的基本都被你找出来了"

• 漏诊少
• 但可能误得多
• 阈值低时实现
• 适合：疾病诊断、欺诈检测、安全监控

$$\displaystyle F1 Score = 2 \cdot (Precision \cdot Recall) / (Precision + Recall)$$ F1是精确率和召回率的调和平均数，综合了两者，只有两个都高时F1才高。如果需要在P和R之间找平衡，F1是个好指标。

ROC曲线与AUC

衡量模型整体排序能力的金标准

准确率、精确率、召回率都依赖于分类阈值的选择。ROC曲线则是通过遍历所有可能的阈值，画出模型在不同阈值下的表现：

📐 ROC的两个轴

横轴：FPR（假阳性率）
FPR = FP / (FP + TN)
= 负类中被误判为正的比例

纵轴：TPR（真阳性率）
TPR = Recall = TP / (TP + FN)
= 正类中被正确找出来的比例

📏 AUC是什么？

AUC = Area Under Curve
= ROC曲线下的面积

• AUC = 1：完美分类器
• AUC = 0.5：随机猜（跟瞎蒙一样）
• AUC < 0.5：比瞎猜还差（反过来用就行）

AUC越大越好，0.8以上算不错，0.9以上很好

✨ AUC的优点

AUC不依赖于阈值选择，衡量的是模型把正样本排在负样本前面的能力——也就是排序能力。而且它对不平衡数据不敏感，是分类问题最常用的评估指标之一。

本集小结

恭喜你完成了第9集！来回顾一下核心要点

🏷️ 分类问题

预测离散类别，输出概率(0,1)而非连续值。二分类是基础。

📐 Sigmoid函数

σ(z)=1/(1+e-z)，把(-∞,+∞)压缩到(0,1)，z=0时σ=0.5，单调递增光滑可导。

🤖 逻辑回归模型

ŷ=σ(wx+b)，输出属于正类的概率。决策边界是wx+b=0（线性超平面）。

📉 交叉熵损失

不用MSE（非凸有局部最优），用交叉熵（凸函数，全局最优）。

✅ 优缺点

优点：简单快、可解释强、输出概率、工业界常用。缺点：只能线性可分、依赖特征工程。

混淆矩阵TP/TN/FP/FN；准确率有陷阱；精确率（准不准）vs召回率（全不全）；F1调和；AUC衡量排序能力（不平衡场景尤其重要）。
