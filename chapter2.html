线性回归——机器学习的第一个模型

⏱ 20分36秒 · BV1xrNGzrEJx
模型假设

📈 什么是线性回归？

线性回归假设特征x与目标y之间存在线性关系，用一条直线（或超平面）来拟合数据点。

单变量：y = wx + b
多变量：y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
  • w（权重）：每个特征对预测值的影响程度
  • b（偏置）：截距项，所有特征为0时的基础预测值
  • 目标：找到最优的w和b，使预测值尽可能接近真实值
损失函数

📉 如何衡量"好坏"？

使用均方误差（MSE）作为损失函数，衡量预测值与真实值的差距：

MSE = (1/n) Σ(ŷᵢ - yᵢ)²
ŷᵢ 是预测值，yᵢ 是真实值
  • 为什么用平方？放大较大误差，数学上便于求导优化
  • 损失越小，模型拟合越好
  • 最小二乘法：直接求解使MSE最小的w和b

💡 核心思想

线性回归的核心是找到一条直线/超平面，使得所有数据点到该直线的距离平方和最小。这就是著名的"最小二乘法"。对于简单线性回归，可以通过求导直接得到解析解（正规方程）；对于复杂情况，则需要梯度下降等迭代优化方法。

梯度下降——模型如何自己学会找最优参数

⏱ 29分30秒 · BV1cpwuz7EgF
优化算法

🏔️ 梯度下降：像下山一样找最小值

梯度下降是机器学习中最核心的优化算法。想象你站在一座山上，想要最快到达山谷最低点——你会怎么做？环顾四周，找到最陡的下坡方向，走一小步，再重复。这就是梯度下降的直觉。

算法步骤

📋 梯度下降的过程

repeat until convergence {
  w = w - α · ∂J/∂w
  b = b - α · ∂J/∂b
}
  • α（学习率）：每步走多大，太大震荡不收敛，太小收敛慢
  • ∂J/∂w：损失函数对w的偏导（梯度），指示最陡方向
  • 负号：沿梯度反方向更新（下坡）
  • 不断迭代，直到损失不再明显下降
关键参数

⚙️ 学习率的选择

学习率α是梯度下降最重要的超参数：

  • α太大：步子迈太大，跨过最低点，来回震荡甚至发散
  • α太小：步子太小，收敛极慢，训练时间过长
  • 合适的α：损失函数稳步下降，平稳收敛到最小值
  • 通常从0.01、0.001等开始尝试，观察损失曲线调整

🎯 三类梯度下降

BGD（批量）：用全部数据算梯度，稳定但慢
SGD（随机）：单个样本算梯度，快但震荡
Mini-batch：小批量数据，兼顾速度与稳定（最常用）

# 梯度下降的简单Python实现
import numpy as np

def gradient_descent(X, y, lr=0.01, epochs=1000):
  n = len(y)
  w, b = 0.0, 0.0
  for _ in range(epochs):
    y_pred = w * X + b
    dw = (2/n) * np.sum((y_pred - y) * X)
    db = (2/n) * np.sum(y_pred - y)
    w -= lr * dw
    b -= lr * db
  return w, b

⚠️ 数据决定上限

数据预处理往往占据机器学习项目80%的工作量。垃圾进，垃圾出（Garbage In, Garbage Out）——再好的模型，面对脏数据也无能为力。

缺失值处理

🕳️ 数据清洗

  • 删除法：缺失比例高（>30%）时直接删除该特征/样本
  • 填充法：数值列用均值/中位数填充；分类列用众数填充
  • 模型预测填充：用其他特征预测缺失值（KNN插值等）
  • 异常值检测：IQR方法（1.5倍四分位距）、3σ原则、箱线图
特征缩放

📏 标准化 vs 归一化

不同特征量纲差异大（如年龄0-100，收入0-100万），会导致梯度下降收敛慢。

标准化 Z-score（常用）：
  x' = (x - μ) / σ → 均值0，方差1

归一化 Min-Max：
  x' = (x - min) / (max - min) → [0,1]范围
  • 基于距离的算法（KNN、SVM、线性回归+梯度下降）必须缩放
  • 树模型（决策树、随机森林）不需要特征缩放

拟合前提——线性回归模型评估

⏱ 14分24秒 · BV1nRXVBBEc4
回归评估指标

📊 如何评估回归模型？

指标公式含义特点
MSE均方误差放大误差，单位是y的平方
RMSEMSE开根号与y同单位，更直观
MAE平均绝对误差对异常值不敏感
R²决定系数0~1之间，越接近1越好
核心指标

🎯 R²（决定系数）

R²是回归模型最重要的评估指标：

R² = 1 - (SS_res / SS_tot)
SS_res: 残差平方和（预测误差）
SS_tot: 总平方和（用均值预测的误差）
  • R² = 1：完美预测，没有误差
  • R² = 0：跟直接猜均值一样差
  • R² < 0：比猜均值还差，模型有问题
  • 注意：R²高不代表模型好，可能过拟合！

欠拟合与过拟合问题诊断与解决

⏱ 22分02秒 · BV1Hb9EB9ESo
📏

欠拟合

模型太简单，连训练数据都没学好，训练误差大

✨

刚好拟合

模型复杂度适中，泛化能力强，训练和测试误差都小

🔍

过拟合

模型太复杂，死记硬背训练数据，训练误差小但测试误差大

诊断方法

🔬 如何判断过/欠拟合？

通过学习曲线（训练误差和验证误差随训练量变化的曲线）判断：

  • 欠拟合信号：训练误差和验证误差都很高，且两者差距小
  • 过拟合信号：训练误差很低，验证误差远高于训练误差（差距大）
  • 良好拟合：训练误差和验证误差都较低，两者差距小
解决方案

🛠️ 如何解决？

欠拟合解决
  • 增加模型复杂度（更高级的算法）
  • 增加更多有效特征
  • 减少正则化强度
过拟合解决
  • 收集更多训练数据
  • 正则化（L1/L2）
  • 减少特征维度
  • 交叉验证
  • 早停（Early Stopping）
正则化

⚖️ 正则化：给模型加"惩罚"防止过拟合

正则化通过在损失函数中加入对模型复杂度的惩罚项，防止权重过大导致模型过于复杂：

L2正则化（Ridge/岭回归）
J = MSE + λ·Σwᵢ²
让权重趋近于0但不为0
防止权重过大，缓解多重共线性
L1正则化（Lasso）
J = MSE + λ·Σ|wᵢ|
可以让部分权重变为0
天然实现特征选择

🎯 偏差-方差权衡

欠拟合对应高偏差（模型太简单，假设错误），过拟合对应高方差（模型对数据太敏感，波动大）。机器学习的核心挑战就是找到偏差和方差之间的最佳平衡点——这就是著名的偏差-方差权衡（Bias-Variance Tradeoff）。
