👨‍🔬 Frank Rosenblatt与感知机

1957年，美国心理学家、计算机科学家Frank Rosenblatt提出了感知机（Perceptron）。这是第一个用算法精确定义的神经网络模型，在当时引起了巨大轰动——媒体甚至报道说"感知机是可以学习、思考、记忆的机器"。Rosenblatt本人对它非常乐观，认为这是通向人工智能的道路。

⚠️ 成也萧何败也萧何

1969年，AI先驱Marvin Minsky和Seymour Papert出版了《Perceptrons》一书，严格证明了单层感知机无法解决异或（XOR）问题，也无法处理很多非线性问题。这个结论直接导致了神经网络研究进入第一次"AI寒冬"，感知机被打入冷宫近20年。

生物神经元的启发

神经网络为什么叫"神经"网络？因为它真的是在模拟大脑

🧠

生物神经元如何工作？

大脑里有大约860亿个神经元，它们通过突触连接成复杂网络：

  • 树突（Dendrite）：接收其他神经元传来的信号
  • 细胞体（Soma）：处理接收到的信号，决定要不要"激活"
  • 轴突（Axon）：如果激活了，就把信号传递给其他神经元
  • 神经元接收到的信号总和超过某个阈值，就会"放电"（激活），产生一个输出信号
💡

抽象成数学模型

感知机就是对生物神经元的极简数学抽象：

  • 输入 x ← 对应树突接收的信号
  • 权重 w ← 对应突触的强度（每个输入有多重要）
  • 加权求和 ← 对应细胞体整合信号
  • 偏置 b / 阈值 ← 对应神经元激活的门槛
  • 激活函数 f ← 决定要不要激活放电
  • 输出 y ← 对应轴突传出的信号

🔑 核心思想

"超过阈值就激活"——这个简单的"all-or-nothing"（全或无）机制，就是感知机的核心思想，也是所有人工神经网络的基础。

感知机模型结构

数学公式：从输入到输出的计算过程

$$\displaystyle z = w_1x_1 + w_2x_2 + ... + w_nx_n + b = w \cdot x + b \ \ y = f(z) = { 1, if z \geq 0; 0, if z < 0 } 其中：x=(x_1,x_2,...,x_n)是输入，w=(w_1,w_2,...,w_n)是权重，b是偏置，f是阶跃激活函数 $$

📥 输入 Inputs

x₁, x₂, ..., xₙ 是n个输入特征，可以是像素值、特征值等。每个输入都有对应的权重w。

⚖️ 权重与偏置

w₁...wₙ是权重，控制每个输入的重要程度；b是偏置，控制神经元被激活的容易程度（阈值）。这些都是模型要学习的参数。

📤 激活与输出

先计算加权和z=w·x+b，然后用阶跃函数f激活，z≥0输出1，否则输出0——二元分类结果。

阶跃激活函数（Step Function）

感知机用的激活函数，非常简单粗暴

$$\displaystyle f(z) = { 1, 当 z \geq 0 时 \         0, 当 z < 0 时 }$$

📈 函数特点

  • 输出只有两个值：0或1（二元）
  • 在z=0处有一个"跳跃"
  • z≥0就激活（输出1），否则不激活（输出0）
  • 模拟生物神经元的"全或无"放电

⚠️ 阶跃函数的问题

  • 不可导！在z=0处导数不存在，其他地方导数都是0
  • 这意味着不能用梯度下降来训练（反传不了梯度）
  • 这也是为什么后来大家改用Sigmoid/ReLU等可导激活函数
  • 感知机只能用特殊的学习规则

🎯 先记下来这个问题

阶跃函数不可导，无法用梯度下降——这是感知机的一个重要局限。等我们后面讲反向传播的时候你会更深刻理解为什么可导性这么重要。

感知机学习算法

如何自动找到合适的权重w和偏置b？

🎓 算法思想：知错就改

感知机的学习规则非常直观：初始化权重为0，然后不断看每个样本，预测错了就调整权重，直到所有样本都分类正确。对了就不改，错了就纠正，直到全对为止——这就是"知错能改"的学习过程！

$$\displaystyle 感知机学习算法步骤： \ \ 1. 初始化权重 w = 0，偏置 b = 0 \ 2. 设置学习率 η（0 < η \leq 1，通常取0.1） \ 3. 重复以下过程直到没有误分类点： \     对每个训练样本 (x, y)： \         计算预测值 \hat{y} = f(w \cdot x + b) \         如果 \hat{y} \neq y（预测错了），更新参数： \             w ← w + η \cdot y \cdot x \             b ← b + η \cdot y$$

理解权重更新规则

为什么这样更新？背后的直觉是什么？

$$\displaystyle w ← w + η \cdot y \cdot x \ b ← b + η \cdot y$$

❌ 情况1：应该是1，但预测成0了（漏报）

此时y=1，ŷ=0，更新规则变成：w←w+ηx，b←b+η
相当于把正样本方向的权重加大，让决策边界往正确方向挪一点，下次这个样本更容易被判定为1。

❌ 情况2：应该是0，但预测成1了（误报）

此时y=-1？等下，注意——我们标签通常用{+1,-1}而不是{1,0}，这样y=-1时更新变成w←w-ηx，b←b-η。把权重往反方向拉，让这个样本下次不那么容易被判定为1。

🔑 关于标签编码

注意：感知机算法里，正类标签通常用+1而不是1，负类用-1而不是0。这样更新公式统一写成w←w+ηyx即可。如果用{0,1}编码，负类时y=0权重不更新，逻辑上需要分开处理。本质是一样的。

📌 收敛定理

如果训练数据是线性可分的，感知机算法一定能在有限步内收敛，找到一个完美分类所有样本的解！如果线性不可分，算法会一直振荡不收敛——这也是感知机的局限。

热身：用感知机实现逻辑门

不用训练，直接给权重参数，验证感知机的表达能力

🎮 逻辑门是什么？

逻辑门是数字电路的基本单元，输入是0或1，输出也是0或1，实现基本的逻辑运算：与(AND)、或(OR)、非(NOT)等。我们来看看感知机能不能实现这些简单逻辑。

💡 我们先不用学算法，直接"手搓"权重

对于简单的逻辑门，我们可以直接思考出合适的w和b，不用算法去学。这能帮助你建立直觉：权重w控制每个输入的重要性，偏置b控制激活的门槛高低。

✅ 准备好了吗？

接下来我们依次实现AND门、OR门、NOT门，看看感知机是怎么工作的。记住判断标准：计算z=w1x1+w2x2+b，如果z≥0输出1，否则输出0。

实现逻辑AND（与门）

只有两个输入都是1，输出才是1

$$\displaystyle w_1 = 1, w_2 = 1, b = -1.5 \ \ z = x_1 + x_2 - 1.5 \ y = 1 if z \geq 0 else 0$$
x₁ x₂ z = x₁+x₂-1.5 y（输出） 是否符合AND？
0 0 -1.5 0 ✅ 正确（0 AND 0 = 0）
0 1 -0.5 0 ✅ 正确（0 AND 1 = 0）
1 0 -0.5 0 ✅ 正确（1 AND 0 = 0）
1 1 0.5 1 ✅ 正确（1 AND 1 = 1）

🎉 AND门实现成功！

验证一下：只有x1和x2都是1的时候，z=0.5≥0才输出1，其他情况都是0，完美符合与门逻辑！偏置-1.5设置了一个比较高的门槛：需要两个输入都为1才能"激活"。

实现逻辑OR（或门）

只要有一个输入是1，输出就是1

$$\displaystyle w_1 = 1, w_2 = 1, b = -0.5 \ \ z = x_1 + x_2 - 0.5 \ y = 1 if z \geq 0 else 0$$
x₁ x₂ z = x₁+x₂-0.5 y（输出） 是否符合OR？
0 0 -0.5 0 ✅ 正确（0 OR 0 = 0）
0 1 0.5 1 ✅ 正确（0 OR 1 = 1）
1 0 0.5 1 ✅ 正确（1 OR 0 = 1）
1 1 1.5 1 ✅ 正确（1 OR 1 = 1）

🤔 对比AND门，你发现了什么？

权重还是w1=1,w2=1，只是偏置从-1.5变成了-0.5——门槛降低了！AND需要两个都满足（总和≥1.5），OR只要有一个就行（总和≥0.5）。你看，参数微小的变化就能实现不同的逻辑！

实现逻辑NOT（非门）

输入是0输出1，输入是1输出0——翻转

$$\displaystyle NOT只有1个输入：w_1 = -1, b = 0.5 \ \ z = -x_1 + 0.5 \ y = 1 if z \geq 0 else 0$$
x₁ z = -x₁ + 0.5 y（输出） 是否符合NOT？
0 0.5 1 ✅ 正确（NOT 0 = 1）
1 -0.5 0 ✅ 正确（NOT 1 = 0）

💡 权重是负数！

NOT门的权重w1=-1是负的——这意味着输入越大，z反而越小。这是"抑制"作用：输入x1=1会让神经元不激活，x1=0反而激活。负权重代表"这个输入是负面信号"。

🎉 小结：线性逻辑门都能实现

AND、OR、NOT——这些简单的线性逻辑门单层感知机都能轻松实现。那是不是所有逻辑门感知机都能实现呢？接下来我们来试试XOR（异或）门——正是这个问题让感知机沉寂了20年！

XOR问题证明：数学上无解！

让我们用简单的不等式推导，证明为什么不可能

$$\displaystyle 从 (0,1)→1: w_2 + b \geq 0   --- (1) \ 从 (1,0)→1: w_1 + b \geq 0   --- (2) \ (1)+(2)得: w_1 + w_2 + 2b \geq 0   --- (3) \ 从 (1,1)→0: w_1 + w_2 + b < 0   --- (4) \ 从(3): w_1 + w_2 \geq -2b，代入(4): \ -2b + b \leq w_1 + w_2 + b < 0 ⇒ -b < 0 ⇒ b > 0 \ \ 但是从(0,0)→0我们得到 b < 0 ——矛盾！无解！$$

😱 结论：单层感知机不可能实现XOR！

这是数学上严格证明的——无论怎么选w1、w2、b，单层感知机都不可能实现异或门。这不是我们不够聪明，而是单层感知机的表达能力天生就有局限！

几何直观：一条直线分不开XOR

用图来看，为什么线性分类器对XOR无能为力

✅ AND/OR：线性可分

一条直线能把红点和绿点分开

❌ XOR：线性不可分

红点绿点交替分布，任何一条直线都分不开

🎯 本质原因

单层感知机是一个线性分类器，只能学习线性决策边界（在二维平面是一条直线）。而XOR的数据分布是"对角线为同类"，不是线性可分的——你需要两条直线或者一条曲线才能把它们分开。

感知机的能力边界

线性可分就能学会，线性不可分就不行

✅

单层感知机能做到的

  • 学习所有线性可分的问题
  • 实现AND、OR、NOT等线性逻辑门
  • 线性二元分类（有一条直线/超平面能分开的）
  • 对于线性可分数据，保证收敛到一个解
❌

单层感知机做不到的

  • 学习线性不可分的问题
  • 无法实现XOR异或门
  • 无法解决复杂的非线性分类问题
  • 无法拟合简单的非线性函数
  • 阶跃函数不可导，无法堆叠多层训练

😔 当年的绝望

Minsky和Papert在书中证明了感知机的这些局限，甚至暗示多层神经网络也没救。这直接导致了神经网络研究经费被砍，进入AI寒冬——很多人以为这条路走不通了。但他们错了！

解决方案：两层感知机（MLP）

既然一条直线分不开，那就用两条直线——多层感知机！

💡 关键思想：组合已有门电路来实现XOR！

本集知识点总结

回顾一下，我们从感知机学到了什么？

📚 核心知识点回顾

  • 感知机：Rosenblatt 1957年提出，最简单的神经网络，模拟生物神经元
  • 模型结构：输入x→权重w→加权求和z=w·x+b→阶跃激活→输出y(0/1)
  • 本质：线性二元分类器，学习一个超平面分开两类
  • 学习算法：初始化0→逐个样本看→分类错了就更新w←w+ηyx，b←b+ηy→直到收敛
  • 能实现：AND、OR、NOT等线性可分问题
  • 关键局限：单层感知机是线性模型，无法解决XOR问题（线性不可分）
  • 解决方案：堆叠成两层/多层感知机（MLP），组合多个线性分类器就能解决非线性问题
  • 遗留问题：阶跃函数不可导，需要换成可导激活函数+反向传播来训练多层网络
