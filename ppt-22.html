Batch Gradient Descent（批量梯度下降）

每次用全部训练数据计算梯度——最原始的版本

$$\displaystyle \theta = \theta - η \cdot \nabla _{ \theta }L( \theta ; 全部训练数据)$$

✅ 优点

• 梯度估计最准确（用了全部数据）
• 收敛稳定，能朝着最优解直线前进
• 对凸问题能保证收敛到全局最优

❌ 缺点

• 极慢！数据集几百万样本，每次更新要算完所有数据
• 内存要求大——要把全部数据放进显存/内存
• 不能在线学习——新数据来了不能增量更新
• 容易陷入局部最优（太"稳"了，没有探索性）

⚠️ 实际情况

在深度学习中，基本不用Batch GD——数据量太大，根本跑不动。只有很小的数据集或凸优化问题才会用。

Stochastic Gradient Descent（随机梯度下降）

每次随机选1个样本计算梯度——另一个极端

$$\displaystyle \theta = \theta - η \cdot \nabla _{ \theta }L( \theta ; 单个随机样本)$$

✅ 优点

• 极快！一次更新只需1个样本
• 内存要求极小
• 可以在线学习(online learning)
• 噪声有助于跳出局部最优

❌ 缺点

• 梯度估计噪声很大，方向不准
• 更新震荡严重，损失曲线剧烈波动
• 永远不会"收敛"，只会在最优点附近晃荡
• 无法利用GPU矩阵并行加速

⚠️ 实际情况

纯SGD（每次1个样本）在深度学习中也很少用——GPU擅长并行计算，1个样本根本吃不饱GPU，浪费算力。

Mini-batch Gradient Descent（小批量梯度下降）

折中方案——每次选一小批样本计算梯度

$$\displaystyle \theta = \theta - η \cdot \nabla _{ \theta }L( \theta ; 一小批(batch)样本)$$

🏆 这才是实际中的标准选择！

每次不是用全部数据，也不是用1个，而是用一小批（比如32/64/128/256个）样本。
这是Batch GD和SGD之间的折中，结合了两者的优点，避免了两者的缺点。

💡 术语澄清

在深度学习中，当人们说"SGD"时，通常指的就是Mini-batch SGD，而不是每次1个样本的纯SGD。不要混淆！

为什么Mini-batch是王道？

四个理由让它成为深度学习的标准选择

⚡

GPU并行加速

GPU擅长并行矩阵运算，一批32/64/128个样本组成矩阵，一次性并行计算，比一个个算快得多！

🎲

噪声帮助跳出局部最优

小批量带来的梯度噪声不是坏事——它能让优化过程跳出尖锐的局部最小值，找到更平坦、泛化更好的最小值。

📊

收敛更稳定

比纯SGD(1个样本)稳定得多，梯度估计更准，不会乱晃；又比Batch GD快得多。

💾 第四个理由：内存效率

不需要把全部数据集放进内存，一批一批来就好。大数据集（几百万张图片）也能训练。

Batch Size怎么选？

这是一个需要权衡的超参数

Batch Size 梯度质量 训练速度 显存需求 泛化能力 适用场景
1 噪声极大 单步快但需要多步 极小 较好？噪声有正则效果 在线学习
32 有噪声 快 小 好 默认首选！小数据集/微调
64/128 较准确 快 中等 好 最常用！大多数场景
256/512 准确 单步慢但步少 大 可能略差 大数据集、大模型
全数据 最准确 极慢 极大 较差 凸优化、小数据集

✅ 实用建议

不知道选什么时，先试32或64！这是最稳妥的默认选择。显存够可以试128/256，但不是越大越好——有研究表明大batch可能泛化略差。

Epoch vs Iteration

这两个概念很容易搞混，一定要分清

Epoch

轮次

完整遍历一遍整个训练集，叫1个epoch。所有样本都被模型"看"过一次了。

Iteration

迭代/步

处理一个mini-batch，做一次参数更新，叫1个iteration（或step）。

举例

换算关系

10000样本，batch=100：
1 epoch = 100 iterations

$$\displaystyle iterations_per_epoch = 训练样本数 / batch_size$$

💡 记住

当别人说"训练了100个epoch"，意思是整个训练集过了100遍；说"训练了10000步(step)"，意思是参数更新了10000次。两者关系取决于batch size。

SGD的问题：沟壑与震荡

普通SGD在某些方向上反复横跳，收敛慢

🏔️ 损失曲面的"沟壑"问题

神经网络的损失曲面不是圆形的碗，而是像一个狭长的"沟壑"（ravine）：
• 一个方向（沟壑方向）很陡，梯度大
• 另一个方向（沿沟壑底部）很平缓，梯度小

SGD在陡的方向上反复震荡（过冲→回来→再过冲），在平缓方向上前进很慢，整体走"之"字形，收敛效率低。

🎯 怎么解决？

就像小球滚下山坡会有惯性——如果能积累"之前的速度"，就能：
1. 在震荡方向上抵消前后摆动，减少震荡
2. 在平缓方向上保持前进，加速收敛
这就是动量法(Momentum)的核心思想！

Momentum动量法

给梯度下降加上"惯性"，像小球滚下山坡

$$\displaystyle v_{t} = \beta \cdot v_{t-1} + (1- \beta ) \cdot \nabla L_{t} \ \theta = \theta - η \cdot v_{t}$$ v是"速度"，β是动量系数（通常0.9）。不是直接用当前梯度更新，而是用梯度的移动平均——积累了历史梯度方向。

✅ 为什么有效？

• 减少震荡：前后相反的梯度互相抵消
• 加速收敛：一致方向的梯度互相叠加，速度越来越快
• 逃出局部最优：有了"惯性"，能冲过小的局部最小值
• 收敛速度通常比普通SGD快很多

🎮 直觉理解

• 想象推一个很重的球下山：一开始慢，但越滚越快
• 遇到小上坡（局部最优），靠惯性冲过去
• β=0.9意味着：当前速度保留90%，新梯度贡献10%
• 就像指数加权平均，最近10步左右的梯度都有影响

Nesterov Accelerated Gradient (NAG)

动量法的改进——"向前看一步"再算梯度

$$\displaystyle v_{t} = \beta \cdot v_{t-1} + (1- \beta ) \cdot \nabla L( \theta - η \beta \cdot v_{t-1}) \ \theta = \theta - η \cdot v_{t}$$ 不是在当前位置θ算梯度，而是在"按照当前动量会走到的位置"θ-ηβvt-1算梯度——先往前看一步，再调整方向。

🧠 直觉

就像开车：普通Momentum是先开（按动量），到位置了再看路标（算梯度）再调整方向；
NAG是先往前看一眼路标（在预期位置算梯度），提前知道要转弯了，就不会冲过头。

📊 效果

NAG在某些情况下比Momentum收敛更快、更稳定，不会那么容易冲过头。但在自适应学习率优化器（Adam等）流行后，NAG用得没那么多了。

问题：所有参数用同一个学习率合适吗？

稀疏特征、频繁更新的参数需要不同的学习率

🤔 思考一下

一个神经网络里可能有几百万个参数：
• 有些参数对应的特征经常出现（比如常见词、常见像素模式）——更新很频繁
• 有些参数对应的特征很少出现（比如罕见词、罕见模式）——更新很少

如果都用同一个学习率η：
• 对频繁更新的参数，η可能太大（震荡）
• 对稀疏、很少更新的参数，η可能太小（学太慢）

💡 解决方案思路

能不能让每个参数有自己的学习率？更新频繁的参数自动减小学习率，更新少的参数保持较大学习率？这就是自适应学习率优化器的核心思想。

AdaGrad：自适应学习率

给每个参数一个"历史梯度平方和"来缩放学习率

$$\displaystyle s_{t} = s_{t-1} + \nabla L_{t} ⊙ \nabla L_{t} \ \theta = \theta - η \cdot \nabla L_{t} / ( \sqrt{s_{t} + \epsilon )$$ s累积历史梯度的平方。梯度大的参数，s累积快，有效学习率η/√s变小；梯度小的参数，s累积慢，有效学习率相对大。

✅ 优点

• 自动调整每个参数的学习率
• 稀疏特征学习率大，稠密特征学习率小
• 适合处理稀疏数据

❌ 致命缺点

• s是单调递增的（一直加）
• 训练越久，学习率被压得越小
• 最终学习率趋近于0，训练提前停止！
• 这在深度学习中是大问题

RMSProp：解决AdaGrad的问题

用滑动平均代替累加，不让学习率降到0

$$\displaystyle s_{t} = \beta \cdot s_{t-1} + (1- \beta ) \cdot \nabla L_{t} ⊙ \nabla L_{t} \ \theta = \theta - η \cdot \nabla L_{t} / ( \sqrt{s_{t} + \epsilon )$$ s不再是无限累加，而是梯度平方的指数滑动平均（β通常0.999）——和Momentum的思路一样，老的梯度会慢慢"遗忘"，s不会无限增大，学习率不会降到0。

✅ 效果

Hinton在Coursera课上提出的未发表方法，简单却有效——既保留了自适应学习率的优点，又解决了AdaGrad学习率单调递减的问题。RMSProp在RNN等场景表现不错。

💡 思路总结

Momentum用滑动平均累积梯度本身（一阶矩），减少震荡、加速；RMSProp用滑动平均累积梯度平方（二阶矩），自适应调整每个参数的学习率。如果把两者结合起来呢？——这就是Adam！

Adam：Momentum + RMSProp 的结合

Adaptive Moment Estimation——目前最常用的默认优化器

$$\displaystyle m_{t} = \beta _1 \cdot m_{t-1} + (1- \beta _1) \cdot \nabla L_{t}   (一阶矩：梯度的滑动平均，类似Momentum) \ v_{t} = \beta _2 \cdot v_{t-1} + (1- \beta _2) \cdot \nabla L_{t}⊙ \nabla L_{t}   (二阶矩：梯度平方的滑动平均，类似RMSProp) \ m̂_{t} = m_{t}/(1- \beta _1ᵗ),  v̂_{t} = v_{t}/(1- \beta _2ᵗ)   (偏差修正：初始m,v为0，需要校正) \ \theta = \theta - η \cdot m̂_{t} / ( \sqrt{v̂_{t} + \epsilon )$$

Adam超参数详解

默认参数通常就很好，一般不需要调

参数 默认值 含义 需要调吗？
η (lr) 0.001 学习率，最重要的参数 经常需要调！常见范围1e-4 ~ 1e-3
β₁ 0.9 一阶矩（梯度均值）的衰减率，类似Momentum的β 一般不用改
β₂ 0.999 二阶矩（梯度平方）的衰减率，类似RMSProp的β 一般不用改，有时可用0.99/0.995
ε 1e-8 防止除0的小常数 完全不用改

🏆 Adam的优点

• 收敛速度快，对学习率不那么敏感
• 基本不需要手动调β₁/β₂，默认就很好
• 处理稀疏梯度、噪声梯度都不错
• 是绝大多数场景的默认首选

Adam的小缺点：可能收敛到次优点

Adam收敛快，但最终精度有时不如精调的SGD+Momentum

🟠 Adam

  • 收敛快，前期下降迅速
  • 对学习率鲁棒，好调参
  • 省时间，快速出baseline
  • 有时最终泛化略差
  • 论文实验、原型开发首选
VS

🟢 SGD+Momentum

  • 收敛慢，需要更多epoch
  • 对学习率敏感，需要精细调参
  • 可能需要更好的学习率调度
  • 调得好时泛化更好
  • 比赛刷榜、追求极致精度时用

💡 实用建议

开始用Adam快速出baseline，确定模型、数据没问题后，如果需要进一步提升精度，可以尝试SGD+Momentum+学习率调度精调。
AdamW（Adam+权重衰减）是Adam的改进版，现在Transformer训练常用。

其他常见优化器

Adam家族还有很多变体，以及其他选择

AdamW

Adam + 权重衰减(Weight Decay)解耦。现在训练Transformer的标配（GPT/BERT/ViT都用），比原版Adam泛化更好。

AdaMax

Adam的变体，用L∞范数代替L2范数，更稳定一些。但用得不多。

NAdam

Adam + Nesterov动量，把NAG的"向前看"思想融入Adam。据说有时比Adam稍好。

RMSprop

前面讲过了，Hinton课上提出，RNN时代常用，现在基本被Adam取代。

Adadelta

AdaGrad的另一种改进，甚至不需要设置初始学习率，但用得很少。

LION

2023年Google提出的新优化器，省显存，在大模型上表现好，值得关注。

优化器选择建议

面对这么多优化器，该怎么选？

🥇 默认首选：Adam / AdamW lr=0.001（或3e-4），快速收敛、省时间，适合90%场景
🥈 训练Transformer/大模型：AdamW 必须用权重衰减，配合Warmup+Cosine学习率调度
🥉 追求极致精度/刷比赛：SGD+Momentum lr=0.1（配合衰减），momentum=0.9，耐心调参+学习率调度

⚠️ 别浪费太多时间选优化器

优化器的影响通常不如学习率、模型架构、数据质量/数量大。用Adam先跑通，比花一周选优化器更有价值。

学习率是最重要的超参数

没有之一——学习率决定了训练能不能成功

🐢

学习率太小

收敛极慢，训练要很久；可能卡在局部最优出不来；看起来loss在降，但降得太慢。

🎯

学习率合适

loss快速下降，稳定收敛；训练速度快，最终效果好。这是我们要找的"黄金区间"。

💥

学习率太大

loss震荡不下降，甚至上升；参数更新步子太大，直接跨过去了；严重时loss变NaN，训练崩溃。

💡 怎么找合适的学习率？

学习率查找(Learning Rate Range Test)：从很小的lr开始，训练几百步，lr指数增长，观察loss什么时候开始下降——那个点就是合适的lr。或者用网格搜索：试1e-4, 3e-4, 1e-3, 3e-3等。

学习率调度(Learning Rate Scheduling)

固定学习率不是最优的——训练过程中调整lr效果更好

🤔 为什么要调度学习率？

训练初期：参数离最优解远，需要大学习率快速前进
训练后期：参数接近最优解，需要小学习率微调，避免震荡

就像开车：高速上开快，到目的地附近减速——不能一直120码，也不能一直20码。

Warmup：为什么训练初期不能用大lr？

一开始就大lr会导致训练不稳定，甚至崩溃

🔍 为什么需要Warmup？

训练刚开始时，参数是随机初始化的，梯度可能很大/很不稳定。如果一开始就用大学习率：
• 参数更新步长太大，可能直接"飞"到一个很差的区域
• 尤其是Adam等自适应优化器，前几步的梯度统计量（m,v）还不准
• 可能直接导致loss变NaN，训练崩掉

Warmup策略：前几百/几千步，学习率从一个很小的值（或0）线性增长到设定的最大值，然后再用Cosine等方式衰减。

✅ Transformer训练标配

GPT、BERT、ViT等所有大模型都用Warmup+CosineAnnealing。通常warmup占总步数的5%-10%（比如总10000步，前500-1000步warmup）。

代码示例：PyTorch优化器配置

在PyTorch中使用不同优化器非常简单

import torch import torch.nn as nn import torch.optim as optim model = MyModel() # 1. SGD（带动量） optimizer = optim.SGD(model.parameters(), lr=0.1, momentum=0.9, weight_decay=1e-4) # 2. Adam（最常用默认选择） optimizer = optim.Adam(model.parameters(), lr=0.001, betas=(0.9, 0.999)) # 3. AdamW（Transformer/大模型标配） optimizer = optim.AdamW(model.parameters(), lr=3e-4, weight_decay=0.01) # 学习率调度器 scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100) # 或者带Warmup（需要用PyTorch 1.10+或transformers库） from transformers import get_cosine_schedule_with_warmup scheduler = get_cosine_schedule_with_warmup( optimizer, num_warmup_steps=500, num_training_steps=10000 ) # 训练循环中使用 for x, y in dataloader: optimizer.zero_grad() loss = criterion(model(x), y) loss.backward() optimizer.step() scheduler.step() # 更新学习率

DL优化中的其他困难

局部最小值、鞍点、梯度消失/爆炸

🕳️

局部最小值

以前以为是大问题，实际上高维空间中鞍点比局部最小值常见得多，而且SGD噪声+动量能逃出小局部最优。

⚡

鞍点(Saddle Point)

某些方向是极大值，某些方向是极小值，梯度为0但不是最优点。这才是高维空间真正的"减速带"。

📉

梯度消失/爆炸

上集讲过，深层网络的顽疾。需要：合理初始化、BatchNorm、残差连接、梯度裁剪等手段辅助。

💡 好消息

这些问题听起来可怕，但现代深度学习框架+好的架构设计（ResNet/Transformer）+好的初始化/BN/优化器，大部分时候你不需要太担心——按照最佳实践来，训练通常能正常收敛。

本集核心知识点总结

从SGD到Adam——优化算法的进化

🎯 记住这些核心点

• Mini-batch SGD是标准选择，batch size默认32/64
• 1 epoch = 遍历一遍全部数据；1 iteration = 更新一次参数
• Momentum通过积累历史梯度减少震荡、加速收敛
• Adam = Momentum + RMSProp，自适应学习率，默认首选
• Adam超参数一般不用调，lr=0.001是好的起点
• 学习率是最重要的超参数，没有之一
• 学习率调度很重要：Warmup+Cosine是现代标配
• 用AdamW训练Transformer，SGD+Momentum适合刷精度
