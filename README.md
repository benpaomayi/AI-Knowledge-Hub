# 机器学习课程学习网站

欢迎来到机器学习课程学习网站！本项目是一个完整的机器学习在线学习平台，包含系统化的课程内容和交互式演示。

## 📚 课程概述

本课程涵盖机器学习的核心概念、算法和实践应用，从基础理论到高级主题，帮助学习者建立扎实的机器学习知识体系。

## 🎯 课程内容

### 基础章节
- **第1章** - 机器学习基础概念与数学基础
- **第2章** - 监督学习算法
- **第3章** - 无监督学习算法
- **第4章** - 模型评估与优化
- **第5章** - 特征工程与数据预处理
- **第6章** - 集成学习方法
- **第7章** - 深度学习基础

### 专题演示文稿
- **PPT 01-36** - 系统化的课程演示文稿，涵盖各个知识点
- **Transformer 专题** - 深入讲解 Transformer 架构原理与应用
- **DeepSeek 专题** - 探索 DeepSeek 大语言模型技术

## 🛠️ 技术栈

- **前端框架**: 纯 HTML5 + CSS3 + JavaScript
- **数据可视化**: ECharts（用于图表展示）
- **流程图**: Mermaid（用于算法流程图）
- **公式渲染**: MathJax（用于数学公式显示）

## 🚀 本地运行

本项目为纯静态网站，可以直接在浏览器中打开 HTML 文件，或使用本地服务器访问：

```bash
# 使用 Python 启动简单 HTTP 服务器
python3 -m http.server 8000

# 或使用 Node.js 的 http-server
npx http-server -p 8000
```

然后在浏览器中访问 `http://localhost:8000`

## 📖 学习建议

1. **循序渐进**: 建议按照章节顺序学习，从基础概念开始
2. **结合实践**: 每章配有演示文稿，建议结合章节内容和 PPT 一起学习
3. **动手实验**: 理解算法原理后，尝试在实际数据上应用
4. **专题深入**: 完成基础学习后，可以深入学习 Transformer 和 DeepSeek 专题

## 📝 特色功能

- **交互式图表**: 使用 ECharts 实现数据可视化，直观展示算法效果
- **数学公式**: 完整的数学公式支持，清晰展示算法原理
- **流程图示**: 使用 Mermaid 绘制算法流程图，帮助理解复杂概念
- **响应式设计**: 适配不同设备，支持桌面和移动端学习
