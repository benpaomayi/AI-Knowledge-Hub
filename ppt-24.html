Loss vs Cost vs Objective

三个经常被混用但略有区别的概念

术语 英文 含义 计算范围 例子
Loss 损失 Loss 单个样本的预测误差 1个样本 一张图片预测错了多少
Cost 代价 Cost 整个训练集上的总损失/平均损失 所有样本 整个batch/epoch的平均误差
Objective 目标 Objective 更广义的概念，包含Cost+正则化项等 整体优化目标 最小化 损失 + L2正则化

💡 实际使用中

在深度学习日常交流和论文中，这三个词经常被混用。当大家说"loss"的时候，通常指的就是Cost Function（代价函数）——整个batch上的平均损失，不用太纠结严格区分。

MSE / L2 Loss（均方误差）

回归任务最常用的损失函数

$$\displaystyle MSE = (1/n) \sum (\hat{y}_i - y_i)²$$ ŷ：模型预测值    y：真实标签    n：样本数量
对每个样本计算预测值和真实值之差的平方，再取平均。

✅ 优点

• 处处可导，方便梯度下降优化
• 凸函数，理论上有全局最优解
• 对大误差惩罚更重（平方放大），梯度稳定

❌ 缺点

• 对异常值非常敏感（一个离群点的误差平方后可能主导整个loss）
• 如果数据中有很多outlier，MSE会被带偏

MAE / L1 Loss（平均绝对误差）

对异常值更鲁棒的回归损失

$$\displaystyle MAE = (1/n) \sum |\hat{y}_i - y_i|$$ 计算预测值和真实值之差的绝对值，再取平均。

✅ 优点

• 对异常值鲁棒，不管误差多大，惩罚都是线性的
• 适合数据中有很多离群点的场景

❌ 缺点

• 在零点不可导（误差为0处有折点），梯度在0点处会震荡
• 梯度大小恒定，即使误差很小梯度也一样大，可能在最小值附近震荡不收敛

🤔 MSE还是MAE？

如果数据干净、异常值少，用MSE（收敛更快更稳）；如果异常值多，用MAE（更鲁棒）；想要两者优点结合——看Huber Loss！

Huber Loss / Smooth L1 Loss

MSE和MAE的"集大成者"，结合两者优点

$$\displaystyle L \delta (y, \hat{y}) = { ½(\hat{y}-y)²       当 |\hat{y}-y| \leq \delta \            \delta |\hat{y}-y| - ½ \delta ²    当 |\hat{y}-y| > \delta }$$ 误差小的时候用MSE（可导、梯度平滑），误差大的时候用MAE（对异常值鲁棒）。δ是超参数，通常取1.0。

✅ 误差小时

类似MSE：平方损失，梯度随误差减小而减小，收敛稳定，在最优点附近不会震荡。

✅ 误差大时

类似MAE：线性损失，梯度恒定为δ，不会被异常值的大梯度带飞。

🎯 应用场景

目标检测中的 bounding box 回归（Faster R-CNN、SSD等都用Smooth L1）。

回归损失：PyTorch代码示例

三种回归损失函数的实际用法

import torch
import torch.nn as nn

# 假设：预测值 predictions，真实值 targets（都是形状为 [batch_size] 的张量）
predictions = torch.tensor([2.5, 0.0, 2.1, 1.8])
targets = torch.tensor([3.0, -0.5, 2.0, 1.7])

# 1. MSE Loss（均方误差）
mse_loss = nn.MSELoss()
loss_mse = mse_loss(predictions, targets)
print(f"MSE Loss: {loss_mse.item():.4f}")

# 2. MAE / L1 Loss（平均绝对误差）
l1_loss = nn.L1Loss()
loss_l1 = l1_loss(predictions, targets)
print(f"L1 Loss: {loss_l1.item():.4f}")

# 3. Smooth L1 / Huber Loss（平滑L1）
smooth_l1 = nn.SmoothL1Loss(beta=1.0) # beta就是公式里的δ
loss_huber = smooth_l1(predictions, targets)
print(f"Smooth L1 Loss: {loss_huber.item():.4f}")

分类任务损失函数

分类问题为什么不能直接用MSE？

⚠️ 分类用MSE的两个严重问题

1. 非凸问题：MSE配合Sigmoid/Softmax，损失函数是非凸的，有很多局部最小值，梯度下降容易陷入局部最优。

2. 梯度消失（饱和区问题）：当预测概率接近0或1时，Sigmoid/Softmax的梯度趋近于0，导致参数更新极慢，模型学不动。

✅ 解决方案：交叉熵损失 Cross-Entropy Loss

交叉熵损失是凸函数（配合Softmax时有全局最优解），而且梯度更大、更稳定，不会出现饱和区梯度消失的问题，是分类任务的标准选择。

二分类交叉熵 BCE Loss

Binary Cross-Entropy——二分类任务的标准损失

$$\displaystyle BCE = - [ y \cdot log(\hat{y}) + (1-y) \cdot log(1-\hat{y}) ]$$ y：真实标签（0或1）   ŷ：模型预测的正类概率（0到1之间，由Sigmoid输出）
当y=1时，只看 -log(ŷ)，预测越接近1损失越小；当y=0时，只看 -log(1-ŷ)，预测越接近0损失越小。

📌 使用场景

二分类问题：垃圾邮件检测、疾病诊断、情感分析（正面/负面）、是否点击等。

输出层激活函数：必须是 Sigmoid，把输出压缩到0-1概率区间。

🔑 直观理解

如果真实标签是1（正例），但模型预测0.01（非常确信是负例），loss会非常大（log(0.01)≈-4.6），会给模型一个很大的惩罚！

这就是"置信度越高但预测错了，惩罚越重"。

多分类交叉熵 Cross-Entropy Loss

多分类任务（如10分类）的标准损失

$$\displaystyle CrossEntropy = - \sum y_i \cdot log(\hat{y}_i)$$ yᵢ：真实标签的one-hot编码（正确类别是1，其他是0）
ŷᵢ：模型预测每个类别的概率（由Softmax输出，所有类别概率和为1）
由于y是one-hot，实际上只计算正确类别的 -log(ŷ)，其他项都是0。

⚠️ PyTorch重要注意事项

nn.CrossEntropyLoss 内置了 LogSoftmax + NLLLoss！

这意味着：
• 网络最后一层 不要 加 Softmax！直接输出原始logits即可
• 真实标签 y 直接传类别索引（0-9这样的整数），不要 转one-hot
• 如果你不小心最后加了Softmax，再用CrossEntropyLoss，相当于算了两次，效果会变差！

分类损失：PyTorch代码示例

BCE和CrossEntropy的正确用法

import torch
import torch.nn as nn

# ========== 二分类：BCE With Logits Loss（推荐） ==========
# BCEWithLogitsLoss = Sigmoid + BCELoss 合二为一，数值更稳定！
bce_loss = nn.BCEWithLogitsLoss() # 不需要自己加Sigmoid！
logits = torch.tensor([1.5, -2.0, 0.8]) # 原始输出，不是0-1概率
labels = torch.tensor([1.0, 0.0, 1.0]) # 0或1
loss_bce = bce_loss(logits, labels)

# ========== 多分类：CrossEntropyLoss ==========
ce_loss = nn.CrossEntropyLoss() # 内置了LogSoftmax，不要自己加Softmax！
logits = torch.tensor([[2.0, 1.0, 0.1], # batch=3, 类别=3
                      [0.5, 2.5, 0.3],
                      [0.2, 0.4, 3.0]])
labels = torch.tensor([0, 1, 2]) # 直接传类别索引，不是one-hot！
loss_ce = ce_loss(logits, labels)

💡 最佳实践

二分类用 BCEWithLogitsLoss，多分类用 CrossEntropyLoss，这两个都内置了激活函数，数值稳定性更好，不容易出NaN。

为什么交叉熵比MSE更适合分类？

从梯度角度看根本原因

$$\displaystyle MSE + Sigmoid 梯度： \partial L/ \partial w = (\hat{y}-y) \cdot \hat{y}(1-\hat{y}) \cdot x \ CrossEntropy + Sigmoid 梯度： \partial L/ \partial w = (\hat{y}-y) \cdot x$$ 注意MSE的梯度多乘了一个 ŷ(1-ŷ)！当ŷ接近0或1（也就是模型非常确信自己的预测时），ŷ(1-ŷ)趋近于0，梯度消失！

而交叉熵的梯度就是(ŷ-y)，误差越大梯度越大，误差越小梯度越小——完美符合直觉！

😱 MSE的"信心悖论"

当模型预测错了但非常自信时（比如y=1但ŷ=0.01），恰恰是最需要大梯度纠正的时候，但ŷ(1-ŷ)≈0，梯度几乎为0——模型"知错不改"！

😎 交叉熵的"赏罚分明"

预测错了且越自信，梯度越大，惩罚越重；预测对了且越自信，梯度越小，越稳定。这正是我们想要的！

Focal Loss：解决类别不平衡

让模型专注于"难分样本"，降低简单样本权重

$$\displaystyle FL(pₜ) = - \alpha ₜ \cdot (1-pₜ)ᵞ \cdot log(pₜ)$$ pₜ：模型对正确类别的预测概率
γ (gamma)：聚焦参数，通常取2。样本越容易分（pₜ接近1），(1-pₜ)ᵞ越小，权重被降低
α (alpha)：类别平衡因子，给少数类更高权重

🎯 解决的问题

在类别不平衡场景下（比如目标检测中大部分区域是背景），大量简单负样本的loss会主导梯度，导致模型学不好难样本。

💡 核心思想

降低易分样本（预测概率>0.9）的权重，让模型把"注意力"集中在那些预测错了的、难分的样本上。

📌 典型应用

目标检测（RetinaNet提出Focal Loss，一阶段检测器精度首次超过二阶段）、稀有类别检测、正负样本极不平衡的场景。

Triplet Loss：度量学习

学习样本间的距离/相似度，用于人脸识别、检索

👤 Anchor
基准样本
📏 Triplet Loss
拉近同类，推远离类
✅ Positive
同类样本（要近）
❌ Negative
异类样本（要远）
$$\displaystyle L = max(0, d(a,p) - d(a,n) + margin)$$ d(a,p)：Anchor和Positive的距离    d(a,n)：Anchor和Negative的距离
margin：间隔，通常取0.2-1.0。目标是让 d(a,p) + margin < d(a,n)，即同类距离至少比异类近margin

📌 应用场景

人脸识别（FaceNet）、图像检索、人脸验证（判断两张脸是不是同一个人）、推荐系统、表征学习。

和Triplet Loss类似，但用成对样本。同类样本拉近距离，异类样本推远到超过margin。常用于Siamese网络。

衡量两个概率分布的差异。常用于生成模型（VAE、GAN）、知识蒸馏（让学生模型学习老师模型的输出分布）。

Hinge Loss 合页损失

SVM的经典损失，也用于某些分类场景。最大化类别间隔，要求正确类别的得分比其他类别高至少margin。

损失函数设计原则

设计一个好的损失函数需要满足什么条件？

📐

1. 可导（几乎处处）

损失函数必须能求梯度，否则反向传播无法进行。允许在有限个点不可导（如MAE在0点），其他点必须可导。

🎯

2. 与评估指标相关

损失函数要和你真正关心的指标（准确率、IOU、F1等）一致。Loss下降但指标不升，说明损失设计得不对。

🛡️

3. 鲁棒性（视情况）

如果数据中有噪声/异常值，损失不能对outlier太敏感（Huber比MSE鲁棒）。干净数据则不用太担心。

💡 进阶技巧：多任务损失

如果一个模型要做多个任务（比如目标检测既要分类又要定位），可以把多个损失加权相加：Loss = λ₁·L_cls + λ₂·L_box。权重λ需要调整，保证各任务损失量级相当。

训练中Loss曲线解读

看懂Loss曲线，诊断训练问题

✅

理想情况

Train Loss ↓ 稳定下降
Val Loss ↓ 也稳定下降
最后两者都收敛到较低值，差距不大——模型训练健康，泛化良好。

⚠️

过拟合

Train Loss ↓ 持续下降
Val Loss 先↓后↑
验证集loss上升是过拟合信号！模型在死记硬背训练集，泛化能力变差。

❌

训练不动

Train Loss 几乎不下降
Val Loss 也不动
可能原因：学习率不对、模型容量不够、梯度消失/爆炸、数据/标签有问题。

正则化与损失函数

在损失函数中加入正则化项，防止过拟合

$$\displaystyle Loss_total = Loss_data + \lambda \cdot Loss_reg$$ 总目标函数 = 数据拟合损失（预测错多少） + 正则化项（惩罚模型复杂度）
λ 是正则化强度超参数，越大正则化越强。

L2正则化（权重衰减）

公式： λ·Σw²

让权重趋向于0但不为0，防止权重过大，模型更平滑。

PyTorch：optimizer中设置weight_decay参数（如Adam的weight_decay=1e-4）

让一部分权重变为0，产生稀疏解，相当于做特征选择。

损失函数 vs 评估指标

这两个不是一回事！别混淆了

📏 损失函数 Loss

  • 用于训练：可导，用来计算梯度更新参数
  • 必须处处可导（或几乎处处）
  • 是优化过程的"代理目标"
  • 例子：CrossEntropy、MSE
  • 关注的是"能不能优化"
VS

🎯 评估指标 Metric

  • 用于评估：衡量模型最终好坏
  • 不需要可导，可以是不可微的
  • 是真正关心的业务目标
  • 例子：准确率、F1、IOU、AUC
  • 关注的是"业务上好不好"

⚠️ 常见误区

分类任务的损失是CrossEntropy，但评估指标是准确率。Loss越低不代表准确率越高（尤其是类别不平衡时）。选模型看验证集指标，而不是只看train loss。

本集知识点总结

损失函数核心要点回顾

📌 核心概念

损失函数量化预测与真实的差距，是优化的目标。Loss（单样本）、Cost（整体平均）、Objective（广义目标）。

📈 回归损失

MSE：凸函数可导，但对异常值敏感
MAE：鲁棒，但零点不可导
Huber/Smooth L1：结合两者优点

🔍 分类损失

BCE：二分类，配Sigmoid
CrossEntropy：多分类，配Softmax
分类不要用MSE（梯度消失+非凸）

⚠️ PyTorch重要提醒

nn.CrossEntropyLoss 和 nn.BCEWithLogitsLoss 内置了激活函数！最后一层不需要加Softmax/Sigmoid，标签格式也要注意。

🎯 进阶损失

Focal Loss：类别不平衡，聚焦难样本
Triplet Loss：度量学习、人脸识别
多任务：加权组合多个损失

📊 Loss曲线解读

Train降Val升→过拟合
都不降→学习率/容量问题
Loss=NaN→梯度爆炸
