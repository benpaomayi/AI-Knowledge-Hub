卷积运算：CNN的核心

卷积（Convolution）到底是怎么算的？

🎯 一句话概括

卷积核（Kernel/Filter）在输入图像上滑动，在每个位置上做逐元素相乘再求和，得到输出特征图（Feature Map）上的一个值。

🔲

输入图像

一个二维矩阵（或三维张量）
比如5×5或224×224

🔳

卷积核/滤波器

一个小的权重矩阵
比如3×3、5×5、7×7
权重是学习出来的

📊

输出特征图

卷积运算的结果
每个值对应一个位置的响应
响应越强 = 特征越匹配

卷积核的直观理解

每个卷积核就是一个"特征检测器"

🔍 怎么理解卷积核？

想象你拿着一个"模板"在图像上扫描：
• 当图像局部和模板匹配时 → 输出值大（激活）
• 当图像局部和模板不匹配时 → 输出值小（抑制）

一个卷积核专门检测一种特定特征！

💡 例子

不同的卷积核学会检测不同的东西：

水平边缘 垂直边缘 45°边缘 颜色斑块 纹理模式 眼睛形状 车轮轮廓

🤖 关键：权重是学出来的！

我们不需要手动设计这些核。通过反向传播，CNN自动学习出最适合当前任务的卷积核权重。浅层学边缘，深层学复杂特征。

卷积运算详细步骤

一步一步看卷积是怎么算出来的

步骤1：定位 将卷积核放在输入图像的左上角（起始位置）
步骤2：乘加 对应位置：输入值 × 卷积核权重，然后全部加起来（再加上偏置b）
步骤3：赋值 这个结果就是输出特征图对应位置的一个值
步骤4：滑动 卷积核向右移动一个步幅（stride），重复步骤2-3
步骤5：换行 到最右边后，向下移动一个步幅，回到左边继续
步骤6：完成 重复直到覆盖整个输入图像，得到完整的输出特征图

📝 术语

这个"逐元素相乘再求和"的运算有个名字叫互相关（Cross-Correlation）。严格数学意义上的卷积还要翻转核，但在深度学习中我们通常直接叫"卷积"，不做翻转——因为翻转与否不影响学习（权重会自动适应）。

 [ 1, 1, 1]]

检测水平方向的亮度变化：上面暗下面亮时响应强。

 [-1, 0, 1]]

检测垂直方向的亮度变化：左边暗右边亮时响应强。

1/9 × [[1,1,1],

 [-1, 5,-1],

强调中心像素，让图像更锐利、边缘更清晰。

手工设计核 vs 自动学习核

传统CV和深度学习的本质区别

👨‍🔬 传统CV：手工设计

Sobel、Canny、SIFT、HOG……都是研究员手工设计的特征提取器：

  • 需要专家知识设计特征
  • 每个检测器只能检测一种特定特征
  • 对不同任务需要重新设计
  • 效果上限低，泛化能力差
  • 代表：SIFT特征+SVM分类

🤖 深度学习CNN：自动学习

卷积核权重通过反向传播自动从数据中学习：

  • 不需要人工设计特征
  • 每层自动学习不同抽象层级的特征
  • 端到端训练，特征+分类一起学
  • 效果远超传统方法
  • 代表：AlexNet、ResNet

🏆 特征学习的革命

从"手工设计特征"到"自动学习特征"，这是深度学习超越传统方法的关键。CNN低层学到的核其实和手工设计的边缘核很像——但高层能学到更复杂的语义特征，这是手工做不到的。

卷积核大小(Kernel Size)

为什么3×3是最常用的卷积核大小？

1×1

不看空间邻域
只做跨通道融合
用于降维/升维

3×3 最常用

最小的能捕捉上下左右中心的核
参数少，效率高
堆叠可获得大感受野

5×5 / 7×7

第一层有时用大核
直接看更大区域
但参数更多

💡 VGGNet的洞见：小核堆叠更好！

两个3×3卷积堆叠，感受野 = 一个5×5卷积（3+3-1=5），但参数量更少：
• 两个3×3：2×(3×3) = 18个参数
• 一个5×5：5×5 = 25个参数（多39%！）

而且中间多了一次非线性激活（ReLU），表达能力更强。这就是VGGNet全部用3×3卷积的原因。

⚠️ 为什么用奇数？

奇数大小有明确的中心点，方便Padding对称（如3×3填1圈0，5×5填2圈0保持尺寸不变）。偶数核无法做到Same Padding。

问题：卷积后特征图变小

不做任何处理，每次卷积都会让图像缩小，边缘信息被浪费

📉 尺寸持续缩小

5×5输入经过3×3卷积后变成3×3，再卷一次变成1×1。如果是224×224的图像，经过几层卷积就变得很小，深层网络无法构建。

⚠️ 更严重的问题：边缘像素只被计算一次

想象一个6×6输入用3×3核卷积：

• 角落像素（如左上角）只在1个位置参与计算
• 边上非角落像素参与2~3个位置计算
• 中心区域像素参与多个位置计算

→ 边缘信息被"扔掉"了！图像边缘的特征提取不充分

✅ 解决方案：Padding（填充）

在输入图像边缘补一圈（或几圈）0，让卷积核在边缘也能"滑"到同样多次，同时可以控制输出特征图的大小！

Padding填充

在边缘补零，解决信息丢失和尺寸缩小问题

Valid Padding（无填充）

P = 0，不补任何东西
输出尺寸 = (I - K)/S + 1
每次卷积尺寸变小
边缘信息丢失

例：5×5 → 3×3（3×3核，S=1）

Same Padding（同尺寸填充）

补P圈0，使输出尺寸 = 输入尺寸
P = (K - 1) / 2（当S=1时）
3×3核 → P=1，5×5核 → P=2
边缘像素也能充分参与计算

例：5×5 → 5×5（3×3核，P=1，S=1）
Same Padding填充量：P = (K - 1) / 2 当Stride=1时，填这么多0就能让输出尺寸与输入相同。比如K=3→P=1，K=5→P=2，K=7→P=3。

💡 Full Padding（不常用）

补更多的0，让输出比输入还大：P = K - 1。通常只用在特殊场景（如分割网络解码阶段、转置卷积）。

Stride步幅

卷积核每次移动几个像素？步幅控制下采样速度

Stride = 1（默认）

每次移动1个像素
逐个像素滑动
保留最密集的信息
计算量最大
用于特征提取的主要部分

Stride = 2（下采样）

每次跳1个像素，移动2格
输出尺寸直接减半
相当于自带下采样效果
计算量减为1/4
现代架构常用stride=2卷积替代池化

📐 Stride=2的效果

7×7输入用3×3核，P=0：
• S=1 → (7-3)/1+1 = 5×5输出
• S=2 → (7-3)/2+1 = 3×3输出（尺寸大幅缩小！）

💡 Stride的作用

Stride>1可以快速降低特征图分辨率，减少计算量和参数量，同时增大感受野。但步幅太大会丢失信息，通常S=1或S=2最常用，S=3以上很少用。

重点：输出尺寸公式

这个公式一定要记住！写CNN代码时随时要用

O = ⌊(I - K + 2P) / S⌋ + 1 O = 输出尺寸（Output size）
I = 输入尺寸（Input size）
K = 卷积核大小（Kernel size）
P = Padding填充量
S = Stride步幅
⌊·⌋ 表示向下取整（某些框架处理方式不同，PyTorch默认向下取整）

🧮 常见尺寸计算例子

例1：I=224, K=3, P=1, S=1 → O = (224-3+2)/1+1 = 224（Same Conv，尺寸不变）
例2：I=224, K=3, P=0, S=1 → O = (224-3+0)/1+1 = 222（Valid Conv，缩小2像素）
例3：I=224, K=3, P=1, S=2 → O = (224-3+2)/2+1 = ⌊223/2⌋+1 = 111+1 = 112（下采样减半）
例4：I=7, K=3, P=0, S=2 → O = (7-3+0)/2+1 = 2+1 = 3

⚠️ 初学者最常犯的错误

尺寸不匹配报错！写CNN代码时一定要用这个公式提前算好每层输出尺寸。如果shape不对，模型一运行就会报错。

多通道卷积

RGB图像有3个通道，卷积核也要有通道！

🔴🟢🔵 彩色图像怎么办？

之前我们只看了单通道（灰度图）的卷积。RGB图像有3个通道，卷积核也必须是3通道的！每个通道单独做卷积，然后三个通道结果相加，得到1个输出通道。

Output(x,y) = Σc=0到C-1 Σi=0到K-1 Σj=0到K-1 W(c,i,j) × Input(c, x+i, y+j) + b C是输入通道数（比如RGB的C=3）。每个输出通道对应一个K×K×C的卷积核，再加上一个偏置b。

📐 卷积核维度

多通道情况下，一个卷积核的维度是：K × K × C_in

比如：处理RGB图像的3×3卷积核，维度是 3×3×3 = 27个权重 + 1个偏置 = 28个参数。

💡 记住

不管输入有多少个通道，一个卷积核只产生一个输出通道。这就是为什么1个输出通道对应1个偏置b。

多卷积核 = 多输出通道

想要多个特征图？用多个卷积核！

🎯 N个卷积核 → N个输出通道

如果我们有N个不同的卷积核，每个核产生一个特征图，叠加起来就得到N个输出通道的特征图。

输入 H×W×Cin
如224×224×3
×
Cout个卷积核
每个K×K×Cin
→
输出 H'×W'×Cout
如224×224×64

🧮 参数量计算（重要！）

卷积层总参数量 = K × K × Cin × Cout + Cout

解释：每个输出通道有一个K×K×C_in的卷积核（K²C_in个权重）+ 1个偏置。C_out个输出通道，所以总参数是K²C_inC_out（权重）+ C_out（偏置）。

🔢 例子

输入3通道，输出64通道，3×3卷积：
参数量 = 3×3×3×64 + 64 = 1,792个参数！相比全连接的上亿参数，确实非常少。

特殊卷积：1×1卷积

看起来没用，实际上是现代CNN的关键组件！

🤔 1×1卷积在做什么？

K=1的卷积核，不看任何空间邻域（只有1个像素），但它可以跨通道融合信息——相当于在每个像素位置上做一次全连接层计算。

📉 降维（减少通道数）

输入256通道，用64个1×1卷积 → 输出64通道
大幅减少后续卷积的计算量
ResNet/Inception中的Bottleneck结构就是这么做的

📈 升维（增加通道数）

输入64通道，用256个1×1卷积 → 输出256通道
增加通道数，提升特征表达能力
也用于匹配残差连接的维度

🔗 跨通道信息融合

即使不改变通道数，1×1卷积也能学习通道间的线性组合，融合不同通道的信息，增加非线性（后面接ReLU）。

📜 历史

1×1卷积最早在Network in Network（2013）中提出，后来在Inception、ResNet、MobileNet等架构中被广泛使用，是设计高效CNN的利器。

1×1卷积的降维效果

为什么1×1卷积能节省大量计算？

❌ 直接用5×5卷积（计算量大）

输入：28×28×192，输出：28×28×32（32个5×5卷积核，Same Padding）

参数量 = 5×5×192×32 + 32 = 153,632
计算量 ≈ 153,632 × 28 × 28 ≈ 1.2亿次乘加

✅ 先用1×1降维再用5×5（Inception思路）

先用16个1×1卷积把通道降到16，再用32个5×5卷积：

1×1层参数量 = 1×1×192×16 + 16 = 3,088
5×5层参数量 = 5×5×16×32 + 32 = 12,832
总参数量 ≈ 15,920（减少约90%！）
计算量也同比大幅减少

💡 这就是Inception模块的核心技巧

用1×1卷积"瓶颈层"降维，再用大核卷积，既保留了大感受野，又大幅降低计算量。这让GoogLeNet能做到22层但计算量还比AlexNet小！

感受野（Receptive Field）

一个输出像素能"看到"输入图像的多大区域？

👁️ 什么是感受野？

输出特征图上一个像素，在输入图像上对应的区域大小。感受野越大，这个神经元"看"得越远，获取的信息越全局。

堆叠n层3×3卷积的感受野 = 2n + 1 每层3×3卷积让感受野增加2。这是最简单的感受野计算（Stride=1时）。

📊 3×3卷积堆叠的感受野增长

1层3×3卷积 → RF = 3×3
2层3×3卷积 → RF = 5×5
3层3×3卷积 → RF = 7×7
5层3×3卷积 → RF = 11×11
10层3×3卷积 → RF = 21×21

🏔️ 深层网络 = 大感受野

这解释了为什么深层网络能识别复杂物体：越深层的神经元感受野越大，能"看到"整张图的大部分区域，整合全局信息理解语义。

卷积层参数量 vs 计算量

学会计算参数量和FLOPs，理解网络效率

🧮 参数量（Params）

Params = K × K × Cin × Cout + Cout

模型存储大小、显存占用与参数量相关。参数需要存储和更新，越少越高效。

例：3×3卷积，3→64通道：
Params = 3×3×3×64 + 64 = 1,792

⚡ 计算量（FLOPs）

FLOPs ≈ 2 × Hout × Wout × K² × Cin × Cout

乘加运算次数，决定训练/推理速度。FLOPs越大，计算越慢。（乘和加算2次FLOPs）

例：224×224输入，3×3卷积，3→64通道：
FLOPs ≈ 2×224×224×9×3×64 ≈ 1.74亿

💡 观察

参数量和输入尺寸无关（只和核大小、通道数有关），但计算量和输出尺寸H_out×W_out成正比。所以下采样（Stride=2/Pool）能大幅减少后续层的计算量！

一张表总结卷积层的所有关键参数

参数 含义 常见取值 说明
Kernel Size (K) 卷积核大小 1, 3, 5, 7 3×3最常用，奇数方便Same Padding
Stride (S) 步幅 1, 2 S=1正常卷积，S=2下采样减半
Padding (P) 填充量 0, 1, 2 P=0(Valid), P=(K-1)/2(Same)
Input Channels (Cin) 输入通道数 3, 64, 128, 256, 512 RGB图C=3，随网络加深通常增加

Bias 偏置项 True/False 接BN层时通常不需要bias（BN自带偏移）

• Same Conv (S=1, P=(K-1)/2): O = I
• 下采样 (S=2, P=K/2取整): O = I/2
• 不确定就用公式 O = ⌊(I-K+2P)/S⌋ + 1 算

常见问题FAQ

初学者最常问的几个问题

❓ Q: 为什么叫"卷积"而不是"互相关"？

A: 严格数学定义中卷积需要先翻转核，但深度学习中我们不翻转（等于互相关）。原因是：如果卷积核是学习出来的，学一个翻转的核和学一个不翻转的核能力完全一样，不影响结果。所以大家都直接叫卷积。

❓ Q: 为什么通道数随着网络加深而增加？

A: 空间分辨率减小（下采样），但特征更抽象，需要更多通道来编码丰富的语义信息。分辨率减半通常通道数翻倍，保持计算量大致平衡（经典设计：64→128→256→512）。

❓ Q: 3×3+Pad=1+S=1为什么尺寸不变？

A: O = (I-3+2×1)/1+1 = (I-1)+1 = I。完美！每次计算时，多出来的2个Padding刚好补上卷积核"少滑"的部分。

❓ Q: 偏置(bias)什么时候需要？

A: 如果卷积层后面接BatchNorm，BN层已经有可学习的偏置参数(β)，此时卷积层可以不加bias（加了也被BN抵消），节省参数。如果后面没有BN则需要bias。

本集核心要点总结

卷积层核心知识一页纸总结

🔧 卷积运算

卷积核在输入上滑动，逐元素相乘再求和。一个核检测一种特征，权重通过反向传播学得。

📐 关键超参数

K（核大小，常用3×3）、S（步幅，常用1/2）、P（填充，Same/Valid）、Cin/Cout（通道数）。

📏 尺寸公式

O = ⌊(I-K+2P)/S⌋ + 1。Same Conv保持尺寸，S=2尺寸减半。

🔢 多通道卷积

卷积核维度K×K×Cin，N个核输出N通道。参数量=K²CinCout+Cout。

✨ 特殊卷积

1×1卷积用于降维/升维/跨通道融合，是高效CNN设计的关键（Inception/ResNet）。

👁️ 感受野

输出一个像素看到的输入区域大小。3×3卷积堆叠n层RF=2n+1，深层RF大，看全局。
