逻辑回归—最常用的分类模型

⏱ 29分22秒 · BV1gZDVBUEqC

💡 核心思想

线性回归输出连续值（如房价），但分类问题需要输出类别（如"是/否垃圾邮件"）。逻辑回归的核心思想：先用线性回归算出一个值，再通过Sigmoid函数把它"压缩"到0~1之间，表示属于正类的概率。

Sigmoid函数

📈 从线性到概率的映射

σ(z) = 1 / (1 + e-z)
其中 z = wx + b（线性回归的输出）

Sigmoid函数将任意实数映射到(0,1)区间，完美表示概率：

  • z很大（正数）→ σ(z)接近1 → 预测为正类
  • z很小（负数）→ σ(z)接近0 → 预测为负类
  • z=0 → σ(z)=0.5 → 决策边界
  • 输出0.7表示有70%概率属于正类
损失函数

📉 对数损失（交叉熵损失）

不能用MSE（非凸，有局部最优），改用对数损失：

J = -(1/n)Σ[y·log(ŷ) + (1-y)·log(1-ŷ)]
  • 当真实y=1时，惩罚- log(ŷ)，预测越接近0惩罚越大
  • 当真实y=0时，惩罚- log(1-ŷ)，预测越接近1惩罚越大
  • 对数损失是凸函数，梯度下降保证找到全局最优
分类评估指标

🎯 分类模型如何评估？

TP/TN
真阳性/真阴性（预测正确）
FP/FN
假阳性/假阴性（预测错误）
Precision
精确率 = TP/(TP+FP)
预测为正中真的比例
Recall
召回率 = TP/(TP+FN)
真实正中被找出的比例
F1
F1 = 2·P·R/(P+R)
精确率和召回率的调和平均
AUC
ROC曲线下面积
越接近1越好，衡量排序能力

决策树——会 if...else 就能懂的机器学习算法

⏱ 17分04秒 · BV1M8D7BWEVQ

💡 直觉理解

决策树就是一层一层的if-else判断。比如判断"今天要不要出去玩"：if 天气=晴 → if 湿度<70% → 去；else → 不去。你每天其实都在用决策树做决策！

划分准则

🌳 如何选择最佳划分特征？

核心问题：每次分裂时，哪个特征最能区分数据？

  • 信息增益（ID3）：划分后信息熵减少多少，减少越多越好
  • 信息增益率（C4.5）：修正信息增益偏向多值特征的问题
  • 基尼系数（CART）：随机抽两个样本类别不一致的概率，越小越纯
信息熵：H(S) = -Σpᵢ·log(pᵢ)
基尼系数：Gini(S) = 1 - Σpᵢ²
pᵢ是第i类样本的比例，熵/基尼越小说明节点越"纯"
关键问题

✂️ 剪枝：防止过拟合

决策树如果不限制，会一直分裂直到每个叶子节点只有一个样本——完美记住训练数据，但在新数据上表现很差（过拟合）。

  • 预剪枝：训练时提前停止
    　- 限制树的最大深度（max_depth）
    　- 限制叶子节点最少样本数（min_samples_leaf）
    　- 分裂所需最小样本数（min_samples_split）
  • 后剪枝：先训练完整树，再裁掉没用的分支

随机森林——决策树模型升级版

⏱ 12分57秒 · BV1NgQuBFEVY
集成学习·Bagging

🌲🌲🌲 三个臭皮匠赛过诸葛亮

单棵决策树容易过拟合，且对训练数据敏感。随机森林训练多棵决策树，让它们投票决定最终结果，大大提升稳定性和准确率。

随机森林 = Bagging + 随机特征选择
1. Bootstrap有放回抽样生成不同子集
2. 每个子集训练一棵决策树
3. 分裂时随机选部分特征
4. 所有树投票/平均得出结果
为什么"随机"？

🎲 双重随机保证多样性

  • 随机样本：每棵树用Bootstrap抽样（有放回）得到不同训练集，约63%原始样本
  • 随机特征：每次分裂只考虑随机选的部分特征（通常√n个）
  • 双重随机确保树之间差异大，集成效果更好
  • 未被抽到的37%数据称为袋外数据（OOB），可用于验证

✅ 随机森林优势

几乎不需要调参就能取得好效果、抗过拟合能力强、能输出特征重要性、并行训练速度快、工业界最常用的baseline模型之一。

集成学习之Boosting模型——XGBoost、LightGBM、CatBoost

⏱ 23分50秒 · BV1QdQJBTEGV

📦 Bagging（并行）

独立训练多个模型，投票/平均
代表：随机森林

✓ 减少方差，防过拟合
✓ 并行训练速度快
✗ 对偏差改善有限

🚀 Boosting（串行）

sequentially训练，每棵树纠正前一棵树的错误
代表：AdaBoost/GBDT/XGBoost

✓ 减少偏差，精度极高
✓ 工业竞赛大杀器
✗ 串行训练相对较慢

GBDT原理

🔧 梯度提升决策树

Boosting的核心思想：每棵新树学习前面所有树的残差（预测误差），逐步逼近真实值。

  • 第1棵树：直接预测目标值
  • 第2棵树：预测第1棵树的残差（真实值-预测值）
  • 第3棵树：预测前两棵树加起来后的残差
  • 最终预测 = 所有树的预测值加起来
  • 用梯度下降的思路拟合负梯度（残差是梯度的特例）
三大神器

⚡ XGBoost / LightGBM / CatBoost

  • XGBoost：GBDT工程优化版，正则化防过拟合、二阶泰勒展开、并行处理、缺失值自动处理，Kaggle竞赛神器
  • LightGBM：微软出品，直方图算法+按叶子生长（leaf-wise），速度比XGBoost快10倍，内存占用更低
  • CatBoost：Yandex出品，自动处理类别特征（无需手动编码），对类别变量友好，鲁棒性强
# sklearn中使用集成学习
from sklearn.ensemble import RandomForestClassifier
from xgboost import XGBClassifier
from lightgbm import LGBMClassifier

# 随机森林
rf = RandomForestClassifier(n_estimators=100, max_depth=10)
rf.fit(X_train, y_train)

# XGBoost (竞赛最常用)
xgb = XGBClassifier(n_estimators=200, learning_rate=0.1, max_depth=6)
xgb.fit(X_train, y_train, eval_set=[(X_val,y_val)], early_stopping_rounds=20)

# LightGBM (速度最快)
lgb = LGBMClassifier(n_estimators=200, learning_rate=0.1)
lgb.fit(X_train, y_train)
