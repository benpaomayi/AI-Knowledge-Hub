什么是聚类(Clustering)？

聚类就是"物以类聚，人以群分"——自动把相似的东西归为一类

聚类的定义：将物理或抽象对象的集合，分成由类似的对象组成的多个类（簇/Cluster）的过程。

简单说就是：相似度高的样本分到同一组，相似度低的样本分到不同组。

$$\displaystyle 相似的聚在一起，不同的分开$$ 这是人类最基本的认知能力之一。你走进一个房间，一眼就能分辨出哪些人是一伙的，哪些物品是一类的——聚类就是让机器也拥有这种能力。

💡 关键直觉

聚类是一种探索性分析——你事先不知道有哪些类别，也不知道每个类别是什么，而是让算法告诉你数据里自然存在几个分组。这和分类（你提前知道类别）完全不同。

聚类的应用场景

聚类在工业界有非常广泛的实际应用

👥

客户分群

电商/银行根据用户的消费行为、消费金额、活跃度等特征，把用户分成不同群体（如高价值客户、潜力客户、流失客户），做精准营销。

🖼️

图像分割

把图片中相似的像素聚成一类，实现前景背景分离、物体识别。比如医学影像中把肿瘤区域自动分割出来。

🚨

异常检测

正常数据会聚成簇，那些离群的、不属于任何簇的点就是异常值。用于信用卡欺诈检测、网络入侵检测、工业故障检测。

📄

文档分类

根据文档内容的相似度，自动把新闻、文章、网页聚成不同主题（体育、财经、科技、娱乐……），用于话题发现、内容推荐。

🎬

推荐系统

把相似用户聚成一类（用户聚类），或者把相似物品聚成一类（物品聚类），然后给你推荐"和你相似的人喜欢的东西"。

🧬

基因分析

生物信息学中，根据基因表达模式对基因或样本聚类，发现不同的基因亚型、辅助疾病诊断。

K-Means算法介绍

最经典、最常用、也是最简单的聚类算法——没有之一

📅 历史地位

K-Means算法最早可以追溯到1955年，1967年由MacQueen正式提出。虽然已经过去了半个多世纪，但它至今仍然是工业界应用最广泛的聚类算法。

⭐ 为什么这么流行？

原理简单、容易理解、实现容易、计算速度快、聚类效果不错、对大数据友好——这些优点让它成为聚类算法的"入门第一课"和"首选基准"。

K-Means名字的含义：

  • K——表示你想把数据分成 K 个簇（这个K需要你提前指定）
  • Means——是"均值"的意思，每个簇的中心点是这个簇所有点的均值（质心）

💡 一句话总结K-Means

给定K，算法通过迭代，找到K个中心点，让每个数据点到离它最近的中心点的距离平方和最小。

K-Means的目标：将数据划分为K个簇

我们希望达到什么效果？簇内紧密，簇间远离

假设我们有一堆数据点（比如二维平面上的点），我们希望算法把它们分成K个组（簇）：

$$\displaystyle 好的聚类 = 簇内相似度高 + 簇间相似度低$$

✅ 好的聚类效果

• 同一个簇里的点紧紧挨在一起（距离近）
• 不同簇之间离得越远越好
• 簇的形状大致是球形/凸形
• 每个簇大小差不多时效果最好

❌ 不好的聚类效果

• 同一簇里的点很分散
• 不同簇重叠在一起
• 出现极端大小的簇（一个簇很大，其他很小）
• 非球形的簇（K-Means不擅长）

🎯 K-Means的核心假设

K-Means隐含假设"簇是球形的"，每个簇的中心就是均值点。这是它的优点（简单高效），也是它的局限（只能发现球形簇）——后面会详说。

质心(Centroid)概念：每个簇的中心点

质心是K-Means中最核心的概念——每个簇都有一个"代表点"

📍 什么是质心？

质心就是一个簇里所有数据点的均值点——每一维特征都取这个簇所有点在该维的平均值。

质心代表了这个簇的"中心位置"，是这个簇的"代言人"。一个点属于哪个簇，就看它离哪个质心最近。

$$\displaystyle \mu ₖ = (1/|Cₖ|) \cdot \sum _{x∈Cₖ} x$$ 符号说明：
• μₖ —— 第k个簇的质心（Centroid）
• Cₖ —— 第k个簇中的所有样本点的集合
• |Cₖ| —— 第k个簇中的样本数量
• 就是把簇里所有点加起来除以个数（求平均）

⚠️ 注意

质心不一定是一个真实存在的数据点！它是计算出来的"虚拟点"，代表这个簇的中心位置。就像"平均家庭有2.5个孩子"——没有哪个家庭真的有2.5个孩子，但这个均值有意义。

目标函数：最小化簇内平方和

K-Means要优化什么？让每个点到它所属质心的距离平方和最小

K-Means有一个明确的优化目标，叫做簇内平方和（Within-Cluster Sum of Squares，简称WCSS），也叫惯性(Inertia)或失真(Distortion)。

$$\displaystyle J = \sum _{k=1到K} \sum _{x∈Cₖ} || x - \mu ₖ ||²$$ 目标函数（损失函数）解释：
• J —— 总的簇内平方和（我们要最小化它）
• 外层Σ：对K个簇求和
• 内层Σ：对第k个簇里的每个点x求和
• ||x - μₖ||² —— 点x到它所属质心μₖ的欧氏距离平方
• 直觉：每个点离自己簇中心越近，J越小，聚类越紧密

📐 为什么用距离平方？

和线性回归用MSE一样：1）数学性质好，容易求导优化；2）对远的点惩罚更大（鼓励把点聚得更紧）。注意K-Means用的是欧氏距离，所以它默认各特征尺度相同——实际使用前记得做特征标准化！

算法非常简单，就是不断重复"分配"和"更新"两步直到收敛

Step 1：初始化质心

随机选择K个点作为初始质心——算法的起点

怎么做？

  • 最简单的方法：从数据集中随机挑选K个样本点，直接作为初始质心
  • 这K个点就是一开始K个簇的"中心"

⚠️ 问题：对初始值敏感！

随机初始化可能会导致：
• 算法收敛到局部最优而不是全局最优
• 不同的随机种子得到不同的聚类结果
• 如果两个初始质心选得太近，可能得到不好的结果

💡 解决方案

实践中通常怎么做？

  • 多次运行：用不同的随机种子跑多次K-Means，选目标函数J最小的那次结果
  • K-Means++：一种更聪明的初始化方法（后面专门讲），让初始质心尽量离得远

🎯 sklean中的默认行为

sklearn的KMeans默认就用K-Means++初始化，而且默认跑10次(n_init=10)，选最好的一次——所以一般不用太担心初始化问题。

Step 2：分配簇——每个样本归到最近质心

这一步也叫"Assignment Step"——给每个点"找老大"

有了K个质心之后，遍历数据集中的每一个样本点：

$$\displaystyle 对于每个点x，找到离它最近的质心 \mu ₖ \ label(x) = argmin_{k} || x - \mu ₖ ||²$$ • 计算x到每个μₖ的距离（通常是欧氏距离）
• 哪个质心离x最近，x就属于那个簇
• 这一步结束后，每个点都有了自己的"簇标签"
📌 点x
计算到→
μ₁距离=5.2
μ₂距离=1.8
μ₃距离=7.3
→
✅ 分配给簇2
因为离μ₂最近

💡 这一步像什么？

就像K个质心是"队长"，每个点选择加入离自己最近的那个队长的队伍。这一步完成后，平面就被划分成了K个区域——这叫Voronoi图（泰森多边形）。

Step 3：更新质心——重新计算每个簇的均值

这一步也叫"Update Step"——队长挪位置，走到队伍的中心

分配完簇之后，每个簇里都有了一些点。现在对每个簇，重新计算质心：

$$\displaystyle 新的 \mu ₖ = 这个簇里所有点的平均值（每一维都求平均）$$

📍 举个简单例子

假设经过Step2，某个簇里有3个二维点：(1,2)、(3,4)、(5,6)

那新的质心就是：
x坐标平均：(1+3+5)/3 = 3
y坐标平均：(2+4+6)/3 = 4
所以新质心是 (3,4)

🔄 直观理解

Step2是"点选队长"，Step3是"队长走到队员中间"。点选最近的队长，队长挪到自己队员的中心位置——然后大家又重新选队长，队长又挪位置……如此反复。

Step 4：重复Step2-3直到收敛

什么时候停止？质心不再变化（或变化很小）

不断重复"分配簇→更新质心"这两步，直到满足收敛条件：

✅ 收敛条件1

质心不再变化
更新后的新质心和上一次的质心完全一样

✅ 收敛条件2

质心变化极小
新质心和旧质心的距离小于某个阈值（如1e-4）

✅ 收敛条件3

达到最大迭代次数
比如最多迭代100次，到了就停（防止特殊情况不收敛）

📉 一定会收敛吗？

是的！K-Means的目标函数J在每一步迭代中都是单调不增的（只会变小或不变，不会变大），而J又是有下界的（≥0），所以算法一定会收敛到某个局部最优值。这在数学上是有保证的。

⚠️ 注意

收敛到的是局部最优，不一定是全局最优。这就是为什么前面说K-Means对初始值敏感——好的初始化能让它收敛到更好的局部最优。

K-Means迭代过程动画解释

我们用文字一步步描述K-Means是怎么"动"起来的

0
初始状态：一堆散乱的点

假设我们有一堆二维数据点，肉眼看大概能分成3堆（但算法不知道）。我们设K=3。

1
第一次迭代：随机放3个质心

随机选3个点作为初始质心μ₁、μ₂、μ₃——这3个位置可能很随意，甚至不在任何"堆"的中心。

2
第一次分配：点选最近的质心

每个点看自己离哪个μ最近，就归到那个簇。你会看到点被染成3种颜色，但此时分群可能很混乱，边界怪怪的。

3
第一次更新：质心挪位置

每个μ走到自己颜色点的平均位置——你会看到μ明显向各自的"点堆"移动了一段距离！

4
第二次分配：重新选边站

μ挪了位置，有些点发现自己现在离另一个μ更近了，就"叛变"到另一个簇——点的颜色又变了一些。

5
重复……直到稳定

每次迭代，质心都会向真正的簇中心靠近一点，叛变的点越来越少……最后，μ不动了，点也不变色了——收敛完成！

K值如何确定？——肘部法则(Elbow Method)

K-Means需要你提前指定K，但K选多少合适呢？第一个方法：肘部法则

K-Means有一个"参数"需要你决定：K=? 也就是你想分成几簇。这是K-Means最让人头疼的问题——K是超参数，没法从数据里直接学出来。

肘部法则是最常用的确定K的方法：

Step 1：让K从1开始，依次取K=1,2,3,4,5,6,7……
Step 2：对每个K值，都跑一次K-Means，记录下对应的目标函数值J（簇内平方和Inertia）
Step 3：画一条"K-J"曲线（x轴是K，y轴是J）
Step 4：找曲线的拐点——那个像"手肘"一样的位置，对应的K就是最佳K

肘部法则详解：为什么选拐点？

理解曲线形状背后的含义——K增大时J怎么变？

先想一个问题：K越大，J会怎么变？

  • K=1时：所有点都在一个簇，J很大
  • K增大时：每个簇更小，点离质心更近，J会一直下降
  • K=N（样本数）时：每个点自己是一个簇，J=0

那为什么不直接选K=N让J=0？因为那就失去聚类的意义了——我们要的是"有意义的分组"，不是每个点一组。

💡 拐点的含义

观察K-J曲线：

  • 在拐点之前：K每增加1，J会大幅下降——因为增加簇能显著改善聚类效果
  • 在拐点之后：K继续增加，J下降得很缓慢——收益递减，再分也只是把一个簇拆得更细，没有本质改善
  • 那个"下降速度突然变慢"的拐点，就是"加簇不再带来明显收益"的点——这就是最佳K

⚠️ 局限

肘部法则很直观，但有时候曲线很平滑，没有明显的"手肘"——这时候就需要其他方法（比如轮廓系数）。

K值确定方法二：轮廓系数(Silhouette Score)

肘部法则有主观性？轮廓系数是更"量化"的评价指标

轮廓系数不仅考虑"簇内紧不紧"，还考虑"簇间远不远"——比单纯看J更全面。

$$\displaystyle 对每个样本点i，计算：s(i) = (b(i) - a(i)) / max(a(i), b(i)) \ 整体轮廓系数 = 所有点s(i)的平均值$$ 符号说明：
• a(i) —— 点i到同簇其他点的平均距离（簇内紧凑度，越小越好）
• b(i) —— 点i到最近的其他簇所有点的平均距离（簇间分离度，越大越好）
• s(i)的取值范围是 [-1, 1]

✅ s ≈ 1

点离自己簇很近，离其他簇很远——聚类效果非常好！

➖ s ≈ 0

点在两个簇的边界上，聚类效果一般，有重叠。

❌ s < 0

点离其他簇比自己簇还近——分错了！聚类效果很差。

🎯 怎么用轮廓系数选K？

和肘部法则类似：尝试不同的K值，跑K-Means，计算每个K对应的平均轮廓系数，选轮廓系数最大的那个K——最客观！

K-Means的优点

为什么K-Means历经半个多世纪还这么流行？它有很多突出优点

😀

原理简单

算法思想非常直观，容易理解，容易解释——"物以类聚，找中心点"，非技术人员也能听懂。聚类结果可解释性强。

⚡

速度快

时间复杂度是O(n·K·t)，n是样本数，t是迭代次数（通常很小，几十次就收敛）。对大数据集非常友好，是最快的聚类算法之一。

📊

适合大数据

不仅能处理中等规模数据，还有Mini-Batch K-Means变种，能处理百万级甚至更大规模的数据，可扩展性极好。

🌟 其他优点

• 数学原理清晰，收敛性有理论保证
• 实现简单，几乎所有机器学习库都有K-Means
• 聚类结果是凸的/球形的，很多场景下效果不错
• 参数少，主要就是调K一个参数
• 可以作为其他算法的预处理步骤（比如先聚类再做分类）

K-Means的缺点

没有银弹——K-Means也有明显的局限性，使用时要注意

❓

需预先指定K

K值是超参数，需要人工选定。肘部法则/轮廓系数能帮忙，但不是全自动的。选不对K结果会很差。

🎲

对初始值敏感

随机初始化可能收敛到不同的局部最优。虽然K-Means++和多次运行能缓解，但不能根本解决。

⚠️

对异常值敏感

质心是均值点，异常值（离群点）会把质心"拉偏"。用之前最好做异常检测和处理，或者考虑用K-Medoids（用中位数代替均值）。

🔴 最大局限：只能发现球形簇

这是K-Means最本质的缺陷：它假设簇是凸的、球形的、各向同性的。
• 对环形、月牙形、不规则形状的簇，K-Means完全分不出来
• 对大小差异很大、密度差异很大的簇，效果也不好
• 它用欧氏距离，默认各特征权重相同，必须先做特征缩放

K-Means++：优化初始质心选择

既然随机初始化不好，那我们就聪明地选初始质心

2007年，Arthur和Vassilvitskii提出了K-Means++，专门解决初始质心选择问题——这是一个小改进，但效果显著。

💡 K-Means++的核心思想

初始质心之间应该尽量离得远——不要把两个初始质心选在同一个簇里。

Step 1：从数据点中随机选1个点作为第一个质心μ₁
Step 2：计算每个点到最近已有质心的距离D(x)，一个点离已有质心越远，被选为下一个质心的概率越大
Step 3：按概率加权随机采样，选出下一个质心
Step 4：重复Step2-3，直到选出K个质心
Step 5：有了这K个"尽量分散"的初始质心后，再用标准K-Means继续迭代

✅ K-Means++的效果

理论上能保证O(log K)的近似比，实践中不仅大幅减少收敛到坏局部最优的概率，还能让迭代收敛更快。sklearn的KMeans默认就是用K-Means++初始化的（init='k-means++'），你基本不用自己做随机初始化了。

其他聚类算法简介

K-Means不是唯一选择——不同场景适合不同算法

🌳

层次聚类 (Hierarchical Clustering)

不需要提前指定K，它会构建一棵树（树状图/Dendrogram）：

  • 自底向上（凝聚）：一开始每个点自己是一簇，然后不断合并最相似的两个簇
  • 自顶向下（分裂）：一开始所有点在一个簇，然后不断分裂
  • 优点：能展示层次关系，不用提前选K
  • 缺点：计算慢，不适合大数据；对异常值敏感
🔮

DBSCAN 能发现任意形状！

基于密度的聚类——和K-Means思路完全不同：

  • 把"稠密区域"视为簇，稀疏区域视为噪声
  • 不需要指定K！能自动发现簇的数量
  • 能发现任意形状的簇！环形、月牙形都能分
  • 能自动识别异常点（噪声）
  • 缺点：对密度不均匀的数据效果不好，调参（eps, min_samples）有点麻烦

📌 算法选择建议

• 常规球形簇、大数据量、要速度 → K-Means（首选）
• 需要层次结构、小数据 → 层次聚类
• 簇形状不规则、有噪声、不知道K → DBSCAN
• 高维数据 → 先降维再聚类，或用谱聚类、高斯混合模型(GMM)

sklearn使用K-Means代码示例

理论讲完了，来看看实际怎么用——三行代码搞定聚类

# 导入KMeans from sklearn.cluster import KMeans from sklearn.datasets import make_blobs import matplotlib.pyplot as plt # 1. 生成模拟数据（4个簇） X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.60, random_state=0) # 2. 创建KMeans模型，指定K=4，然后训练 kmeans = KMeans(n_clusters=4, init='k-means++', n_init=10, max_iter=300, random_state=42) y_kmeans = kmeans.fit_predict(X) # 3. 查看结果 print("簇标签：", y_kmeans) # 每个点分到哪个簇（0~3） print("质心坐标：\n", kmeans.cluster_centers_) # K个质心的位置 print("目标函数J(Inertia)：", kmeans.inertia_) # 簇内平方和

⚙️ 重要参数说明

• n_clusters：K值，最重要的参数
• init：初始化方法，默认'k-means++'（推荐），也可以'random'
• n_init：跑多少次（不同随机种子），默认10次选最好的
• max_iter：最大迭代次数，默认300（一般够了）

肘部法则代码示例

用代码画出K-Inertia曲线，找最佳K值

# 肘部法则选择最佳K import matplotlib.pyplot as plt from sklearn.cluster import KMeans inertias = [] # 记录每个K对应的Inertia(J值) K_range = range(1, 11) # 尝试K=1到10 for k in K_range: kmeans = KMeans(n_clusters=k, init='k-means++', n_init=10, random_state=42) kmeans.fit(X) inertias.append(kmeans.inertia_) # 画肘部法则曲线 plt.figure(figsize=(8, 4)) plt.plot(K_range, inertias, 'bo-') plt.xlabel('Number of clusters (K)') plt.ylabel('Inertia (WCSS)') plt.title('The Elbow Method for choosing K') plt.grid(True) # 如果你想加轮廓系数法： from sklearn.metrics import silhouette_score sil_scores = [] for k in range(2, 11): # K至少为2才能算轮廓系数 kmeans = KMeans(n_clusters=k, random_state=42) labels = kmeans.fit_predict(X) sil_scores.append(silhouette_score(X, labels)) # 选sil_scores最大的那个K

💡 实践提示

实际项目中，建议肘部法则和轮廓系数结合起来用，再配合业务理解（比如你知道客户大概可以分几类）综合判断K值，不要完全依赖单一指标。

本集小结

恭喜你完成了第13集！来回顾一下核心要点

🔮 无监督学习

数据没有标签，算法自动发现隐藏结构。聚类是无监督学习最典型的任务。

🎯 聚类 vs 分类

分类是监督学习，类别预先定义；聚类是无监督学习，类别自动发现——本质区别！

⭐ K-Means核心思想

K个质心，迭代执行"分配簇→更新质心"直到收敛，最小化簇内平方和J。原理简单、速度快、工业界最常用。

📐 K值选择

肘部法则看拐点，轮廓系数看最大值，再结合业务知识综合判断。

⚠️ K-Means局限

需提前指定K、对初始值/异常值敏感、只能发现球形簇。K-Means++优化初始化，DBSCAN适合非球形簇。
