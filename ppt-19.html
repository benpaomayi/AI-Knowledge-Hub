回顾：单层感知机的局限

上一集我们知道了单层只能解决线性问题，那怎么办？

❌ 单层感知机的问题

只能学习线性决策边界（一条直线/一个超平面），无法解决XOR等非线性问题，表达能力太有限了。就像一个只有一个神经元的"大脑"，能做的事情非常少。

💡 关键思想：堆叠多层！

既然一层不够，那就把很多个感知机堆叠起来：第一层的输出作为第二层的输入，第二层的输出作为第三层的输入……这样层层组合，就能表达非常复杂的非线性关系了！

🔑 还有一个关键：非线性激活

但光堆线性层没用——不管叠多少层线性变换，等价于一层线性变换！我们需要在层与层之间加非线性激活函数，这样多层组合才能产生真正的非线性表达能力。

各层详细解释

每一层在做什么？有多少个神经元？

📥

输入层 Input Layer

数据进入网络的入口

  • 神经元数量 = 特征数量
  • 比如MNIST手写数字是28×28=784像素，输入层就是784个神经元
  • 输入层不做计算，只是把数据传进去
🧠

隐藏层 Hidden Layer

真正做特征变换和学习的地方

  • 可以有1个或多个隐藏层
  • 隐藏层神经元数量是超参数，可以自己定
  • 层数越多、神经元越多，网络容量越大
  • 为什么叫"隐藏"？因为它的输出不是我们直接想要的，中间过程看不见
📤

输出层 Output Layer

给出最终预测结果

  • 神经元数量 = 任务需要的输出数
  • 回归：1个神经元
  • 二分类：1个神经元(Sigmoid)
  • 多分类：类别数个神经元(Softmax)

什么是"深度"学习？

不是"理解深"，而是"网络层数深"

📏 定义：多少层才算"深"？

一般来说：隐藏层层数≥2的神经网络就可以叫"深度"神经网络（Deep Neural Network, DNN）了。

网络类型 隐藏层层数 别称
感知机/逻辑回归 0层 单层网络（线性模型）
经典MLP 1层 浅层神经网络
深度神经网络（DNN） ≥2层 深度学习！
现代深度网络 几十到上千层 ResNet可以做到1000+层

💡 有趣的历史

以前"深度学习"就是指有很多隐藏层的神经网络。现在CNN/RNN/Transformer等虽然结构不同，但都属于"深层"架构，所以都算深度学习。

全连接层（Fully Connected / Dense Layer）

MLP中每一层都是全连接层——每个神经元连所有下一层神经元

z = Wx + b
a = σ(z) x是输入向量，W是权重矩阵，b是偏置向量，z是加权和（预激活），σ是激活函数，a是激活后的输出

🔢 维度计算

假设输入x是n维向量，该层有m个神经元：
• W是m×n的权重矩阵
• b是m维的偏置向量
• z=Wx+b 得到m维向量
• a=σ(z) 也是m维向量（输出给下一层）

📊 参数量计算

这一层有多少个可学习参数？
• W有m×n个参数
• b有m个参数
• 总参数量 = m×n + m
这就是为什么全连接层参数多——连接数是n×m！

前向传播（Forward Propagation）

数据在网络中从输入到输出的计算过程

➡️ 什么是前向传播？

就是从输入层开始，一层一层往后算，直到得到输出层的预测结果。数据"向前"流动，所以叫前向传播。这是神经网络做预测时的计算过程。

以单隐藏层MLP为例：

输入数据 → 输入层: x
↓
隐藏层加权和: z⁽¹⁾ = W⁽¹⁾x + b⁽¹⁾
隐藏层激活: a⁽¹⁾ = σ(z⁽¹⁾)
↓
输出层加权和: z⁽²⁾ = W⁽²⁾a⁽¹⁾ + b⁽²⁾
输出层激活: ŷ = σ(z⁽²⁾)   ŷ就是预测结果！

🔑 多层网络就重复这个过程

如果有多个隐藏层，就不断重复"线性变换(Wx+b)→激活函数(σ)"这个过程，一层一层算下去就行。非常机械、非常简单——就是大量的矩阵乘法和激活函数！

为什么需要非线性激活函数？

没有激活函数，叠多少层都等于一层！

😱 证明：如果不用激活函数

假设我们有两层，没有激活函数，那输出就是：
ŷ = W²(W¹x + b¹) + b² = (W²W¹)x + (W²b¹ + b²) = W'x + b'
这还是一个线性变换！和直接做一层线性变换没有区别。不管你叠10层还是100层，都等价于一层——那深度学习就没意义了！

✅ 加了非线性激活之后

在层与层之间加入σ（如Sigmoid/ReLU/Tanh等非线性函数），多层组合之后就能表达复杂的非线性函数了。这就是为什么激活函数是必须的——没有它，深度就没有意义！

💡 直觉理解

线性变换就是"旋转、缩放、平移"，不管做多少次还是线性的。非线性激活就像"折一下"——每一层折一次，折很多次之后就能弯成任意复杂的形状，拟合任意函数。

万能近似定理（Universal Approximation Theorem）

为什么神经网络这么强大？数学证明给你看

📜 万能近似定理

只要隐藏层用的是非线性激活函数（如Sigmoid/ReLU），
并且隐藏层的神经元数量足够多，
那么单隐藏层的MLP可以以任意精度逼近任意连续函数！

🤯 这是什么意思？

理论上，只要一层隐藏层+足够多神经元，MLP就能学任何东西——不管是图像识别、语言翻译还是什么复杂任务，一个宽MLP理论上都能搞定。这是不是意味着我们不需要"深度"网络了？

那为什么还需要"深度"网络？

万能近似定理说一层就够了——为什么我们还要做几十上百层的深网？

📐 宽而浅（Wide & Shallow）

单隐藏层但神经元极多

  • 参数效率极低——需要指数级数量的神经元才能拟合复杂函数
  • 容易过拟合，泛化能力差
  • 没有利用"组合性"——特征是扁平的
  • 训练困难，优化 landscape 复杂
  • 需要大量数据才能训好

🗼 窄而深（Narrow & Deep）

多层但每层神经元不用太多

  • 参数效率高——深度可以用少得多的参数表达同样复杂的函数
  • 层次化表示特征，泛化能力更好
  • 和大脑视觉皮层处理方式类似
  • 实践中深网比宽网好训得多（残差连接等技术）
  • 同样参数下，深网表达能力远超宽网

💡 经典类比

就像写程序——你是愿意写一个包含1000个if-else的巨型函数，还是愿意写多个小函数、层层调用？后者模块化、可复用、好理解。深度网络就是后者的思路——层次化、模块化地表示复杂函数。

深度网络的关键优势：层次化特征表示

这是深度学习最本质的"魔力"所在

第1层（低层）：简单特征 图像识别中学：边缘、颜色、纹理；NLP中学：字、词、词性
第2-3层（中层）：组合特征 图像：纹理组合成形状、部件（眼睛、轮子、窗户）；NLP：词组、短语、语法结构
第4-5层（高层）：抽象特征 图像：完整物体（猫、汽车、人脸）；NLP：句子语义、段落含义
最后几层：任务输出 分类结果、预测值、生成内容

🔑 这就是"特征学习"

传统ML需要人工设计特征，而深度网络自动从低层到高层逐层学习特征——这正是深度学习最强大的地方！低层学通用简单特征，高层学任务相关的抽象特征，不需要人手工设计。

神经网络的四大核心组件

所有神经网络（不管是MLP/CNN/Transformer）都有这四个部分

🧱

1. 层（Layers）

神经网络的基本构建块。数据在层中做变换：线性变换(Wx+b)+非线性激活。不同类型的网络用不同类型的层：全连接层、卷积层、注意力层……

📊

2. 输入数据 + 真实标签

训练数据：输入特征x和对应的真实标签y（ground truth）。没有数据，网络就没有东西可学。数据是深度学习的"燃料"。

📏

3. 损失函数（Loss Function）

衡量模型预测ŷ和真实标签y之间的差距——模型"错得有多离谱"。损失越大，错得越厉害。训练的目标就是最小化损失。

⚡

4. 优化器（Optimizer）

根据损失函数，告诉网络怎么更新参数才能让损失变小。最常用的是SGD、Adam等梯度下降类优化器。

输出层应该怎么设计？

不同任务用不同的输出层配置——激活函数和神经元数量都不一样

任务类型 输出神经元数 输出层激活函数 常用损失函数 例子
回归 Regression 1个 无激活（线性） MSE均方误差 预测房价、预测温度
二分类 Binary Classification 1个 Sigmoid 二元交叉熵 BCE 判断垃圾邮件、疾病诊断
多分类 Multi-class Classification 类别数K个 Softmax 交叉熵 Cross-Entropy MNIST手写数字(10类)、图像分类
多标签分类 Multi-label 标签数K个 Sigmoid（每个独立） 二元交叉熵 一首歌同时有多个标签

⚠️ 不要乱选激活函数！

隐藏层通常用ReLU，但输出层的激活函数必须根据任务类型选。回归用线性，二分类用Sigmoid输出0-1概率，多分类用Softmax输出各类别概率和为1。选错了模型会训不动！

Sigmoid和Softmax快速回顾

输出层最常用的两个激活函数

🔵 Sigmoid（二分类用）

σ(z) = 1 / (1 + e⁻ᶻ)
  • 把任意实数压缩到(0,1)之间
  • 输出可以解释为"属于正类的概率"
  • σ(z)≥0.5判为正类，否则负类
  • 每个神经元独立输出概率

🟢 Softmax（多分类用）

Softmax(zᵢ) = eᶻⁱ / Σⱼ eᶻʲ
  • 输入K个实数，输出K个0-1之间的概率
  • 所有输出加起来等于1
  • 哪个输出概率最大就判为哪一类
  • 各类别之间是竞争关系

💡 隐藏层不用Sigmoid了

虽然Sigmoid是经典激活函数，但现在隐藏层基本都用ReLU（简单、训练快、缓解梯度消失）。Sigmoid主要用在二分类输出层。

参数（Parameters）vs 超参数（Hyperparameters）

搞清楚这两个概念的区别，非常重要！

🎓

模型参数 Parameters

模型自己从数据中学到的东西

  • 权重W、偏置b
  • 训练过程中自动更新，不用人手动设置
  • 训练的目的就是找到最优参数
  • 参数量可能从几千到几十亿（GPT）
  • 例子：W和b的具体数值
🎛️

超参数 Hyperparameters

人手动设置的"旋钮"，训练前就要定好

  • 学习率learning rate、batch size
  • 隐藏层层数、每层神经元数
  • 激活函数类型、优化器选择
  • 训练轮数epoch、正则化强度
  • 需要靠经验/实验来选择

🎯 简单记法

参数是模型学的，超参数是你设的。"调参"通常说的是调超参数。好的超参数能让模型训练更快、效果更好。

神经网络训练循环（Training Loop）

训练神经网络就是在不断重复这四步

1. 前向传播
Forward Pass
→
2. 计算损失
Compute Loss
→
3. 反向传播
Backward Pass
→
4. 更新参数
Update Params

➡️ 步骤1：前向传播

把一个batch的数据x输入网络，一层层往前算，得到预测ŷ。

📏 步骤2：计算损失

用损失函数算ŷ和真实y之间的差距loss——告诉模型"你错了多少"。

⬅️ 步骤3：反向传播（Backprop）

从损失开始，从后往前算梯度——每个参数应该往哪个方向调、调多少能让损失减小。（下集详细讲）

⚡ 步骤4：更新参数

优化器（如SGD/Adam）根据梯度，把参数W和b往"让损失变小"的方向调整一小步。

训练过程的直观理解

用"下山"来类比梯度下降最形象

🏔️ ⛰️ 🧗

🗻 损失函数 landscape 是一座山

• 位置 = 当前参数W,b
• 高度 = 损失Loss（越高错得越厉害）
• 目标 = 走到山的最低点（全局最优）
• 梯度 = "最陡的上坡方向"
• 梯度下降 = 往梯度反方向走一步（下坡）
• 学习率 = 每步迈多大
• 反复走 = 训练循环

✅ 训练就是"找最低点"

神经网络的训练本质上就是在参数空间里用梯度下降找损失函数的最小值。前向传播算当前高度，反向传播算往哪下坡，参数更新就是迈一步下坡——这个过程重复成千上万次，直到走到山谷底部（损失收敛）。

实战：MLP参数量计算举例

拿经典的MNIST手写数字识别举例，算一下一个MLP有多少参数

🔢 网络配置

• 输入：28×28像素手写数字图片 → 784维输入
• 隐藏层1：256个神经元 + ReLU激活
• 隐藏层2：128个神经元 + ReLU激活
• 输出层：10个神经元（数字0-9，共10类）+ Softmax

逐层数参数：

输入→隐藏1: W(784×256) + b(256) = 784×256 + 256 = 200,960
隐藏1→隐藏2: W(256×128) + b(128) = 256×128 + 128 = 32,896
隐藏2→输出: W(128×10) + b(10) = 128×10 + 10 = 1,290

总参数量 = 200,960 + 32,896 + 1,290 = 235,146 个参数！

😮 感受一下

这么一个"小"网络就有23万多个参数要学习——而这在深度学习里已经算非常小的了！现代大语言模型有几十亿到上万亿个参数。

再简单点：单隐藏层MLP（如课程例子）

784输入→256隐藏→10输出：这个"入门版"有多少参数？

W1: 784 × 256 = 200,704
b1: 256
W2: 256 × 10 = 2,560
b2: 10

总参数 = 200,704 + 256 + 2,560 + 10 = 203,530

🤔 思考一下

你发现没有？大部分参数都在第一层（20万/20万）——因为输入维度784很大，接256个神经元光W1就有20万参数了。这也是为什么我们需要CNN处理图像——全连接层在图像上参数太多了，CNN通过权值共享大幅减少参数。

💡 总结公式

全连接层参数量 = 输入维度 × 输出维度 + 输出维度（偏置）。记住这个公式，以后看网络结构自己就能算参数量了。

MLP的实际应用场景

全连接神经网络虽然简单，但这些地方仍然很好用

📊

结构化表格数据

CSV表格数据分类/回归，特征是数值/类别型的——MLP是不错的选择，和XGBoost可以互补。

🔢

作为网络的"头部"

CNN/Transformer提取特征后，最后接一个MLP分类头做分类/回归——几乎所有现代网络最后都有FC层。

🎓

学习入门最佳

结构最简单、最容易理解——学习深度学习的最佳入门模型。MNIST手写数字识别是"Hello World"。

⚠️ MLP不擅长什么？

图像（参数太多、没有利用空间局部性）、文本/序列（不能处理变长序列、没有时序建模能力）。这就是为什么我们需要CNN处理图像，RNN/Transformer处理序列——但它们最终都还是会用到MLP的思想。

本集知识点总结

恭喜你，现在你理解神经网络的基本架构了！

📚 核心知识点回顾

  • MLP结构：输入层→隐藏层（可多层）→输出层，层间全连接
  • "深度"：隐藏层≥2层就是深度网络（DNN）
  • 全连接层：每个神经元连下一层所有神经元，参数量=in×out+out
  • 前向传播：从输入到输出，一层层做"线性变换+激活函数"计算
  • 非线性激活：没有它叠多少层都是线性的，必须有！
  • 万能近似定理：单隐藏层+足够神经元能逼近任意连续函数
  • 为什么要深：参数效率高、层次化特征表示、泛化好
  • 四大组件：层、数据、损失函数、优化器
  • 输出层设计：回归→线性；二分类→Sigmoid；多分类→Softmax
  • 参数vs超参数：参数是模型学的(W,b)，超参数是人设的(层数/学习率)
  • 训练循环：前向传播→算损失→反向传播→更新参数，循环
